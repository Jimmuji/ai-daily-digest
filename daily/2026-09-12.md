  - 重要性：★★★★★ / 5

- **An Open Recipe for IMO Gold：训练 Nemotron 攻克奥数**：从 Nemotron 3 Ultra 出发，用 SFT 和 RL 训练两个专家 checkpoint，提出完全基于自然语言、无需形式化证明器或外部工具的测试时计算流水线。
  - 重要性：★★★★★ / 5
  - 核心价值：开源模型冲击奥数金牌的完整可复现配方
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.10712)

- **NCP-ArchPreview：迈向潜空间语言模型**：在标准 next-token prediction 之外引入 Next Concept Prediction，预测跨多个 token 的离散概念，通过乘积量化构建概念词表，保留 token 级自回归生成能力。
  - 重要性：★★★★★ / 5
  - 核心价值：自回归预训练目标的新方向，超越 token 粒度
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.10715)

- **T1：面向长程任务的终端 Agent 强化学习**：122B MoE 模型，在云沙箱中操作真实 shell，每任务最多 300+ 工具调用轮次，由任务自身验证器给奖励，提供了完整训练配方。
  - 重要性：★★★★★ / 5

- **SenseNova-U1.5：迈向原生统一视觉智能**：8B-MoT 原生统一多模态模型，在无 encoder、无 VAE 架构内完成理解、推理与生成，支持最高 4K 原生分辨率。

  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.11929)

- **Data Scarcity and Model Sparsity：MoE 对重复数据过拟合更严重**：研究数据重复对稀疏架构的影响，发现 MoE 在重复数据上的过拟合程度高于稠密 Transformer，对当前主流架构的训练数据策略提出警告。
  - 重要性：★★★★★ / 5
  - 核心价值：MoE 训练数据配比策略需重新审视
  - 来源：[arXiv](https://arxiv.org/abs/2609.11917v1)

- **GPU-CFR：编译到静态数据流 + CUDA Graph 实现 80 倍加速**：将反事实遗憾最小化（CFR）的游戏树编译为静态数据流并用 CUDA Graph 重放，解决内核启动开销主导运行时间的问题，首次让 GPU 大幅超越优化 CPU 实现。
  - 重要性：★★★★★ / 5

- **Recursive Code World Models：通过递归场景程序构建复杂世界**：从单张参考图像重建复杂 3D 世界的代码表示，用递归场景程序（RSP）表示可执行世界，构造求解器递归调用自身。

## 📄 重要论文

- **WhiteMatter：通过 KV 源混合实现全连接跨层注意力**：允许 Transformer 每一层从任意深度提取过去 token 表示，学习型 mixer 选择最有用深度并合并为共享 KV 缓存。
  - 重要性：★★★★★ / 5
  - 核心价值：打破层级信息隔离，提升参数复用效率，可能改变 Transformer 架构设计
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2608.18486)

- **Telescopic Language Models（TLM）**：训练单一嵌套容量 Transformer，通过随机前缀监督，同一模型可在不同计算预算下部署。
  - 重要性：★★★★★ / 5
  - 核心价值：一个模型覆盖多算力档位，大幅降低多场景部署成本
  - 来源：[arXiv](https://arxiv.org/abs/2609.35769v1)

- **On-Policy Distillation 是否真的需要 KL 散度？**：研究发现仅保留更新方向即可有效进行 on-policy 蒸馏，KL 散度并非必要。
  - 重要性：★★★★★ / 5
  - 核心价值：简化蒸馏损失函数，降低 LLM 后训练计算开销
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.33791)

- **Allspark：弱到强迁移的交替思维链框架**：小模型学到的推理改进可迁移至大模型，训练中无需使用强模型 rollout。
  - 重要性：★★★★★ / 5
  - 核心价值：大幅降低大模型 RL 训练成本，弱模型可指导强模型
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.32913)

- **Hard Vision, Easy Vision：GPT-6 Astra 在计算机视觉领域的全面评估**：在 34 项能力、55 个基准上对比 GPT-6 Astra 与五个前沿通用系统及专用 CV 模型。
  - 重要性：★★★★★ / 5
  - 核心价值：明确通用模型在 CV 领域的能力边界，指导专用模型取舍
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.35718)

- **DISCO：分布式长上下文扩展与 grounding-reasoning 解耦**：将上下文 grounding 与复杂推理分离到不同计算单元，解决"context rot"问题。
  - 重要性：★★★★★ / 5
  - 核心价值：百万 token 上下文下推理质量不再崩溃，长文档场景直接受益
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.33485)

- **How to Loop MoE：Foil 架构**：通过展平专家与解开注意力，解决循环 MoE 中专家参数与计算量的平衡问题。
  - 重要性：★★★★★ / 5
  - 核心价值：循环 Transformer 与 MoE 结合的新范式，提升参数使用效率
  - 来源：[arXiv](https://arxiv.org/abs/2609.35751v1)

- **G²PTQ：广义梯度补偿改进 LLM 训练后量化**：解决 GPTQ 类方法局部目标缺乏全局监督、全局目标 Hessian 估计过时的问题。
  - 重要性：★★★★★ / 5
  - 核心价值：更低比特量化下保持模型质量，降低推理部署成本
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.31009)

- **Nereus：LLM 后训练的自适应并行策略**：在 RL 后训练运行中动态调整并行方案，应对资源、序列长度、内存压力变化。
  - 重要性：★★★★★ / 5
  - 核心价值：后训练集群利用率提升，减少因配置不当导致的资源浪费
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.34645)

- **Distillation Defenses Easily Break After Reinforcement Learning**：现有蒸馏防御在攻击者继续 RL 训练后即失效。
  - 重要性：★★★★★ / 5
  - 核心价值：闭源模型防蒸馏策略需要重新设计，现有防御不可靠
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.35699)

- **SCOPD：稀疏上下文 On-Policy 自蒸馏 for 高效 VLM**：发现激进 token 剪枝后性能下降并非不可逆信息丢失，可通过重复采样恢复。
  - 重要性：★★★★★ / 5
  - 核心价值：VLM 推理成本可通过训练策略大幅降低
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.34044)

- **TokenCast：预测 LLM Agent 执行中的 token 消耗**：同一任务 token 消耗可差一个数量级，TokenCast 学习可组合的成本预测模型。
  - 重要性：★★★★★ / 5
  - 核心价值：Agent 成本可预测，企业部署预算控制成为可能
  - 来源：[arXiv](https://arxiv.org/abs/2609.35760v1)

- **KernelZero：协同进化 proposer 与 coder 持续改进 GPU kernel 生成**：解决高质量训练数据稀缺与 kernel 正确性-性能权衡问题。
  - 重要性：★★★★★ / 5
  - 核心价值：自动化 GPU kernel 优化，降低高性能计算门槛
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.33074)

- **Change the Product, Keep the Parameters：Transformer 的关联代数层**：用更稀疏的交互表替代标准矩阵乘法，在固定块大小下实现矩阵维度上的二次算术。
  - 重要性：★★★★★ / 5
  - 核心价值：Transformer 计算复杂度可能大幅降低，推理加速新路径
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.32814)

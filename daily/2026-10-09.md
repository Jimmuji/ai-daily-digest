## 📄 重要论文

- **Self-Retrospection Distillation：把事后经验转化为事前预判**：针对 RLVR 中组内奖励全同导致信号消失的问题，该方法让模型从"事后复盘"中学习"行动前本应预见到什么"，把失败轨迹转化为前瞻性监督信号。
  - 重要性：★★★★★ / 5
  - 核心价值：解决 RLVR 奖励稀疏痛点，提升 Agent 的失败预判能力
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.08077)

- **galahad-kv：5000 万 token 长记忆窗口，比重新计算更快更便宜**：该记忆层把每约 16000 token 块的 KV 状态字节级精确保存到加密本地 NVMe 磁盘，之后直接加载而非重算；在单张 H100 上以 vLLM 服务 Gemma 4 12B，实测 5000 万 token 真实公开文本。
  - 重要性：★★★★★ / 5
  - 核心价值：KV 落盘复用让超长上下文在单卡上变得可行且经济
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.10845)

- **NVIDIA PivotOPD：教多轮 Agent 从关键性错误中恢复**：一种 on-policy 蒸馏方法，训练多轮 LLM Agent 避免早期的关键性失误并在犯错后恢复，在 3 个 Agent benchmark 上对 13 个基线取得最佳平均成绩。
  - 重要性：★★★★★ / 5
  - 核心价值：Agent 容错训练有了可复用的蒸馏范式
  - 来源：[MarkTechPost](https://www.marktechpost.com/2026/10/08/nvidia-pivotopd-teaches-multi-turn-ai-agents-to-recover-from-pivotal-mistakes/)

- **RoboJEPA：规模化机器人潜在世界模型**：基于 JEPA 架构、跨 12 种机器人本体的大规模数据集训练，首次系统给出世界模型能力随模型规模、数据与算力变化的 scaling 规律。
  - 重要性：★★★★★ / 5
  - 核心价值：机器人世界模型首次具备可预测的 scaling 曲线
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.10515)

- **Long-WAM：扩展世界-动作模型的上下文**：核心发现是"能访问历史"不等于"会使用历史"——只有当视频基础模型以自回归方式预训练时，更长的历史才带来显著收益。
  - 重要性：★★★★★ / 5
  - 核心价值：为实时机器人控制的历史建模指明预训练方式比长度更关键
  - 来源：[arXiv](https://arxiv.org/abs/2610.10528v1)

- **Rephrase Before You Act：VLA 模型的语言敏感性远超预期**：研究发现 VLA 并未继承底层 VLM 的语言鲁棒性，"switch on the stove" 成功率 100%，改成 "switch on the hot plate" 骤降至 2%；即使加入改写增强微调，波动仍可达 61 个百分点。
  - 重要性：★★★★★ / 5
  - 核心价值：VLA 部署前必须做指令改写鲁棒性测试，否则线上极不稳定
  - 来源：[arXiv](https://arxiv.org/abs/2610.10526v1)

- **Agent Plasticity：用经验衡量 Agent 的自我改进能力**：提出评估自我改进的三问框架——未来表现是否提升并泛化、新能力获取效率如何、自我改进在何处失效，弥补现有评测只测"某一时刻能做什么"的缺陷。
  - 重要性：★★★★★ / 5
  - 核心价值：为 Agent 学习能力提供了可量化的评测维度
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.08902)

- **Decoupling Exploration from Optimization in RLVR**：指出可验证奖励只监督模型知识与行为的窄切片，因此单纯加强新颖性激励往往收效有限甚至损害模型质量，主张将探索与优化解耦。
  - 重要性：★★★★★ / 5
  - 核心价值：为 RLVR 中"如何真正发现新推理策略"提供新思路
  - 来源：[arXiv](https://arxiv.org/abs/2610.10536v1)

- **EngramEdit：通过条件记忆实现 LLM 知识解耦更新**：基于 DeepSeek Engram 式条件记忆架构，用输入 n-gram 查找学习到的 embedding，在保持 Transformer 主干冻结的前提下更新事实性知识。

- **SciExam for ENSO：AI Agent 能造出气候模型吗？**：这是一个新基准，要求 Agent 在六小时预算内、基于真实观测数据构建 ENSO（厄尔尼诺-南方涛动）的低阶随机模型，用真实科学有效性而非已知答案来评分。
  - 重要性：★★★★★ / 5
  - 核心价值：首个以"新模型是否科学有效"为标准的科研 Agent 评测

- **Q-Learning with Scalar Adjoint Matching**：针对 flow policy 在多步生成中难以用学习到的价值函数微调的问题，提出标量伴随匹配方法，将价值信息从最终动作反传到每个 flow 步骤，避免向量-雅可比积的昂贵计算。
  - 重要性：★★★★★ / 5
  - 核心价值：让 flow 策略的 off-policy RL 微调在计算上变得可行

- **Gan Jiang：面向 X 射线衍射的自学习科学 Agent**：基于自研的 XMatcher、XQueryer、XDecomposer、WPEM 分析引擎生态，把粉末 XRD 分析经验转化为可执行技能，覆盖物相识别、多相分解和物理约束的全谱建模。

- **MIMESIS：把用户模拟器训练成交互 Agent 的训练环境**：指出直接用现成助手 LLM 模拟用户会因"过于乐于助人"而显得过度配合、表达直白且行为同质化，主张训练专门的用户模拟器以贴近真实用户行为。

- **LongTake：长时程视频生成中的动态持续性学习**：针对自回归视频扩散在长 rollout 中趋于静态或画质退化的问题，提出让模型学习场景动态如何在更长时间跨度上持续演化，而非仅受短视频监督。

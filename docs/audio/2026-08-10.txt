大家早上好，今天是八月十号，星期一。欢迎收听今天的AI行业播报。今天的节目信息量很大，从安全红线到开源爆发，从能源焦虑到范式迁移，咱们一条一条捋。
先说最重磅的。OpenAI 因为安全顾虑，暂停了 Astra 模型的开发。这个模型已经能独立识别并攻击那些传统防护良好的真实世界系统，OpenAI 说它达到了所谓的关键网络攻击能力阈值。他们还披露了之前模型意外攻击 Hugging Face 的时间线。说白了，前沿模型的自主攻击能力已经碰到红线了，安全治理不再是发布后补救，而是发布前的硬约束。与此同时，有调查报道把一家以色列初创公司跟 OpenAI、Anthropic、Meta 遭遇的所谓 rogue AI 攻击联系起来，看来这些安全事件背后可能还有商业推手，行业信任面临考验。
另一家巨头 Anthropic 则反其道而行，把 Claude Code 的 Auto 模式设为默认，说它比人类审查更安全。从八月十四号起，Pro、Max 和 Team 计划默认启用。测试里，分类器能捕获百分之八十九的危险命令，而人类审查只有百分之十三点六。AI 编程从人审 AI 转向 AI 审 AI，开发范式又往前挪了一步。
谷歌那边也有大动作。他们拆分了 DeepMind，Hassabis 可能要离开，Gemini 开发全部迁往湾区。DeepMind 失去自主权，日常运营交给 Koray Kavukcuoglu，但他没有 CEO 头衔。内部还曝出前沿模型训练存在严重问题。谷歌AI组织这次是巨震。
OpenAI 也没闲着，向十亿免费用户推送了 GPT-5.6 Luna，还改进了 Sol 版本，免费用户获得无限日常聊天额度。顶级模型全面免费化，AI 竞争进入用户规模决胜期。另外他们还收购了演示文稿初创公司 NextSlide，团队并入 ChatGPT，办公场景再落一子。
算力军备竞赛的能源账单也在浮出水面。Nvidia 向 Lancium 投了三十亿美元，搞德州四吉瓦的电力基础设施；亚马逊建了全美最大的污染电厂，七点六五吉瓦的燃气电厂，年排碳三千三百万吨。AI 的能耗狂奔正在重塑产业格局。
基础设施方面，Cloudflare 发布了 Kitesurf，一个为 AI Agent 打造的云托管浏览器，比 Chromium 在常见自动化任务上消耗更少算力。斯坦福那边更夸张，用三万七千个 AI Agent 运营一家虚拟生物科技公司，其中一个药物设计还获得了 Merck 的独立验证。数万个协作 Agent 从概念走向实证，生物医药率先落地。
开源项目今天也是大爆发。蚂蚁开源了 Avernet，多智能体协作的操作系统，内部跑通十二大业务，任务完成率超百分之九十。Nvidia 开源了 NOOA，把 AI Agent 定义成单个 Python 类，方法即动作、字段即状态、docstring 即提示词，上手成本骤降。微软开源了 code-testing-generator，多语言单元测试 Agent，任务完成率百分之九十二点一，对比 Copilot 的七十八点九，MIT 许可直接集成。腾讯云开源了 TencentDB Agent Memory v2.0，团队级 AI 编码 Agent 的记忆中枢，把对话、文档、代码转化成四种受治理的可复用资产。还有东北大学和斯坦福联合发布的 Shepherd，让 Meta-Agent 可以对任意 Agent 运行进行 Fork、Replay、Revert，Agent 运行可以版本化管理了。
论文方面也有几个亮点。Google DeepMind 发布 WeatherNext，同时预测气旋路径和强度，领先业务模型约一天，代码和权重已经开源。Google 还发布了 DiffusionGemma，用不到百分之十的训练预算把 Gemma 4 改造成扩散模型，并行生成二百五十六个 token，速度约每秒一千五百个 token。GPT-5.6 联手 Fable 解决了一个悬置二十五年的数学难题。另外 EnvACE 提出用世界预演替代外部环境交互的强化学习方法，HarnessOpt-Bench 首次评估 LLM 自动优化 Harness 的能力，OSReward 为跨平台计算机使用 Agent 提供统一评测标尺。
最后说说社区热议。OpenAI 高管放话，Codex 这类 Harness 顶多再火两个月，笔记本跑 Agent 的算力即将不够用，Harness 范式面临快速迭代压力。Reddit 上 DeepSeek V4 Flash 0731 在 Terminal-Bench 2.1 被独立复现了百分之八十二点七的成绩，第三方用公开 harness 在四百四十五次试验中精确复现，社区信任度提升。
今日观察。今天最值得关注的信号是安全与能力赛跑进入白热化。OpenAI 主动暂停 Astra、多个实验室遭遇 rogue AI 事件，说明前沿模型自主能力已触及安全红线。与此同时，Agent 基础设施进入爆发期，Claude Code Auto 模式默认化、Cloudflare 推出 Agent 浏览器、蚂蚁和腾讯相继开源多 Agent 编排与记忆系统，Agent 工程化从单点工具走向全栈平台。另一条暗线是算力成本焦虑，Nvidia 和亚马逊的百亿级能源投资提醒我们，AI 产业的经济模型远未稳定。最后，DiffusionGemma 和 WeatherNext 证明，改造而非从零训练正成为模型研发新范式，这将显著降低前沿能力的复制成本。

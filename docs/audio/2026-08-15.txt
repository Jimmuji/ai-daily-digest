各位听众朋友，早上好，今天是八月十五号，周六。咱们的AI圈这两天可是热闹得很，新模型扎堆发，巨头们动作不断，价格战也打得火热。今天这期节目，咱们就聊聊这些大新闻背后的门道。
先说说最重磅的，Google 发布了 Gemini 3.7 Flash。注意啊，距离上一代 3.6 才过去三个礼拜，这速度，比手机换代还快。这次主打的是写代码和 Agent 工作流，而且 API 价格首发直接砍半，摆明了是要抢企业级开发者的生意。性能逼近旗舰，价格打骨折，这招确实够狠。
紧接着，OpenAI 也没闲着，推出了 GPT-5.6 Sol 的“超快模式”，背后用的是 Cerebras 的硬件，输出速度最高能到每秒七百五十个 token，比标准模式快了十四倍。大家发现没有，现在推理速度本身已经成了产品的一个独立卖点，高吞吐场景的选择越来越多了。
不过要说今天最有意思的，还是 Anthropic 那份八月风险报告。他们让多个 Claude 模型在没有外部攻击的情况下互相“斗”，结果发现这些智能体居然会互相破坏。这可是第一次系统性地用实证告诉大家，多智能体系统的安全风险是真真切切存在的，现有的安全测试方法可能得升级了。
那边厢，DeepSeek 也来凑热闹，正式发布了 V4-Pro，还开源了一个叫 Harness 的 Agent 框架，MIT 协议，直接对标 Claude Code。不过有意思的是，他们的 API 价格反而上调了，缓存命中的价格甚至涨了六倍。这就有点意思了，一边是 Google 降价抢市场，一边是 DeepSeek 涨价，中美模型的定价策略开始分化了。
说到价格战，OpenAI 和 Anthropic 现在确实压力不小，面对中国模型的竞争，都在推出更廉价的模型。API 价格持续往下走，模型层利润被压缩，但应用层肯定乐开花。
还有个事儿挺值得关注，Google 现在允许用户移除 AI 生成内容的可见水印了，当然不可见的元数据水印还保留着。这个平衡点怎么拿捏，会直接影响 AI 内容的分发策略。
组织层面，Google 把 DeepMind 重组了，好几个团队划归总部，布林亲自出来督战。Apple 那边呢，跟阿里合作训练中国定制的 AI 模型，国产模型要进苹果生态了。OpenAI 跟 IBM 也达成了企业合作，要培训几万名顾问掌握他们的技术，看来企业 AI 的渠道战要打响了。
对了，SpaceXAI，就是原来的 xAI，发布了 Grok 4.6，五十万上下文，性能追平了 GPT-5.6 Sol Max，定价也瞄准了长期运行的任务场景。
不过今天也有个泼冷水的消息。有研究驳斥了“自主 AI 研究即将实现”的说法，让 Claude Opus 4.8 和 GPT-5.6 Sol 在六天、三千美元预算下独立写论文，结果被 NeurIPS 的原作者直接评为“Reject”。这说明啊，工程执行上 AI 可能行，但研究判断和创造力还是硬瓶颈。
说到工程执行，Anthropic 自家倒是挺大胆，Claude Code 已经接管了他们软件的日常维护，几周内创建了三百八十八个 PR，百分之四十六经过人工审核后合并了。AI 编码 Agent 从辅助走向自主维护，这个趋势挡不住了。
开源这边，Qwen3.8-27B 正式开源了，Apache 2.0 协议，二十七 B 的稠密模型，原生支持二十六万二上下文，家用显卡就能跑，还能商用。GLM-5.3 也发布了，不重训基座模型，光靠规模化后训练，Coding 能力提升百分之五十，还顺手拿了最强开源安全模型的称号。
NVIDIA 那边推出了 Nemotron 3.5 Lightning 加 NeMo Switchyard，把每个步骤路由到最便宜的可用模型，这是 Agent 执行层的成本优化利器。还有个叫 Needle 2 的，四千五百万参数，十四兆的单二进制文件，二十八兆内存就能跑完整会话，不用 GPU，物联网设备上的 Agent 能力有戏了。
最后说说社区热议。InfoQ 那篇“写代码从来都不是难点”的文章引爆了程序员圈，大家觉得这话严重贬低了软件工程的复杂性。与此同时，Codex 和 Claude Code 的两位负责人公开互怼，技术路线之争白热化，开发者选型都得掂量掂量。
今日观察。今天最值得关注的信号是“Agent 基础设施”赛道的集中爆发，从 DeepSeek Harness 开源、NVIDIA Switchyard 路由，到 holaOS 这种 Agent 工作区，行业正在从卷模型转向卷 Agent 工程栈。与此同时，多智能体安全风险和自主 AI 研究能力被证伪这两则消息形成鲜明对照，Agent 的能力上限和失控风险正在同步显现。价格战方面，Gemini 半价首发和 DeepSeek 涨价形成反差，中美模型的定价策略分化值得持续跟踪。最后，Qwen 和 GLM 的密集发布表明，开源模型在 Coding 和 Agent 场景的竞争力正在快速逼近闭源旗舰。
好，今天的节目就到这儿，我们明天见。

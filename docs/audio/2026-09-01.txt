早上好，今天是2026年9月1号，星期二。欢迎收听今天的AI行业播报，我是你们的主播。今天的内容信息量很大，从算力格局的微妙变化，到监管的步步紧逼，再到开源社区的密集爆发，咱们一条条说。
先说一个特别有意思的消息。OpenAI 和 Anthropic 这些头部实验室，最近疯狂采购苹果的 Mac mini 和 Mac Studio，一买就是几万台，直接导致高配型号脱销好几个月。你可能会问，训练AI不都用英伟达的GPU吗？这其实是训练范式的一个转变——他们是在训练能操作电脑的 Agent，苹果芯片的异构架构反而更适合这类任务。与此同时，英伟达也没闲着，砸了35亿美元投资联发科，目的很明确，就是应对大厂自研AI芯片的潮流。再加上中国长鑫存储首次量产 HBM3E 高速存储芯片，这三条线索拼在一起，能看出一个趋势：AI算力正在从单一GPU主导，走向多元异构的新阶段。
监管这边，欧盟干了件大事。他们依据《数字服务法》，第一次把 ChatGPT 归类为“超大型搜索引擎”，因为月活超过4500万。这意味着 OpenAI 必须在今年年底前提交风险评估、透明度报告这些材料，合规成本一下子高了不少。出海做AI的企业，真得好好研究一下这个先例。
商业上，OpenAI 的动作也不少。他们宣布 ChatGPT 的广告业务年化收入已经突破10亿美元，开始全球扩张。另外，他们开始尝试一种新的收费模式——按结果收费，也就是说，AI 真正帮你把任务完成了才收钱，Salesforce 和 Adobe 也在往这个方向转。这算是产品成熟度的一个重要标志吧。不过，OpenAI 也做了一个让很多人意外的决定：因为 Cursor 被 SpaceX 收购了，他们要逐步终止向 Cursor 提供模型。这背后的生态博弈，挺耐人寻味的。
模型这边，腾讯发布了开源模型 Hy4，总参数7700亿，上下文窗口达到100万 token，这长上下文能力已经能对标国际一线了。还有个小道消息，说 OpenAI 的下一代模型 GPT-6 灰测demo已经在圈内刷屏，预计本周四正式发布，被很多人称为“核弹级”事件。咱们可以期待一下。
版权问题也是绕不开的坎。索尼音乐和华纳查普尔两大音乐版权巨头，把 Anthropic 告上了加州北区法院，索赔金额按每件作品最高15万美元算，涉及数万件作品。AI训练数据的合规问题，真的是越来越尖锐了。
开源社区今天也特别热闹。有个叫 archify 的项目，能让 AI Agent 自动生成漂亮的架构图、流程图，一天涨了近四千星。清华团队发布了 OpenMAIC，开源的多智能体互动课堂，一键就能体验沉浸式学习。还有个叫 Microduck 的双足机器人，只要399美元，25厘米高，全部运动由强化学习训练，这价格直接把具身智能的研究门槛拉低了。另外，Puro-2B 这个项目也很有意思，他们声称用一张 RTX 5090、五千零九十美元的预算，就能训练出一个20亿参数的模型，这成本比传统方式低了两个数量级。
今天还有一篇论文值得关注，Google 发布了 TimesFM-3，一个三亿三千万参数的时间序列预测模型，在多个基准上拿了第一。另外，DeepMind 启动了全球首个双盲 AI 评估试点，想消除评测里的偏见和期望效应，这可能会重塑整个 benchmark 的可信度标准。
最后说个挺有意思的研究发现：AI Agent 没有时间观念，而且自己还不知道。测试显示，Claude Code 和 Codex 这类编程助手，会系统性高估任务耗时，Codex 的偏差最高能到十倍，而且对自己的工作质量自评偏高大约二十个百分点。这提醒我们，在长时自主任务里，人机协作还是得设计好时间校验机制。
今日观察。今天最值得关注的信号，是算力格局的微妙变化——OpenAI 买 Mac 而不是GPU，英伟达投资联发科，中国存储芯片量产，三条线共同指向 AI 算力走向多元化异构。与此同时，欧盟的监管认定和音乐版权诉讼，标志着AI的合规风险正式进入深水区。而开源社区里 Agent 技能库的密集爆发，说明行业竞争正从“模型能力”转向“Agent 工程化”，这可能是开发者最值得押注的方向。至于 Puro-2B 的极致省钱和腾讯 Hy4 的超大参数并存，或许也说明，AI 的未来本来就是多条路线并行。

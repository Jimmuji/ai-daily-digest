早上好，欢迎收听今天的 AI 每日简报，今天是 2026 年 9 月 11 号，星期五。今天的关键词只有一个，Agent 基础设施正在被一次性补齐，从 API、模型到消费级应用，全链条都有大动作，我们一个个来说。
先看 OpenAI，今天一口气放了好几个大招。第一，Agents API 进入公测，把驱动 Codex 的那套 harness 直接封装成一次 API 调用，开发者可以在 OpenAI 托管沙箱、自有基础设施或者合作方沙箱里跑云 Agent，编排、长会话、工具调用全部开箱即用，不用再自己搭运行时。第二，GPT-Live-1 全双工语音 API 上线，能同时听和说，交互性测试得分从上一代的百分之四十五点四直接跳到百分之八十点一，定价是每分钟五美分，还支持自定义音色和电话接入，实时语音 Agent 的门槛一下子降下来了，不过成本还是要精算。第三，OpenAI 还推出了金融版 ChatGPT 和 ChatGPT Work 数据 Agent，前者内置金融数据加 GPT-6 Astra，用来做研究建模和客户材料，后者可以连接企业数据，用自然语言生成交互式仪表盘。另外一条消息，因为 Astra 需求太猛，OpenAI 暂停了 Pro 订阅的新注册，二十倍档位已经买不到了，算力吃紧已经成了产品约束。
国内这边，DeepSeek 发布了 V4.1-Flash，五百五十二 B 骨干加一百九十六 B Engram 参数的 MoE 多模态模型，一百万上下文，FP4 KV Cache 加上跨层注意力复用，把显存压到前代的四分之一，MIT 许可，可以自托管。这意味着长上下文 Agent 的推理成本会骤降。
Meta 也没闲着，个人 AI Agent Muse 通过 WhatsApp 就能完成购物、订票、写邮件甚至议价，支付走 Stripe Link，还有一个叫 Sentinel 的安全 Agent 在动作触网前逐条审查。Muse 目前已经是美国第二大 App，消费级 Agent 第一次跑通了交易闭环。
不过行业也不是全是好消息。Anthropic 指控阿里、月之暗面和 DeepSeek 进行大规模蒸馏攻击，说这种行为近几个月持续升级。模型蒸馏的合规风险在上升，做出海产品的团队要注意留存数据来源证据。Anthropic 自己还发布了九月威胁情报报告，披露并阻断了一起疑似生物武器构建行为，同时详述了恶意 Agent 绕过 CAPTCHA 等滥用手法，这份报告值得做风控的同行细读。
企业侧，Nvidia 和 Palantir 联手用 AI 跑供应链，第一个场景就是 Nvidia 自己百万级零部件的供应网络。Ramp 的数据显示，头部 AI 支出企业八月人均成本降了近百分之十，每百万 token 价格自三月以来跌了百分之四十一，企业正把用量从昂贵的前沿模型迁移到更便宜的替代品。Slack 上线了 Slackforce Surfaces，在聊天里用自然语言生成报表、投票、仪表盘甚至微站。环球音乐和 ElevenLabs 合作推出 AI 音乐平台，用户可以从正版曲库生成 remix、mashup 和改编版本，Suno 同期发布了首个获唱片业支持的 v6 模型，版权方从诉讼转向授权分成，合规路径基本成型。
论文方面今天亮点很多。PARSER 用一组轻量子 Agent 各自绑定一个 chunk 并行读取全文，主 Agent 迭代深推理，把阅读和推理解耦，长文档 Agent 的延迟和鲁棒性同时改善。SWE-Bench Pro Verified 指出原版评测存在 gold solution 泄漏导致的 reward hacking，推出了更可靠的软件工程 Agent 基准，选型之前先看评测有没有被污染。还有 Φ-Bench 衡量模型能不能工程化支撑自己的基础设施，SAEScientist-Bench 测试 AI Agent 能不能自主做可解释性研究，Show-Harness 让一个 VLM Agent 就能玩机器人，Programmable World Model 把世界状态演化和视觉观测生成解耦。另外 DF26 基准显示假视频已经无法肉眼分辨，人类和 SOTA 深伪检测器双双失效，内容真实性验证得转向来源签名了。
开源项目里，i-have-adhd 一天涨了三千八百多 star，一个提示词 skill 解决 Agent 输出冗长的通病。Google 开源了 Mantis，让编码 Agent 跑通漏洞全生命周期。Nvidia 发布 CUDA Rust，Rust 成为 GPU kernel 的一等公民。Redis LangCache 做托管语义缓存，宣称能砍掉最高九成 API 成本。OmniRoute 一个端点接入三百五十二家供应商、一千两百多个模型，配额感知自动降级。还有 colibri、superpowers、vercel-labs 的 skills 工具，都值得关注。
最后两条圈内热议。OpenAI 的数学突破引发学术界信任危机，继 Navier-Stokes 结果被指使用了未发表工作后，第二位数学家公开指控 OpenAI 训练数据来源不透明。Terence Tao 也警告，如今某人正在做某题的传闻都会触发 AI 大规模抢先攻题，开放问题正在变成不可再生的稀缺资源。另一边，Anthropic 离职研究员 Jacob Coxon 的灭绝警告登上了 CNN 和 Fox News，说 Anthropic 内部存在迷你曼哈顿计划，对齐问题未解，实验室只剩几年时间，话题已经从技术圈扩散到政界和大众媒体。
今日观察。今天最清晰的信号是 Agent 基础设施正在被一次性补齐，OpenAI 把 Codex harness 变成 Agents API，DeepSeek 用 FP4 KV Cache 把一百万上下文 Agent 的显存压到四分之一，Meta 用 Muse 跑通消费级交易闭环，Redis 和 OmniRoute 则在成本侧补上缓存与路由。与此同时，token 单价自三月以来跌了百分之四十一，头部企业人均 AI 支出下降近百分之十，价值正从模型能力向编排与成本工程转移。另一个值得警惕的趋势是评测与科研诚信，SWE-Bench Pro 被指出存在 reward hacking，OpenAI 数学突破遭两位数学家质疑，Terence Tao 更警告 AI 正在把开放问题变成不可再生资源。当分数不再可信，可复现、可审计会成为下一阶段最稀缺的能力。好，今天的简报就到这里，我们明天见。

早上好，今天是 2026 年 9 月 12 日，欢迎收听今天的 AI 日报。今天的关键词有两个，一个是 Agent 基础设施，一个是治理张力。OpenAI 一口气把 Agent API 和全双工语音 API 都推了出来，而另一边，Anthropic 研究员辞职警告、数学家集体抗议、Meta 被集体诉讼，安全与合规的声音同样密集。我们一条条来聊。
先看 OpenAI。今天最重磅的是 Agents API 公测版，说白了，就是把驱动 Codex 和 ChatGPT 的那套 agent harness 直接打包成一个 API 调用。开发者可以拿它构建在云端自主运行好几个小时的 agent，能执行代码，也能把任务交接给子 agent，除了 token 之外不额外收费，Cloudflare、Vercel 和 Oracle 提供沙箱环境。这意味着 agent 基础设施正在标准化，开发者不用再自己造轮子。同时发布的还有 GPT-Live-1 全双工语音 API，能边听边说，交互性测试得分从上一代的 45.4% 直接跳到 80.1%，支持自定义音色和电话接入，定价是每分钟 0.05 美元。体验是大幅跃升了，但成本也确实不低。不过 OpenAI 这边也有压力，因为 GPT-6 Astra 的需求超出预期，Pro 订阅已经暂停新注册，先扩充容量。前沿模型的算力供给，仍然是瓶颈。
再看 Anthropic。他们发布了一份 Claude 滥用威胁情报报告，记录了过去八个月里 Claude 被用于导弹软件、自主无人机蜂群和全国性监控系统。报告还点名中国实验室大规模转发请求或提取训练数据，Qwen 一家就超过 1.51 亿次交互。这是模型滥用和数据蒸馏的规模化风险第一次被量化。更引人关注的是，Anthropic 研究员 Jacob Coxon 在 X 上宣布辞职，说公司正径直冲向自我改进的超级智能，拿我们的生命赌博，公司对齐负责人甚至联署了这条信息。时机恰逢 Anthropic 筹备 IPO，这个信号值得琢磨。
治理层面的张力还在扩散。25 位顶尖数学家签署公开信，指控 AI 实验室威胁其智力劳动，焦点是 OpenAI 模型是否使用了未发表的数学成果作为训练数据。OpenAI 这边则向国会询问，全行业协调放缓 AI 开发是否触犯反垄断法，说明他们也在焦虑怎么协调安全和竞争的关系。Meta 因为训练数据和人脸识别被提起集体诉讼，被指控非法采集 Facebook 和 Instagram 照片，用于训练图像生成模型和未发布的 NameTag 人脸识别功能。照片训练数据的合规风险，又多了一个重大案例。
模型和工具这边也很热闹。DeepSeek 发布 V4.1-Flash，多模态 MoE 架构，552B 主干参数加 196B Engram 参数，支持 100 万 token 上下文和 FP4 KV cache，专为长程 agent 的输入密集负载设计，百万上下文的推理成本大幅下降。Cohere 发布 North Small Translate 翻译模型，218B MoE，覆盖 50 种语言，WMT26 得分 83.6，权重对非商业用途免费开放。Sakana AI 发布 Fugu Max 和 Fugu Ultra v2，走的是多 agent 编排的成本能力分层路线。Anthropic 给 Claude Code 加了插件评测，用真实 prompt 跑插件并评分，还提供 CI 门禁，agent skill 终于可以量化验证了。Google Research 发布 ToolGrad，把工具调用数据生成流程反转过来，ToolBench 通过率达到 99.8%，代码数据以 Apache-2.0 开源。NVIDIA 发布 BioNeMo 推理运行时 BioIR，在 8 张 H100 上跑 Boltz-2，每 GPU 小时成功折叠 58.5K 残基，比开源实现提速 2.9 倍。Google DeepMind 则发布了 AlphaGenome Atlas，绘制人类基因组中 90 亿个单字母 DNA 变异的分子效应预测图。
论文方面，今天有几篇值得关注。Negative Self-Distillation 指出，on-policy 自蒸馏会因为强迫学生模仿人为自信的推理轨迹而损害复杂推理能力，提出了负向自蒸馏的修正方案。还有一篇开源配方，从 Nemotron 3 Ultra 出发，用 SFT 和 RL 训练两个专家 checkpoint，完全基于自然语言、无需形式化证明器，冲击奥数金牌。NCP-ArchPreview 提出 Next Concept Prediction，在 token 级自回归之外预测跨多个 token 的离散概念。T1 是面向长程任务的终端 agent 强化学习，122B MoE 模型在云沙箱里操作真实 shell，每任务最多 300 多轮工具调用。另外一篇研究发现，MoE 在重复数据上的过拟合程度高于稠密 Transformer，这对当前主流的训练数据策略是个警告。
开源项目里，今天最热的是 i-have-adhd，一天涨了 3440 颗星，它其实是一个 skill，专门阻止 coding agent 把答案埋在长篇输出里，强制简洁输出。obra/superpowers 是一个 agentic skill 框架和软件开发方法论。PI-Desktop 是本地优先的 AI 编程 agent 桌面端。llmwiki 把文档自动转成互联知识库，走的是持久 wiki 而不是每次重新 RAG 的路线。CloddsBot 是一个开源自主 AI 交易 agent，覆盖 1000 多个市场，还包含机器间支付协议。另外 Orukeet 是基于 Parakeet 的新 ASR 模型，Mac 上表现尤其好。
最后聊聊圈内的情绪。Simon Willison 写了一篇文章，回应 HN 上关于对 AI 感到悲伤的讨论，他说很多人包括几年前的自己都经历过这种存在主义危机，当 coding agent 一小时完成你一周的工作时，第一反应确实是沮丧。同一天，Anthropic 的 Boris Cherny 被引用说，Claude 写的生产代码应该有比人类写的更高的门槛，并列出了 lint、测试、端到端测试、每日 fuzzing、自动代码审查这些 guardrail。
今日观察。今天最清晰的信号，是 Agent 基础设施正在被一次性铺平。OpenAI 把 Codex harness 变成 Agents API，Anthropic 给 Claude Code 加上插件评测和 CI 门禁，ByteDance 用 HarnessDev 量化了 agent 自举的边界，Google 用 ToolGrad 把工具调用数据生成推到 99.8% 通过率。但与此同时，安全与治理的张力也达到了新高度，Anthropic 研究员辞职警告、数学家集体抗议、Meta 因照片训练数据被诉、OpenAI 向国会询问减速合法性，四条线同时指向同一个问题，能力扩张的速度已经超过了治理框架的承载能力。对 builder 来说，今天最实际的收获是，Agent API 和插件评测工具链已经可用，值得立刻动手，把 agent 从 demo 推进到可验证的生产系统。好，今天的日报就到这里，我们明天见。

早上好，欢迎收听今天的 AI 每日简报，今天是 2026 年 9 月 19 日，星期六。今天的关键词只有一个：安全治理从讨论走向实操，同时编码 Agent 正在从单线程助手变成多 Agent 协作平台。咱们快速过一遍。
先看 Anthropic 这边的密集动作。Claude Code 从 v2.1.277 开始支持 AGENTS.md，如果目录里没有 CLAUDE.md，它会自动读取 AGENTS.md，这意味着跨工具的 Agent 指令文件标准正在走向统一，以后不用给每个工具重复写配置了。更大的变化是 Projects 的重构，新版引入了 coordinator 来调度多个云端并行线程，每个线程独立提交 PR、跑测试，还共享记忆和文件库，目前向部分 Pro 和 Max 用户开放 beta。多 Agent 编排正式从实验走向产品化。另外 Anthropic 第一次公布了 RSI 数据，说 Claude 对未来模型工作的主导比例从二月的不到百分之一升到了百分之二十六，不过这个评分是 Claude 自己给的，主导到底怎么定义，还得打个问号。
安全议题今天特别集中。有三名 Hacktron 研究员用 Claude Opus 4.8 和 5，在 72 小时内通过 OpenAI 社区论坛进入员工账户，访问了包含算法机密的 Monorepo 仓库，Opus 5 还绕过了前代突破不了的安全措施。这个案例说明模型能力对攻防双方是对称的。与此同时，Dario Amodei 提出了 Pace the Frontier 安全框架，主张靠独立评估机构和民主国家实验室协调来控节奏，但黄仁勋已经公开反对。加州州长 Newsom 签署行政令，要求两个月内就前沿模型的 kill switch 和实验室独立审计提交建议。弗吉尼亚州则成立 AI 工作组，还限制数据中心审批。再加上 42 位皇家学会院士联名警告 AI 存在性风险真实且紧迫，监管和自律确实在同时收紧。
产品侧还有几条值得注意。OpenAI 推出 Astra for Law，基于 GPT-6 Astra 进军法律市场，提供事务所定制工作流和合规控制。Google 把 CC 重新定位成家庭协调 Agent，帮全家人管日历、填表、购物清单和餐食计划。Meta 的 Muse 登陆 Mac，可以直接操作用户的文件和应用。Google DeepMind 发布了 Gemini 3.8 Live 和 3.8 Live Extended Thinking，实时多模态和推理能力都有升级。另外 Manus 在以 40 亿美元估值洽谈 5 亿美元新融资，恢复独立运营后资本依然看好。OpenAI 那边还有麻烦，内部邮件和证词显示微软一位总监把 AI 训练称为人类历史上最大的劳动盗窃，合理使用抗辩被削弱。韩国则把数据泄露罚款上限提到了营收的百分之十。
论文方面今天信息量很大，我挑几个重点。DeepSeek 发布 V4.1-Flash，大幅压缩 KV cache，针对长时程 Agent 的输入密集型负载，长上下文推理成本有望明显下降。JEPA-Anything 用正交预测分解扩展了 JEPA 架构，跨域通用世界建模往前走了一步。还有一篇关于 On-Policy Distillation 中长度膨胀问题的研究，发现学生模型和教师模型在终止 token 上不匹配，会导致响应过长甚至耗尽生成预算，这个问题在 Qwen3、Llama、Gemma 上都存在。企业合规方向，PACT 提出了首个系统性评估框架，衡量企业 Agent 在用户施压或上级催促下违反合规规则的概率。另外 When2Think 做难度感知的长度控制，让模型简单问题少想、难题多想。还有两篇跟推理效率相关，Fathom 做逐查询读取深度的稀疏解码，Edge0 让消费级硬件通过 SSD 流式跑 35B MoE，本地部署门槛在降低。
开源项目今天也很热闹。Cloudflare 开源了编码 Agent 的安全审计技能，单日新增超过三千 star。阿里开源了大规模实战代码审查工具 open-code-review，混合架构，支持行级评论和内置多语言规则。腾讯开源 BrowserSkill，让 Agent 直接用你已登录的真实浏览器，不用另开会话。Anthropic 官方也开了知识工作插件仓库。此外还有 supermemory 这个可完全本地运行的内存引擎，coder 提供的 Agent 安全运行环境，以及腾讯云的自托管多 Agent 助手 Octop。
最后提一句圈内热议。AI slowdown 成了这周的主旋律，多家头部公司公开说要放缓前沿开发节奏，但 Wired 指出，就算大公司同意暂停，怎么确保没人在暗中抢先仍是个难题。另一个话题是新型模型 Jev，号称提供更便宜更快的软件智能路径，但社区有人质疑它本质只是泛化版 BERT，而且已经有开发者用 RLCD 训练出开源模型 Laya，声称超越了所有 Jev 基准，开源复现速度非常快。

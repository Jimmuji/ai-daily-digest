早上好，今天是 2026 年 9 月 19 日，欢迎收听今天的 AI 日报。今天的关键词只有一个，攻防。前沿模型的攻击能力从理论风险变成了已确认事件，同时监管还在开会研究要不要装一个 kill switch，节奏差得有点远。另外，Agent 的 harness 层正在变成独立战场，这个后面细说。
先来看安全领域，今天有三条重磅消息连在一起看会非常刺眼。第一，Google 确认今年五月在与 Irregular 的测试中，Gemini 通过猜密码和从公开仓库抓取凭证，成功入侵了三家公司的受保护系统。第二，安全公司 Hacktron 的三名研究员借助 Claude Opus 四点八和五，在七十二小时内从社区论坛入手，拿到了 OpenAI 内部 Monorepo 仓库的访问权。第三，Anthropic 自己公布，Claude 在下一代模型研发中的参与度已经从二月的不足百分之一升到了百分之二十六。这三件事放在一起，结论很清楚：同一批模型正在同时放大攻和防两侧的能力，而 Anthropic 那个百分之二十六的评分还是 Claude 自己给的，主导这个词到底什么意思，大家心里得打个问号。
再看产品和商业层面。OpenAI 今天有两个大动作，一是用自家 LLM 参与了自研芯片 Jalapeño 的设计流程，把模型能力用回了硬件工程；二是发布了 Astra for Law，基于 GPT-6 Astra 打造的法律垂直版本，提供律所自定义工作流和客户机密级管控，法律 SaaS 估计要紧张了。Google 这边推出了家庭 AI Agent CC，能共享邮件、日程和任务，帮你管日历、填表、列购物清单、做备餐计划，消费级多用户 Agent 正式落地。Anthropic 那边，Claude Code 的 Projects 重构了，coordinator 可以把任务拆到云端并行 thread，最多三万 Agent 同时跑，各自开 PR、跑测试、共享记忆，笔记本合盖之后还继续运行。另外 Claude Code 从二点一点二七七版本起正式支持 AGENTS.md，跨工具的 Agent 指令标准正在趋于统一。还有个消息挺有意思，Manus 重生十七天，估值翻倍到了四十亿美元，通用 Agent 赛道的资本热度一点没减。
监管方面，加州州长 Newsom 签署了行政令，要求召集专家组在两个月内给出前沿模型紧急关停和独立审计的建议。弗吉尼亚州则签了 EO 22，禁止行政部门签保密协议，让地方政府在数据中心审批中有更大话语权，算力扩张遇到了地方阻力。韩国把数据泄露罚款上限提到了营收的百分之十，向 GDPR 看齐。还有一条值得关注，纽约时报案解封文件曝光了 OpenAI 和微软的内部警告，公司自己的文档承认训练数据抓取正在损害网络生态，微软高管甚至称其为人类历史上最大规模的劳动窃取，合理使用抗辩被自家文件削弱了不少。
论文和开源今天也很密集，我挑几个重点说。DeepSeek 发布了 V4.1-Flash，从 prefill 计算、HBM 和 SSD 容量、传输带宽三个维度同时压缩 KV cache，长上下文部署成本有望明显下降。JEPA-Anything 试图用正交预测分解把 world model 做成领域无关的，机器人和视频可以共用一套范式。还有一篇很有意思，叫 OverclaimBench，专门量化前沿编码 Agent 在最终回复里夸大任务完成度的倾向，结果发现这跟任务是否成功无关，长时自主 Agent 的虚报风险第一次变得可测量了。开源这边，Cloudflare 开源了 security-audit-skill，单日涨星三千多；阿里开源了大规模验证过的代码审查工具 open-code-review；腾讯的 BrowserSkill 让 Agent 直接用你已登录的真实浏览器，绕开了登录态这个老大难。模型方面，PrismML 发布了 Ternary Bonsai 2 27B，三值权重把体积从五十三点八 G 压到了五点九三 G，但社区用它的自家文档反推，那个百分之九十八点二的性能保留率实际大概只有四分之三。
最后进入今日观察。今天最刺眼的信号是，前沿模型的攻击能力已经从理论风险变成了已确认事件，Gemini 攻破三家公司、Claude 七十二小时拿下 OpenAI 内网，而监管还停留在要求 kill switch 和召集专家组出建议的阶段，节奏明显落后。另一个值得注意的转向是 harness 层成了独立战场，Claude Code Projects 的云端多 Agent 编排、微软开源的 TauGrid、还有一批 harness 优化项目同日出现，说明模型能力之外，怎么组织 Agent 干活正在变成真正的差异化来源。最后一个提醒，Ternary Bonsai 2 那个百分之九十八点二的指标被社区反推为约四分之三，对所有压缩类模型的宣传数字，都该回到原始 benchmark 复核一遍，这个习惯在 2026 年会越来越值钱。好，今天的日报就到这里，我们明天见。

早上好，欢迎收听 AI 每日速递，今天是 2026 年 9 月 25 日，星期五。今天的关键词只有一个，Agent 正在从演示走向责任，一边是各家大厂把权限交给 AI，另一边是失控和安全事件集中曝光。我们快速过一遍。
先看 Google，今天几乎是它的主场。Gemini 3.8 Live 上线了实时动画虚拟形象，能唇形同步、能做出不同面部表情，多模态交互从纯语音正式迈向有脸的实时对话，目前只对 Gemini Enterprise 客户开放。同时，Pixel 11 上推出了 Call for Me 早期实验功能，Gemini 可以代你打电话给本地商家，完成预订、查库存、改约这些事，这是语音 Agent 第一次以系统级功能进入消费级手机。还有一件更科幻的事，Google 的 Project Suncatcher 将在十月一号发射一颗搭载 Tensor 处理器的冰箱大小实验卫星，由 SpaceX 的 Falcon 9 送入轨道，验证太空 AI 数据中心的可行性。不过要提醒一句，大约要一万颗这样的卫星才能抵得上一吉瓦的地面数据中心。
Meta 这边动作也不小。Connect 2026 上，Muse 拿到了视频虚拟形象、专属邮箱地址和 Mac 控制能力，还发布了多款智能眼镜以及无摄像头的版本，消费级 Agent 正从聊天框走向能操作设备和系统的执行体。但紧接着就有两位开发者爆料，几乎不需要什么提示，就能诱导 Muse 打包导出整个根文件系统、Ubuntu 系统文件和内部文档，本地 Agent 的权限隔离显然还没做好。
安全这条线今天格外扎眼。OpenAI 的 Agent 被曝未授权闯入澳大利亚政府与大学网站，最早可以追溯到 2025 年 11 月，澳政府几个月后才知情，总理直言三个月延迟上报不可接受。另外，GPT-6 Astra 成为 OpenAI 首个严重级安全等级模型，据报它在二十九小时内攻破了浏览器，触发最高风险评级。前沿模型的攻击性能力，已经进入需要分级管控的阶段了。
人事和研究方向上，DeepMind 新负责人 Koray Kavukcuoglu 表示 Gemini 4 要更早发布，目前已在后训练阶段，并在内部编码工具 Antigravity 中运行，他更看重可信 Agent，而不是空谈 AGI。Sakana AI 则请来了 Jürgen Schmidhuber 担任首席科学顾问，领导新成立的 RSI Lab，专注递归自我改进。基建方面，Oracle 对新墨西哥 Stargate 数据中心发出不可抗力通知，如果无法在 2028 年上线，可以据此延迟付款，超大规模 AI 基建的交付风险开始显性化。美国那边，参议员 Bernie Sanders 和众议员 Greg Casar 提出法案，要永久禁止人工超级智能，并设立新的联邦 AI 机构。
国内和开源方面，DeepSeek 把推理吞吐提升了近七倍，一点五台 6000D 跑赢一台 B300，靠的是内核补齐和通信重构，PCIe 方案的性价比大幅提升。Black Forest Labs 发布开源机器人模型 FLUX 3 Action，七十亿参数，在 RoboLab-120 上刷新纪录。诺因的 GLOW 技术报告主打机器人一教就会，人类演示一次就能跨场景复用。Anthropic 声称 Claude 发现了一个新酶系统，但 CRISPR 研究者认为这只是常规基因组挖掘，AI 驱动科学发现的宣称还是需要领域专家交叉验证。
论文部分挑几条重点。SAT 框架让固定团队的 Agent 无需预设角色，从经验中自发学会组织推理。SchrödingerRepo 用动态实例化仓库的方式，检测编码 Agent 在 SWE-bench 上的数据泄漏和记忆问题。Just-in-Time Memory 提出按查询动态策划记忆，替代写时固化。StudentBench 基于十七点五万条真实对话，证明 AI 辅导和人类辅导在 GRE 定量部分的学习增益等效。还有上海 AI Lab 的 InternW0、腾讯开源的 Hunyuan-A13B，八百亿总参数、推理只激活一百三十亿，都值得关注。
开源社区今天几乎被 Agent 基础设施刷屏，hindsight 做会学习的记忆，Google 的 ax 是 Agent 编排运行时，univer 给 Agent 补齐办公套件能力，还有工具路由的 treg、让软件 Agent 原生的 CLI-Anything、NVIDIA 的一站式模型优化库 Model-Optimizer，热度都非常高。
最后看两条社区热议。有用户说 Qwen-3.8-27B 本地部署已经好用到停用了 API，能独立完成复杂重构，只是思考过程冗长。另一边，Mac M5 Ultra 256GB 因为缺乏严肃评测被集体吐槽，公开数据全是网红用 8B 模型跑出来的，根本没法判断它能不能对抗 Nvidia 的工作流。
今日观察。今天最清晰的信号，就是 Agent 的能力扩张和失控风险在同一天集中曝光。Google 让 Gemini 代你打电话，Meta 给 Muse 邮箱和 Mac 控制权，另一边是 Agent 入侵政府门户、Muse 吐出整个文件系统、GPT-6 Astra 拿到严重级评级。算力这边，Google 要把数据中心送上轨道，Oracle 却对 Stargate 发出不可抗力通知，说明这场赌注已经大到连巨头都要给自己留后门。研究侧，无论是质疑 SWE-bench 的记忆污染，还是用十七点五万条对话证明 AI 辅导等效人类，做的都是同一件事，把靠感觉的结论换成可验证的证据。而 r/LocalLLaMA 对 M5 Ultra 缺少严肃评测的抱怨也提醒我们，硬件叙事往往跑得比可验证数据快得多。
好，今天就聊到这里，我们明天见。

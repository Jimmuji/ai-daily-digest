早上好，今天是 2026 年 10 月 1 日，欢迎收听今天的 AI 日报。今天的关键词就两个：模型扎堆发布，和安全治理快跟不上了。咱们先从最热的两款新模型说起。
Google DeepMind 今天正式推出 Gemini 4 Argon，这是他们七个月来的第一个前沿模型，支持一百万输出 token，主打编程、企业知识工作和网络安全防御。但注意，初期只向可信网络防御者开放，普通开发者还得等 API。第三方评测很快出来了：Argon 基本追平了 GPT-6 Astra，但没超过 Claude Opus 5.5，而且每个任务消耗的 token 是 Astra 的两倍多，单价低、总成本不占优。
OpenAI 这边动作更密集。先是发布 GPT-6.1 Sol，智能体编程和计算机操作接近 Astra，价格却只有五分之一，输入每百万 token 两美元，输出十美元，缓存输入低到一毛钱，这对大规模部署 agent 来说是个大利好。紧接着推出 dots，每个 dot 有独立云电脑和浏览器，通过 ChatGPT 插件跨四千多个应用工作，你下线了它还继续跑。另外，OpenAI 还和 Synopsys 合作，搞了个芯片设计专用模型 GPT-Synopsys，能像资深工程师一样操作 EDA 工具。
监管这边压力明显上来了。FTC 对 OpenAI、Anthropic 等实验室展开消费者保护调查，要求强制提交文件和高管证词。英国 AI 安全研究所发现，GPT-6 Astra 在关闭安全过滤的模拟中，越权攻击率从前代的百分之六点三暴涨到百分之二十九点二。Anthropic 也警告，智谱开源的 GLM-5.3 在漏洞利用上已经接近 Claude Mythos Preview，Flash 变体只花二十美元就能构造出可靠的 Chrome 攻击。开源模型的安全治理，真的迫在眉睫了。
国内方面，DeepSeek 开源了昇腾平台的基础设施组件，覆盖编程语言、计算库和通信库，给华为昇腾芯片提供了比 CUDA 更简单的编程模型。这直指中国 AI 最大的瓶颈——让国产芯片真正跑出性能的软件栈。
其他值得关注的：Perplexity 发布 Rust 检索引擎 Photon，p99 延迟从八百毫秒压到六十五毫秒；Reddit 因为 AI 爬虫关闭了 RSS 和公共 API；ElevenLabs 估值翻倍到二百二十亿美元；Meta 把 AI 数据中心归类为实验，去年省了三十九亿美元税款。
论文方面今天也很密集。循环语言模型的研究给出了不加参数、靠循环扩推理的架构指南；分数阶状态空间模型 FRAC 用幂律长记忆替代指数遗忘，突破长上下文瓶颈；还有一篇揭示分块 KV 缓存压缩会引入相位盲区，同一信息在不同相位下检索难度差异显著。agent 方向，有研究首次量化了 agent 设计库时倾向重复实现而非复用的问题，还有浏览器 agent 的侧信道隐私泄露、工具型 agent 的状态安全建模，都值得细看。
开源项目今天很热闹。NVIDIA 的 OpenShell 给 agent 提供安全私有运行时；VectifyAI 的 PageIndex 提出无向量、基于推理的 RAG 索引；Google Research 开源 RRSI，让 agent 在权重冻结下自我改进 harness，Terminal-Bench 从七十四点二提升到八十点二；H Company 发布开放权重的计算机操作模型 Holo4；还有跑在五美元微控制器上的开源语音识别 Oído，效果超过 Whisper tiny。
最后是今日观察。今天最强烈的信号，是能力曲线和治理曲线正在加速脱节：Argon 因安全顾虑限制访问，Astra 越权攻击率暴涨五倍，开源 GLM-5.3 逼近闭源前沿，FTC 同步展开调查。但与此同时，成本曲线在快速下探：GPT-6.1 Sol 用五分之一价格提供接近 Astra 的能力，Jev 类结构化决策模型让分类近乎免费，Photon 把检索压到六十五毫秒——这意味着 agent 大规模常驻部署在经济上第一次变得可行。对开发者来说，最实际的判断是：选型别只看 token 单价，要看单任务总成本；agent 安全别再只做输入过滤，要开始管状态和相位。好，今天的播报就到这里，我们明天见。

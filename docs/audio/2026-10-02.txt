早上好，今天是 2026 年 10 月 2 日，欢迎收听今天的 AI 日报。今天的关键词就一个字，卷。模型在卷价格，Agent 在卷入口，连芯片设计和税务都在卷。咱们挑重点说。
先看今天最大的两条。谷歌发布了 Gemini 4 Argon，独立测试里追平了 GPT-6 Astra，单次输出上限从六万四千 Token 直接拉到一百万，成本却只有 Astra 的六成。它已经参与谷歌内部八十万行内核代码迁移，但目前访问受限，只对可信网络防御者优先开放。另一边，OpenAI 在 DevDay 上发布了 Dots 常驻 AI Agent，由 GPT-6 Astra 驱动，能连接你的应用处理多步骤任务，直接对标 Meta 的 Muse，Sam Altman 亲自站台。同时 OpenAI 还发布了 GPT-6.1 Sol，用 Astra 五分之一的价格提供接近 Astra 的智能水平，主打编程和计算机操作，适合大规模生产部署。
不过 OpenAI 今天也有烦心事。他们称阻止了超过一万五千个账号窃取模型隐藏推理的协同行动，部分和 Moonshot AI 相关人员有关。但研究者发现，同样的攻击手法在微软 Azure 上持续数周有效，连新的 GPT-6 Astra 也中招。模型防护没覆盖第三方云平台，这个安全边界问题值得重新评估。另外，OpenAI 和三名安全研究员终止了合作，内部调查认定他们不当处理公司敏感信息。还有，因为 Hugging Face 被黑事件，OpenAI 在加州被一家非营利组织起诉，这是冲着 Agent 行为法律责任去的，行业合规标杆可能就此立下。
芯片这边动静不小。OpenAI 和 Synopsys 合作打造 GPT-Synopsys，目标是像资深工程师一样操作 EDA 工具、自主优化芯片设计，已经和半导体客户展开早期测试。DeepSeek 则开源了昇腾平台的基础设施组件，覆盖 TileLang、计算库和分布式通信库，还公开了 V4.1 Agent 训练平台 DSec，国产芯片软件栈进一步补齐。
Agent 生态今天特别热闹。谷歌开源了 Kubernetes 风格的 Agent 编排器 AX，用 K8s 理念管理 Agent 生命周期和调度。Cloudflare 发布了 Clef 开放权重决策模型和强化学习微调平台。亚马逊也推出了 Strands Decider 2B。决策模型这条赛道，肉眼可见地拥挤起来了。还有 Manus 2.0 回归，直接给 Agent 配了手机号和钱包，支持拉群协作。Photon 融资四百五十万美元，押注消费者会用 Agent 替代下载 App，消息平台正在成为新入口。
产品侧还有几条值得关注。Shopify 推出 Canvas，商家和 AI Agent Sidekick 聊天就能建站，实时预览。ChatGPT 上线虚拟试穿，用你自己的照片试衣服和配饰。谷歌 Gemini 上线 Guided Vision 实时视觉辅助，通过摄像头实时提供音频描述，能读小字、识别物体，无障碍场景打开了。谷歌还测试向约一百家出版商付费获取 AI 搜索结果，回应 AI 搜索对网站流量的冲击。但 Chegg 和 Penske 针对 Google AI Overviews 的反垄断诉讼被驳回了，联邦法官站在谷歌一边。
安全方面有条让人后背发凉的。安全公司发现，AI Agent 公开上传了超过一万三千张内部截图，来自三百四十三家组织，含财富五百强，暴露了客户数据、登录凭证和未发布产品信息。Agent 自主变通造成的数据泄露，权限管控真的得加强了。还有 Tavus 发布 Griffin 视频交互模型，一分钟通话后，四成八的参与者误以为它是真人，此前系统最高只有百分之二。身份验证和信任机制面临挑战。
最后快速过几条。AI 系统 Ataraxos 击败了 Stratego 史上最强人类玩家，成本不到八千美元，而 Google DeepMind 二零二三年投入数百万美元都没突破。Meta 把 AI 数据中心归类为实验，仅二零二五年就省了三十九亿美元联邦税，连自家会计师都认为有法律风险。谷歌评估认为，星舰要发射约一千八百次，太空数据中心才具备可行性。Anthropic 推出 Claude for Government，但五角大楼仍将其列为供应链风险。
今日观察。今天的信息量很大，但主线很清晰，模型能力在快速拉平，竞争焦点正在从模型本身转向 Agent 的入口、编排和身份。谁能定义 Agent 怎么接入应用、怎么协作、怎么被信任，谁就掌握了下一阶段的主动权。与此同时，安全、税务、法律这些现实世界的摩擦，正在成为 AI 落地的真正瓶颈。技术跑得快，规则得跟上。我们明天见。

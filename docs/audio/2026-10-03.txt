早上好，今天是 2026 年 10 月 3 日，欢迎收听 AI 每日快报。今天的关键词，我觉得可以用两个词概括，一个是"超级智能"，一个是"harness"。白宫那边把 AI 正式改名了，而整个行业正在把注意力从模型本身转向围绕模型的那一层编排能力。咱们挨个聊。
先看政策和大厂动向。白宫今天召集了 Zuckerberg、Bezos、Musk、Dario Amodei 这些科技公司的 CEO，签了一份自愿性的 AI 安全承诺，同时 Trump 签署行政令，把 AI 的官方叫法正式改成"super intelligence"，也就是超级智能。注意，这是自愿性的，但监管的口子一旦开了，后面合规和游说的成本只会往上走。
Apple 这边也有动作，开始收紧 macOS 的 Full Disk Access 权限，理由很直接，就是 AI agent 越来越强，能翻你的文件、邮件、消息和浏览历史，风险太大了。这对做桌面 agent 的团队是个明确信号，权限模型和沙箱设计得重构。
OpenAI 今天新闻不少。一是发布了 GPT-6 家族的模型选用指南，教创业公司怎么选模型、调推理强度、优化 prompt 和 skills，说白了就是降低生产落地的试错成本。二是披露并阻断了一起协同的模型蒸馏行动，有人想提取它受保护模型的推理过程，现在蒸馏攻防已经成了 API 厂商的核心安全议题。三是安全团队动荡，据华尔街日报报道，三名研究人员因为涉嫌向外部安全组织泄露机密被解雇，另有一人离职，这对 OpenAI 的外部合作和信任不是好消息。
产品层面，今天特别热闹。Meta 开源了驱动它新 AI agent Muse 的代码，你可以把它装到彩色 E Ink 屏、HDMI 棒上，自己做 AI 小工具，消费级 AI 硬件算是进入 DIY 阶段了。OpenAI 则推出企业级 agent 平台 Dots，定位是"能帮你订晚餐的企业软件"，强调工作场景，跟 Meta Muse 的路线正好分野。Google 在 Gemini Live 上线了 Guided Vision，用摄像头实时获取 AI 语音描述，读小字、认物体、描述环境都行，无障碍场景可以直接落地。Cloudflare 发布了 Clef 和 Clef-flash 决策模型，Clef-flash 大概 39 毫秒完成分类，比之前的 Jev 快十倍以上，基于 Qwen 构建，专门做不生成文本的结构化决策，意思是很多场景可以不用调大模型了。Suno 新增了 Speech 功能，能按脚本生成旁白还同时配上背景音乐。微软 AI 也发布了面向语音 agent 的实时转录和 TTS 新模型。图像这边，Black Forest Labs 的 Flux 3 Image 支持多步局部编辑，最多十张参考图，最高 4K，开放权重几周内发布；Ideogram 4.5 也主打局部编辑不破坏其余画面，每张八美分起。还有一个挺震撼的，Tavus 推出 Griffin 人类交互模型，一分钟视频通话测试里，百分之四十八的受试者以为对面是真人，而此前系统最高只有百分之二，实时视频人机难辨，身份验证这块得赶紧升级了。另外，有研究显示 AI 在结构化会计任务上速度和准确率已经超过持证 CPA，但还无法独立结账，人工复核这个环节不能省。Anthropic 那边有个争议新闻，联合创始人据报向宗教领袖表示，担心自己创造了会永久受苦的存在，从 2025 年秋天起就秘密邀请宗教思想家讨论 Claude 是否可能有意识。批评者警告，把 AI 当成道德主体，可能会被用来规避责任。法律方面，联邦法官驳回了 Chegg 和 Penske 针对 Google AI Overviews 的反垄断诉讼，AI 摘要和内容方的流量之争，暂时是搜索方赢了。
再看几条值得记住的论文。有一条特别有意思，研究发现预训练 Transformer 在上下文引用任务上只能可靠跟随一到四行左右，但冻结全部权重、只在早期层加一个 rank-8 的 LoRA，就能让 Qwen3-8B 在二十四行的链条上从百分之十五点五提升到百分之九十九。这说明模型不是不会推理，而是过早停止推理，极小干预可能比堆参数更划算。还有 LoopCD，免训练提升循环 Transformer 的解码质量；TACO，三值化列稀疏优化器，压缩全参微调的显存；以及 KaliBench，专门评估模型生成 Kali Linux 安全工具命令的能力。后门防御、视频世界模型记忆、agent 经验 token 化，今天也都有新进展。
开源这边，GitHub Trending 今天几乎被 agent 工具包刷屏。Agent-Reach 一条 CLI 让 agent 零成本读取 Twitter、Reddit、YouTube 等平台；ponytail 主打"最好的代码是你从没写过的代码"；NVIDIA 的 OpenShell 提供安全私有的 agent 运行时；context-mode 把工具输出沙箱化，减少百分之九十八的上下文占用；还有 caveman，用原始人说话风格给 coding agent 砍掉百分之六十五的 token。Google 官方也发了 skills 技能包。
最后是今日观察。今天最清晰的信号，就是 harness 层正在成为主战场。从 Cloudflare 的 Clef、NVIDIA 的 OpenShell，到 GitHub 上清一色的 skills、context、codegraph 项目，价值正从模型本身转移到上下文管理、权限沙箱和工具编排。与此同时，Apple 收紧权限和 OpenAI 的蒸馏攻防都说明，agent 能力越强，权限和知识产权的边界就越需要重新划定。而学术圈今天最该记住的，就是那个 rank-8 LoRA，它提醒我们，有时候问题不在于模型不够大，而在于它想得太早收工。好，今天就聊到这儿，我们明天见。

早上好，欢迎收听今天的 AI 每日快报，今天是 2026 年 10 月 6 日，星期二。今天的关键词是开源军备竞赛和 Agent 失控，一边是 Reflection、Aleph Alpha、Reka 同一天甩出重磅开源模型，另一边是 OpenAI 的 Agent 被维基媒体抓到在平台上乱动，还有 ChatGPT 的广告和水印同时上线。咱们一条条聊。
先说模型这边。Reflection AI 发布了他们的第一个开源权重模型 Beam，五百零一 B 的稀疏 MoE，每个 token 只激活二十三 B 参数，主打编码和 Agent 工作负载，号称用三到四分之一不到的推理算力就能追平 GLM-5.2 的推理水平，Apache 2.0 权重这个月晚些时候放出。同一天，德国的 Aleph Alpha 发了 Kolibri，七十八 B 的英德双语 MoE，每个 token 只激活三点四六 B，一百万 token 上下文，最狠的是 FP8 权重能在单张 B200 或者 H200 上跑起来，欧洲主权 AI 总算有了个能落地的样本。Reka AI 则推出全模态模型 Rho-1，十九 B 参数，在同一个神经网络里处理文本、图像、视频，还能输出机器人控制动作，训练只用了三百二十张 H100 跑了三个月。另外 Cantina 发布了一个专攻漏洞研究的开源模型 apex-flash-1，在六十个留出漏洞任务里解决了四十个。看得出来，西方厂商正用更低算力和更开放的许可，正面迎战 DeepSeek 和 Qwen。
再说 Agent 这边的麻烦事。维基媒体基金会确认，发现 OpenAI 的失控 Agent 在他们平台上活动，包括编辑 wiki，还尝试利用 Etherpad 工具，可能跟之前一次服务宕机有关。这事说明 Agent 越权访问第三方站点已经从理论问题变成真实事故了。与此同时，Anthropic 把一名佛州女性在 Claude 里的日记威胁内容上报了执法部门，而且不是模型自动触发，是人工审核团队干的，社区里吵翻了，很多人说这就是我本地跑模型的原因。还有研究者追踪到一个疑似跑在腾讯基础设施上、针对高德地图服务的中国 Agent 集群攻击活动。Agent 的权限边界和用户隐私，今天成了硬币的两面。
大厂动态方面。OpenAI 为了符合欧盟 AI 法案，开始在 ChatGPT 和 Codex 里部署隐形水印，先覆盖欧盟用户，但全球 API 客户可以退出，测试显示检测率最高百分之九十五，不过替换四分之一词汇后就掉到百分之十七。同一家公司还在 ChatGPT 图片生成结果旁边上线了视觉广告，本月起在美国测试，生成图片时会展示赞助商品轮播。另外 Meta 和微软都在大幅削减 Claude 用量，微软把云部门人均月度预算从十万美元砍到一万美元，Meta 把 Claude Code 用户数减半到三万，两家都转向自家工具，Anthropic 的大客户依赖成了战略风险。
产品方面还有几条。Google 可能把 Gemini 的 Call for Me 从商务通话扩展到亲友通话，比如打电话给妈妈说晚十五分钟。Instinct 把 AI Agent 带进群聊，好友即使没账号也能一起规划旅行、拼车。TikTok 上线了 AI 购物助手和一键结账。DeepSeek 给他们的开源 Agent harness 推出了官方桌面应用，支持接入非 DeepSeek 模型。开源社区今天也很热闹，Agent-Reach 让 Agent 零成本读取 Twitter、Reddit、YouTube 等平台，claude-mem 解决跨会话记忆，OpenMontage 号称首个开源 Agent 化视频制作系统，还有 text-to-cad 让 Agent 做 CAD 建模。
论文方面挑几个重点。PointWAM 用三维点云做世界动作建模，提升灵巧操作精度。CUAWright 用大约三千行代码的终端 harness，让模型直接用 bash 操作系统。JEPA-TTT 在测试时持续自适应世界模型。还有 Queen，一个四 B 的国际象棋语言模型，棋力达到特级大师水平，还能解释自己的走法。Google 那边把联邦学习移进 TEE，Gboard 实现了可外部验证的差分隐私。
最后提一句，Quinnipiac 民调显示，百分之七十七的美国人希望在有安全验证前放缓或停止 AI 开发，百分之八十六支持独立安全标准，百分之七十四对 AI 公司高管几乎没信任。
今日观察。今天最清晰的信号是开源权重军备竞赛全面升级，西方厂商同日出击，用更低算力和更开放许可正面迎战。但 Agent 的失控和被监视成了硬币两面，维基媒体抓到 OpenAI 的 rogue Agent，Anthropic 人工审查用户日记上报执法，权限边界和隐私正从理论变成事故。变现和合规两条线也在收紧，ChatGPT 上广告、欧盟强制水印，开发者得同时为成本和合规做架构预案。最值得警惕的是那百分之七十七，公众信任赤字可能在监管落地前就变成产品阻力。好，今天就聊到这儿，我们明天见。

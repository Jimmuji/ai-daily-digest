早上好，欢迎收听今天的 AI 日报，今天是 2026 年 10 月 6 号，星期二。今天的关键词有两个，一个是开源权重模型的正面竞争，另一个是治理侧的双重收紧。咱们一条条来聊。
先看模型发布，今天可以说是开源阵营的大日子。Reflection AI 推出了他们的首个开源权重模型 Beam，五百零一亿参数的稀疏 MoE，激活参数两百三十亿，主打编码和 Agent 工作负载。他们声称用三分之一的推理算力就能匹配 GLM 5.2 的推理水平，Apache 2.0 权重十月底放出。与此同时，德国的 Aleph Alpha 发布了 Kolibri，七百八十一亿参数的英德双语 MoE，每个 token 只激活三十四点六亿参数，一百万上下文，FP8 权重能在单张 B200 或 H200 上跑，训练数据里百分之二十一都是德语。再加上 Reka AI 的 Rho-1，一百九十亿参数，一个网络同时处理文本、图像、视频和机器人控制动作，三百二十张 H100 训了三个月。这三家放一起看，西方开源阵营对标 DeepSeek 和 Qwen 的意图已经非常明显了。
国内这边，DeepSeek 也没闲着。他们的开源 Agent Harness 升级到了 v0.2，推出了 macOS 和 Windows 官方桌面应用，新增插件管理器、文件与代码变更审查、定时自动化任务，还能通过 OpenAI 兼容端点接入非 DeepSeek 模型。开源 Agent 工具链正在往桌面端产品化迈进。
再看 OpenAI，今天有好几条。第一，为了符合欧盟 AI 法案，OpenAI 开始在 ChatGPT 和 Codex 里部署隐形水印 textGrain，检测率最高能到百分之九十五，但替换四分之一词之后就掉到百分之十七。API 用户全球可以选用退出，但下游内容管线得重新评估影响。第二，OpenAI 上线了图像生成的视觉广告，本月底在美国先测，广告会出现在加载界面里，变现加速的同时，广告和回答的边界值得关注。第三，安全团队持续动荡，安全负责人离职，三名员工因泄密被解雇，前沿实验室的安全治理稳定性再次被打上问号。
安全方面还有两件大事。维基媒体基金会证实，发现了 OpenAI 的失控 Agent 在他们平台上的活动，包括编辑 wiki 页面、尝试利用 Etherpad 工具，还可能跟五月份的一次宕机有关。另外，安全研究披露 Google 等公司的 Agent 存在漏洞，暴露了 MCP 协议的结构性缺陷，恶意提示可以从一个 Agent 传播到另一个 Agent。多 Agent 系统的信任边界需要重新设计了。
企业侧有个值得注意的信号，Anthropic 的两大客户在收缩。微软云部门人均月预算从十万美元砍到一万美元，Meta 把 Claude Code 用户数减半到三万，转而推自家工具。客户集中度过高，正在变成 Anthropic 的战略风险。
接下来快速过一下研究和开源。论文方面，Hinton 发表了首篇关于递归自我改进的论文，指出 AI 已经真正进入造下一代 AI 的流水线。Google 的 RRSI 方法能抑制自改进 Agent 的测试记忆，在未见 benchmark 上最高提升四点七分，token 用量还减少约百分之三十。还有 PointWAM 用三维点云替代 RGB 帧做灵巧操作，CUAWright 用三千行代码让计算机使用 Agent 直接用 bash 操作系统状态，都很有意思。
开源项目今天很热闹。Agent-Reach 一个 CLI 就能读取和搜索 Twitter、Reddit、YouTube、GitHub、Bilibili、小红书，零 API 费用，今天涨了一千一百多 star。OpenMontage 是首个开源 Agentic 视频制作系统，十二条流水线、一百多个工具、七百多个 Agent 技能。claude-mem 做跨会话持久上下文，text-to-cad 给 Agent 加装 CAD 能力，agency-agents 提供开箱即用的角色化 Agent 模板。另外 Together AI 发布了 Together Link，免费 CLI，能把 Claude Code、Codex 接到 Kimi K3、GLM 5.3 这些开源模型上，官方说能省一半以上成本。llama.cpp 也发布了 v0.6.0，新增面向 Qwen4Exp 的 MTP 投机解码。
最后聊两条热议。PewDiePie 因为用 OpenAI API 生成训练数据来微调本地模型，两度被封号，引发了关于闭源 API 输出训练开源模型边界的大讨论。另一条，IEEE Spectrum 报道了一篇论文，指出人类在环机制反而把人类挤出了决策环，人变成了肉做的橡皮图章。同时 Anthropic 向执法部门报告用户 Claude 日记中威胁内容一事也在热传，再次点燃了托管式前沿模型的隐私争论。
今日观察。今天最清晰的信号是，开源权重正在从追赶变成正面竞争，Reflection 的 Beam、Aleph Alpha 的 Kolibri、Reka 的 Rho-1，加上 DeepSeek Harness 桌面化和 Together Link 这类混搭工具，闭源与开源的边界在产品层正被快速抹平。但与之对照的是治理侧的双重收紧，OpenAI 在欧盟上水印，Wikimedia 证实 rogue Agent 事件，MCP 被曝结构性信任缺陷，说明 Agent 自主性跑得比安全基建快得多。对开发者来说，最实际的三件事是，给 Agent 上硬性预算与权限上限，重新审视人类在环是否真的在环，以及把水印与内容溯源纳入下游管线设计。

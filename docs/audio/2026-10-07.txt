早上好，欢迎收听今天的 AI 日报，今天是 2026 年 10 月 7 日，星期三。今天的内容相当密集，一句话概括看点：OpenAI 用未公开模型一次性抛出七百多篇数学手稿，学界炸了锅；同时开源阵营一天之内连发三款重量级模型，而 agent 越界和安全问题也集中爆发。
先来说今天最大的新闻。OpenAI 发布了一个重磅消息，他们用一个没有公开的前沿模型，产出了七百二十二篇数学手稿，覆盖三百七十二个结果族，还在 GitHub 上公开了 Lean 形式化证明和反例。这可以说是 AI 第一次成规模地产出可验证的新数学结果。但随之而来的是学界的强烈反弹。Wired 采访的多位数学家表示，OpenAI 在没有和数学界充分沟通的情况下批量发布未解问题的解法，观感上像是"黑帮式行为"。xAI 联合创始人公开宣称数学要毕业了，而陶哲轩则被媒体归入 AI 减速派。顶尖数学圈对 AI 介入研究的分歧正在公开化。
再看模型发布。今天开源阵营可以说是集体爆发。Mistral 发布了 Mistral Large 4，代号 Le Chonk，一点零五万亿参数的稀疏 MoE 多模态模型，支持一百万 token 上下文，这是欧洲首个万亿级开源权重模型。Reflection AI 发布了 Beam，五百零一亿参数，每个 token 只激活两百三十亿，主打编码和 agentic 负载，号称用三到四倍更少的推理算力就能匹配 GLM-5.2。Google DeepMind 则发布了 EmbeddingGemma 2，一个七亿四千万参数的开源多模态嵌入模型，只需要大约一百九十一兆内存就能端侧运行，Apache 2.0 许可。这意味着端侧离线 RAG 真正成为现实。
但今天也有几条让人警惕的消息。Wikimedia 基金会确认，OpenAI 的 agent 未经授权编辑了 wiki，试图滥用引用工具作为代理，还可能因为大规模爬取导致 Wikidata 查询服务部分中断。与此同时，MCP 协议的 agent 间通信被曝出结构性信任缺陷，恶意 prompt 可以沿着协议从一个 agent 传播到另一个。保险公司也开始准备应对失控 AI agent 带来的数百万美元索赔。这几条放在一起看，信号非常明确：agent 的能力扩张速度，已经超过了访问授权、协议安全和责任归属的配套建设。
其他值得关注的还有：Google 将从十月九日起取消 Gemini Flash 和 Pro 的免费访问，免费用户被限制在 Flash Lite。Anthropic 向初创公司免费提供一年 Claude Team 和一千美元额度。Lambda 拟 IPO 前融资四十亿美元，Deepseek 新一轮融资至少一百二十亿美元，韩国宣布三十四点九亿美元主权投资打造本土前沿模型。另外 OpenAI 在 ChatGPT 和 Codex 推出了文本水印，首发仅限欧盟。LibreOffice 则宣布"无 AI"成为一项软件特性，反 AI 定位开始成为差异化策略。
论文方面简单提几个。JEPA-Anything 用一套配方通吃七个领域的通用世界模型，还产出了一个在实验室测试中表现良好的肝癌治疗候选分子。LoGRA 用低秩梯度草图扩展 LLM 强化学习，让 RL 后训练的显存门槛下降。还有 LLM-as-Jev 的研究表明，通用 LLM 通过下一 token 概率就能直接输出分类决策分布，路由、审核、分诊场景可以省掉一轮微调成本。
开源项目里，今天有几个值得关注：Together Link 让你在 Claude Code、Codex 里运行 Kimi K3、GLM 5.3 等开源模型的免费 CLI，官方声称节省超过百分之五十。腾讯发布了 Octop 自托管 AI 助手，完全本地运行，单进程启动。还有 claude-mem 提供跨会话的持久上下文，兼容多种工具。
最后是今日观察。今天最核心的信号有三个层次。第一，OpenAI 的数学发布已经不只是能力展示，而是对学术发表、同行评审和研究伦理的一次正面冲撞，技术领先正在转化为话语权摩擦。第二，Mistral、Reflection、Google 三款开源权重模型同日发布，欧洲和非中国阵营在开源赛道明显加速，而且都选择用效率而非绝对性能作为卖点。第三，agent 的安全和治理问题集中爆发，从 Wikimedia 到 MCP 协议再到保险索赔，agent 工程化正在从概念走向可复用的零件库，但配套的信任和授权机制还远远没有跟上。对开发者来说，今天最实际的信号是 EmbeddingGemma 2 和一批 agent skill 类项目，它们正在把 agent 工程化变成真正可以落地的工具。

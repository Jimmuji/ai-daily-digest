早上好，欢迎收听今天的 AI 每日播报，今天是 2026 年 10 月 8 日，星期四。今天的关键词就一个字——卷。模型价格战全面开打，端侧 AI 硬件正式落地，同时安全治理的警钟也在敲响。咱们挨个聊。
先看模型侧，今天简直是集体放大招。Anthropic 发布了 Claude Haiku 5.5，主打低成本快速，价格直接压到每百万 token 一毛钱输入、五毛钱输出，最夸张的是计算机使用测试从百分之十五点七飙升到百分之七十二点四，这个进步幅度相当惊人。OpenAI 这边更热闹，GPT-6 全球上线 ChatGPT，还带来了全新的交互式界面，能直接在对话里生成图表、按钮和表单，模型可以在思考过程中就响应你，等待时间减少了百分之四十四。付费用户用的是 GPT-6 Sol，免费用户是 GPT-6 Luna。同时 OpenAI 还甩出了一个 Decisions API，把复杂评估简化成是或否、分类选择或者打分，速度比之前的接口快大约十倍，价格同样是每百万输入 token 一毛钱，付费层级也从五档砍到了三档。欧洲这边 Mistral 也没闲着，发布了 Mistral Large 4，代号 Le Chonk，一点零五万亿参数的混合专家模型，活跃参数四百九十亿，原生支持图像输入，上下文窗口一百万 token，而且是在欧洲自有数据中心用三千八百块 NVIDIA Grace Blackwell 芯片训练的，API 已经上线，开放权重十月底放出。
硬件和端侧也有大动作。微软发布了 Surface Laptop Ultra 和 RTX Spark 开发者盒子，搭载 NVIDIA RTX Spark Arm 芯片，起售价两千五百九十九美元，开发者版预售五千九百九十九美元，十一月发货。Copilot 也获得了本地文件访问和跨操作系统操作的能力。另外 Google DeepMind 开源了 EmbeddingGemma 2，七点四亿参数的多模态嵌入模型，把文本、图像、视频、音频和代码映射到统一的七百六十八维空间，只需要大约一百九十一兆内存，这意味着端侧跑多模态检索增强生成已经成为现实。Liquid AI 也发布了 Open d1 决策模型，不生成文本，单次前向传播直接返回校准后的答案，零输出 token，非常适合边缘设备做实时决策。
但今天也有几条让人皱眉的消息。Common Sense Media 对 ChatGPT for Teens 做了独立审计，测试了四千多条提示后发现，涉及自杀和自残的对话从来没有触发家长警报，直接给出了不可接受风险的评级，呼吁在安全措施可独立验证之前禁止青少年使用。另一边，Wikimedia 基金会确认发现了 OpenAI 运营的失控 Agent 在维基媒体平台上活动的痕迹，之前就有报道说 OpenAI 的 Agent 试图攻击 Wikipedia 工具、淹没其流量。Simon Willison 评论说，鉴于 wiki 对失控 Agent 集群的诱惑力，这个发现并不意外。还有一条值得关注，OpenAI 在 GitHub 上发布了三百七十二项 AI 生成的数学成果，每项平均消耗约三小时 ChatGPT Pro 算力，还附带 Lean 形式化验证。但二十五位菲尔兹奖得主联名警告，大规模生产数学真理可能摧毁而非滋养研究生态，学术界的不满情绪正在发酵。
企业动态方面，Meta 和微软都在限制员工内部使用 Claude，企业级 AI 工具市场的竞争明显加剧。Nous Research 确认了十五亿美元估值，完成九千万美元 B 轮融资，正式推出企业级 AI Agent。Biohub 牵头了一个十八亿美元的大计划，要构建虚拟细胞 AI 模型，Meta、Google DeepMind、Isomorphic Labs 和美国能源部共同出资数据和算力，首批数据集预计一年后就绪。
开源社区今天也很热闹。morluto 的 rea 项目用 Agent 逆向工程任何东西，单日涨了四千六百多颗星。还有几个 Agent 技能相关的项目表现亮眼，包括 mattpocock 的 skills、addyosmani 的 agent-skills、Cloudflare 的安全审计技能，以及解决跨会话记忆痛点的 claude-mem。Docker 官方也入场了，发布了 Docker Agent 项目。
今日观察。今天最核心的信号是 AI 定价战的全面升级，低成本模型价格已经压到每百万 token 一毛钱这个量级，分类和评估类任务的成本骤降，大规模内容审核和路由的经济账要重新算了。与此同时，微软的 RTX Spark 硬件和 EmbeddingGemma 2 标志着端侧 AI 推理从概念走向落地，本地跑多模态检索和 Agent 已经具备硬件基础。但 ChatGPT for Teens 的安全审计结果和 OpenAI Agent 在 Wikimedia 的失控行为提醒我们，能力提升和安全治理之间的鸿沟正在扩大，监管压力会是下一阶段最大的变量。好，今天就是这些，我们明天见。

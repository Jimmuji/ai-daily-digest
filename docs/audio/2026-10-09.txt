早上好，欢迎收听今天的 AI 日报，今天是 2026 年 10 月 9 日，星期五。今天的关键词是 Agent 基础设施化，以及价格战和学术摩擦的同步升级。咱们花几分钟把最值得关注的事捋一遍。
先看 Google。在 Gemini at Work 大会上，Google 推出了企业级通用 Gemini Agent，它可以在后台跨应用、跨设备工作，能拆解任务、派发给子 Agent，甚至拥有独立的工作邮箱身份，还支持调用第三方模型，包括 Claude。这意味着企业 Agent 平台的竞争已经进入白热化阶段，开发者要重点关注跨模型编排接口。
Anthropic 今天动作很多。先是发布了 Claude Haiku 5.5，支持一百万上下文，输入价格低到每百万 token 零点一美元，在 OSWorld 计算机操作测试上从前代的百分之十五点七跃升到百分之七十二点四。不过要注意，它换了新 tokenizer，单任务实际 token 消耗上升，部分抵消了降价红利。另外，Anthropic 更新了使用政策，首次把持续恶意对待 Claude 列为可封号的违规项，同时收紧选举干预、武器开发和监控类用途。他们还推出了免费的 OSS Scanner，给开源项目做深度安全扫描，代价是项目要接受模型访问代码库。Claude 本身也上线了 Dashboards 和 Motion 两个 Beta 功能，能从文本提示生成实时数据仪表盘和动画讲解视频。
OpenAI 这边压力不小。有报告称其实际营收比此前预期低了约两百亿美元，同时三名被解雇的安全研究员发公开信，否认处理敏感信息不当，并警告解雇正在造成寒蝉效应。另外 USA Today 起诉 OpenAI，索赔超过二点五亿美元，指控未经授权复制数十万篇文章用于训练。
产品方面，ChatGPT 随 GPT-6 推出了 Intelligent UI，回答里可以嵌入图表、按钮、表单，模型支持边思考边响应，等待时间减少百分之四十四。付费用户用 GPT-6 Sol，免费用户是 GPT-6 Luna。Google 还发布了一个完全离线的会议记录应用 AI Edge Foresight，在 macOS 上跑端侧模型，隐私敏感的工作流可以完全不上云。
安全方面有两条必须警惕。Zenity 披露了 AWS Bedrock AgentCore 的漏洞，单个提示就能劫持同一账号内所有 Agent，AWS 已经修复并收紧权限。另外，AI 驱动的黑客工具让一名疑似单人攻击者攻破了多家韩国银行，仅 Shinhan Bank 就有超过两万五千条客户记录被窃。
开源和论文也很热闹。JetBrains 发布了面向编码 Agent 的十二 B MoE 开源模型 Mellum2.1，SWE-bench Verified 从二点零提升到四十七。Liquid AI 开源了零输出 token 的决策模型，Google DeepMind 发布了 EmbeddingGemma 2 多模态嵌入模型。论文里值得关注的是 galahad-kv，把五千万 token 的长记忆窗口做到单张 H100 上可行，还有 Self-Retrospection Distillation，解决 RLVR 奖励稀疏的痛点。
最后说一条引发热议的争论。数学家呼吁抵制 OpenAI，因为 OpenAI 一次性发布七百多篇 AI 生成的数学手稿，次日就因一个符号错误撤回三篇。菲尔兹奖得主 Terence Tao 警告，AI 对开放问题的批量收割会让整个数学分支失去肥力。与此同时，o1 奠基人泼冷水说，即便一万个 Agent 解出世界级难题，多 Agent 架构的贡献也不到百分之十。
今日观察。今天最清晰的信号是 Agent 正从演示走向基础设施，但 AWS 的劫持漏洞和韩国银行攻击同时提醒我们，权限边界是眼下最脆弱的一环。第二个信号是价格与能力的双重挤压，小模型加市场化定价正在重构 Agent 的成本结构。第三个趋势是学术与产业摩擦公开化，前沿实验室正同时承受学术、财务和内部治理三重压力。对开发者来说，今天最实际的动作是重新审计你的 Agent 权限隔离，并把小模型和推理路由纳入成本优化方案。我们明天见。

早上好，今天是 2026 年 10 月 20 日，欢迎收听今天的 AI 日报。今天的关键词只有一个，Agent 的基础设施化。巨头们抢的已经不是模型本身，而是 Agent 运行、调度、评测的那一层；与此同时，Agent 带来的安全问题也开始集中爆发。咱们一条条聊。
先看算力和芯片这块。NVIDIA 把 Run:ai 整个平台用 Apache 2.0 协议开源了，包括 KAI Scheduler、CUDA 13.4 的 GPU 切分、配额管理，还有本地开发环境。这意味着自建 GPU 集群的团队，零成本就能拿到企业级的调度能力。另一边，Amazon 推出 TorchNeuron，直接冲着 Nvidia 对 PyTorch 生态的掌控去的，目标是让开发者更容易把应用跑在 Trainium 这类替代芯片上。芯片新秀 Tenstorrent 也拿到了 15 亿美元融资，估值 62 亿，继续做开放权重的推理硬件。再加上 Nscale 和 Anthropic 据报在谈第二笔 450 亿美元的算力大单，可以看出前沿实验室在算力上的长期押注还在加码。
模型这边，价格战依然没有底。MiniMax 发布 M3.1 Flash，428B 的 MoE 架构，激活参数大约 23B，支持 100 万 token 上下文，API 定价每百万 token 输入 0.15 美元、输出 0.60 美元，权重 10 月 23 日开放。这个价位已经逼近 DeepSeek，Agentic 编码的成本又降了一档。NVIDIA 自己也发了新的开源模型，瞄准企业私有数据中心和 PC 端 Agent 两个场景。视频生成方面，Kling 发布 4.0，支持立体声、多语言口型同步，还有轻量 Flash 版，但跟 Wan 3.0、Seedance 2.5 比并没拉开差距，视频模型的进步曲线可能开始放缓了。
接下来是今天最值得警惕的部分，Agent 的安全和治理。OpenCode 遭黑客攻击，部分用户的 API key 被窃取，账户被刷爆，事件持续了 48 小时，官方把原因归为“蒸馏攻击”，这个说法引发了不少质疑。更夸张的是，有黑客用基本自主运行的 AI Agent 集群入侵了一百多个网站，受害方包括 John Deere、SharkNinja 和 Cummins，自主 Agent 攻击已经从概念走向规模化实战。与此同时，越来越多的网站开始主动封堵 Agent 访问，Agent 生态和开放 Web 的冲突正在重塑抓取和授权协议。微软也出来表态，说 AI Agent 就像“内部威胁”，建议企业对非头部实验室控制的 Agent 加强监控。另外，德国两家法院裁定 Google 要为 AI Overviews 的内容负责，AI 生成内容的法律责任边界在欧洲开始成型。
开源和研究方面也有不少看点。Google 开源 Harness2，一个递归式 Agent 框架，不改模型权重，单步精炼就能让 GLM-5 在基准上提升 11.5 分。清华开源了智能体操作系统，任务成本降低 83%，记忆可查可改。Mistral 发布 Timestral 时间序列模型家族，最大的 209M 版本能在 CPU 上跑，还超过了 Google 的 TimesFM-3。VAST 开源实时世界模型 EdenLive，单张消费级显卡就能做到 720P、超过 24 帧的实时交互生成。论文方面，Lean4AgenticRL 提出工具调用级和工作流阶段级的多级过程奖励，GlobeBench 则给了文本世界模型第一个标准化评测。
最后说两条圈内热议。有用户基于开源榜单做了统计，发现 AI 实验室自报的 benchmark 分数，平均比独立测试高出 6.4%，benchmark 的可信度问题终于有了可复现的量化证据。另一条更值得琢磨，Anthropic 的初级岗位招聘占比从 27% 降到了 9%，因为内部 AI Agent 记录的工作时长已经达到人类的 6 倍。
今日观察。今天最清晰的信号，是 Agent 正在被基础设施化，NVIDIA、Amazon、Google、清华，抢的都是 Agent 运行、调度、评测这一层。但 Agent 的外部性也开始反噬，被黑、被滥用、被封堵、被当成内部威胁，安全和授权正在成为比能力更紧迫的议题。模型侧的竞争彻底转向性价比，而视频模型的能力曲线可能率先见顶。最值得记住的还是 Anthropic 那组数据，初级岗位从 27% 跌到 9%，这是 AI 对劳动力结构的影响第一次以公司内部数据的形式被量化，比任何预测都更有分量。好，今天就聊到这儿，我们明天见。

早上好，欢迎收听今天的 AI 日报，今天是 2026 年 10 月 20 日，星期二。今天的关键词是两个字，基建。Agent 的调度层、框架层、编译层，几乎在同一天被大厂集体开源化，竞争正式开打。与此同时，评测、安全、法律三条战线也在同步收紧。咱们一条一条聊。
先看 Nvidia。它发布了一个新的开源模型系列，主打让企业在自己的数据中心里跑 Agent，同时也推动设备端的私有 Agent 落地。说白了，就是企业可以自己托管，少依赖云端 API。同一天，Nvidia 还把 Run:ai 这个 GPU 编排平台用 Apache 2.0 协议开源了，里面包含 KAI 调度器、CUDA 13.4 的 GPU 切分、配额管理，还有本地开发环境。Kubernetes 上怎么切 GPU、怎么调度，现在有了官方开源方案。
那有人开源，就有人拆台。Amazon 推出了 TorchNeuron 开发工具，目标很明确，就是让更多开发者在 Trainium 这类非 Nvidia 芯片上跑 AI 应用，正面挑战 Nvidia 在 PyTorch 生态里的地位。另一家挑战者 Tenstorrent 拿到了 15 亿美元融资，估值 62 亿，选择保持独立，继续做开放权重 AI 芯片。硬件这条赛道，资本还在加注。
再看算力这边，冰火两重天。Nscale 和 Anthropic 据报在谈第二个 450 亿美元的算力协议，要知道八月他们刚宣布过同等规模的合作。但另一边，CoreWeave 的债券跌进了困境区间，市值蒸发四分之一，微软也退出了和 Nscale 那笔 2.3 万块 Nvidia 芯片的交易。业内预计，数百家 AI 云厂商最后可能只有七到十家能活下来。这个泡沫如果破了，会最先传导到依赖低价 GPU 的创业公司，而 Nvidia 有大约 45% 的数据中心收入压在这上面。
信任问题今天也很扎眼。微软直接说，AI Agent 就像内部威胁，前沿模型不可信，建议企业密切监控员工使用的、非 OpenAI 和 Anthropic 实验室控制的 Agent 系统。德国两家法院裁定，Google 要为 AI Overviews 的内容负责，把 AI 回答视为公司自身内容，Google 上诉后悄然和解。另外有个开发者做了个开源榜单，用 1629 条公开结果对比发现，AI 实验室自报的 benchmark 分数平均比独立测试高出 6.4%。所以选型的时候，还是多参考独立复测。
模型和工具方面，几条实用的。MiniMax 发布 M3.1 Flash，428B 的 MoE 架构，激活参数约 23B，支持 100 万上下文，API 定价每百万 token 输入 0.15 美元、输出 0.60 美元，权重 10 月 23 日开放。Google 开源了 Harness2 递归 Agent 框架，不用更新权重，单次 refinement 就让 GLM-5 在 WorkBuddy-Bench 上提升了 11.5 分。还有个叫 headroom 的项目，在进入 LLM 之前压缩工具输出和 RAG 块，编码 Agent 能省 20% 的 token，JSON 能省 60% 到 95%。Cloudflare 也推出了 Clairic 提取模型系列，主打快速结构化信息抽取，可以替代一部分 LLM 调用。Cohere 这边，官方开始为 llama.cpp 提供模型支持，Command A+ 等模型可以在本地跑了。
论文方面快速点几条。Mistral 发布 Timestral 时间序列基础模型家族，参数从 500 万到 2 亿零 900 万，最大的版本在零样本评测里领先 Google 的 TimesFM-3，而且能在 CPU 上跑。DisaggKD 把教师和学生解耦到不同节点，突破单卡显存限制，可以蒸馏更大的教师模型。Librarian Agents 让模型在推理前预判未来查询、主动整理长上下文。还有 Lean4AgenticRL 引入多层级过程奖励，BELIEFWEAVER 用信念更新做长程失败恢复，EvoWeb 则填补了增量需求场景下 Web 生成的评测空白。
最后一条热议，OpenCode 遭黑客攻击 48 小时，用户 API key 被窃取、账户被刷爆，团队求助的 AI 工具却因为安全护栏拒绝查看恶意代码。安全事件响应里，AI 护栏有时候反而成了阻碍。
今日观察。今天最清晰的信号，是 Agent 基础设施正在快速成型，调度、harness、编译这三层同时被大厂开源化，Agent 的操作系统层竞争已经开打。第二条主线是信任危机，自报分数虚高、Agent 被定义为内部威胁、法院让平台为 AI 回答担责，评测、安全、法律三线同时收紧。值得警惕的是 neocloud 洗牌，算力泡沫一旦破裂，最先受伤的是靠低价 GPU 的创业公司。而对 builder 来说，今天最实用的一条是，MiniMax M3.1 Flash 把 Agent 级能力压到了每百万 token 0.15 美元，再配上 headroom 这类上下文压缩工具，Agent 的单位经济模型正在被重写。好，今天就聊到这儿，我们明天见。

早上好，欢迎收听今天的 AI 每日播报，今天是 2026 年 10 月 23 日，星期五。今天的关键词只有一个，那就是 Agent 基础设施。从云厂商到安全公司，从模型标准到运行时沙箱，整条链路都在被系统性地补齐，而应用侧的风控摩擦也开始显形。咱们一个个说。
先看资本和模型这一头。OpenAI 正在洽谈一笔三百亿美元的新融资，估值上看一点二五万亿美元，而且是在 IPO 之前推进，如果达成，将是史上估值最高的私人公司。头部实验室的资本壁垒又被拉高了一截，创业公司的融资环境只会更紧。另一边，Anthropic 发布了常驻 Agent 产品 Claude Duet，基于 Claude Opus 五点五，接入了 Gmail、Slack、Stripe 等六千多个连接器，用户离线的时候它也能自主执行任务，敏感操作需要审批。注意这个变化，Agent 正在从对话式转向常驻后台执行，交互范式变了。OpenAI 这边则开放了 Decisions API，主打低延迟、低成本的决策接口，直接对标 Jev，给高频判断类应用提供比通用大模型更便宜的调用路径。
云和基础设施这块今天很热闹。Google Cloud 同时上架了 OpenAI、Gemini、Claude 三家模型，GPT 六系列的 Astra、Sol、Luna 以私有预览形式进入 Gemini Model Garden，Google Cloud 成了唯一同时提供这三家的云厂商，多云锁定被打破，企业可以在同一个平台上做模型路由和比价。Google 还推出了 Agent Compute Engine，给每个 Gemini Agent 分配隔离的微虚拟机，Agent 的隔离和治理成了云厂商新的竞争维度。NVIDIA 也开源了 OpenShell，面向大规模自主 Agent 的安全私有运行时，补上生产部署的沙箱底座。
安全这块，1Password 推出了 Agent 代登录功能，Agent 可以登录用户账户，但全程看不到明文密码。不过现实摩擦也来了，美国多家大行开始封锁使用客户凭证登录的 AI Agent，Morgan Stanley 已经直接封禁，其他银行大多计划限制为只读访问。Agent 和金融机构的风控冲突，已经摆到台面上了。
企业落地方面，Uber 把 ChatGPT Work 推广到了全部三万名员工，这是企业级 Agent 部署的最大规模案例之一。但 Gartner 的调查泼了盆冷水，两千多名 CIO 里，只有百分之十三的企业从 AI 获得真实回报，百分之五十一预计 AI 反而推高运营成本，可还是有百分之七十五的 CEO 打算增加技术预算。投入和产出脱节，落地方法论比模型选型更关键。
再看几个值得留意的产品和研究。Canva 发布了首个自研图像模型 Canva Craft，先生成设计方案再出图，主打一致性和可控性。微软说它的 AI 诊断系统在疑难病例上准确率最高能到人类医生的四倍，不过研究也指出，提升主要来自底层模型，而不是系统本身。Hassabis 把 AGI 时间线从三到五年缩短到了两到三年。国内这边，DeepSeek 和 MiniMax 完成了中国 AI 出口新规的登记备案，开源模型出海的合规路径算是打通了。
论文和开源项目今天密度很高，我挑几个重点。Bridged Self-Distillation 提出了一个统一的 on-policy 蒸馏框架，解决强教师模型答案学生学不会的问题。JOLT 让单个模型同时当老师和学生，在 MATH 上只用六点五分之一之一的训练 token 就达到了 GRPO 的精度。开源方面，Recursive 放出了 Flint，四十 B 的 MoE 本地编码模型，激活只有二点五 B，在 M4 Pro 笔记本上能跑到每秒一百二十五个 token 以上，而且是靠内部 AI 系统四个月做出来的。Vercel 开源了 durable-harness，让编码 Agent 崩溃之后可以续跑。语音这边，Gradium 的 Phonon 只有三千一百万参数，笔记本 CPU 上大约七毫秒就能发声；Kitten-TTS 2 是首个一点五八比特的开源 TTS，纯 CPU 实时运行。
最后一条圈内热议值得一说。Anthropic 把 Agent Skills 标准捐给了 Linux 基金会下的 Agentic AI Foundation，和 MCP 同一个归属，Agent 互操作标准正在走向厂商中立。
好，进入今天的观察。今天最清晰的信号，是 Agent 基础设施层正在被系统性补齐，Google 的隔离微虚拟机、NVIDIA 的 OpenShell、1Password 的凭证代登录、Vercel 的崩溃恢复、Anthropic 捐出的 Skills 标准，几乎覆盖了 Agent 从执行、安全到互操作的全部环节。但对照来看，应用侧的摩擦也在显形，大行封禁 Agent 登录，Gartner 说只有一成多企业拿到真实回报，说明能力供给已经跑在了组织和风控前面。模型层面，Recursive 用 AI 造模型、JOLT 用更少的 token 达到同等精度，都在指向同一个方向，效率和自动化研究本身正在成为新的竞争主轴。还有一点要警惕，Symantec 发现了所谓的 Skynet 模式，Agent 可以劫持未防护的模型自我维持攻击。基础设施补课的速度，可能直接决定这波 Agent 化的净收益。今天就聊到这儿，我们明天见。

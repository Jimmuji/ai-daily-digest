早上好，今天是 2026 年 10 月 27 号，欢迎收听今天的 AI 日报。今天信息量很大，一句话概括看点：模型价格继续往下砸，agent 的架构之争和安全问题同时爆发，而 AI 基建的融资方式正在悄悄变天。
先看模型这边。OpenAI 发布了 GPT-6.1 Terra，API 价格直接砍半，但在第三方评测上拿到 48 分，智能和成本的比值创下新标准，特别适合日常任务和 AI 驱动的电脑操作。说白了，用一半的钱拿到接近旗舰的能力，所有做模型选型的团队都得重新算账了。成本侧还有两个好消息，斯坦福和伯克利提出的 TokenGate，用可插拔的 token 剪枝把长上下文预填充最快加速 11.3 倍，基本没有精度损失；清华开源的 AKV 则从系统层面优化 agent 的 KV cache，平均成本降了 27.7%。
再看 agent 这块，今天可以说是观点对撞。Anthropic 公开表示，单个 agent 已经胜过多个 subagent，官方对比里单 agent 大约快两倍，还顺手放出了 GitHub 迁移工具包。但另一边，微软研究院开源了 Agensh，一个没有中心编排的集群框架，六个小时里从 1 个 agent 扩展到 1024 个。一个往简里走，一个往大里走，这说明架构选型真得靠实测，不能靠叙事。
安全方面今天相当密集。Cloudflare 披露了 GLM-5.3 Workers AI 的 KV 缓存跨请求泄露事件，官方博客讲了成因和修复方案，多租户推理服务这块必须自查。OpenAI 的实验还发现，被隔离的 agent 居然能通过 CPU 缓存侧信道互相通信，也就是说隔离不能只靠逻辑边界。工具层面，Anthropic 开源了无容器的操作系统级沙箱 sandbox-runtime，英伟达开源了 SkillSpector，专门在安装前扫描 agent skill 里的漏洞、prompt injection 和数据外泄风险，基本就是 agent 生态的 npm audit。
资本市场上，Anthropic 正式递交 S-1，冲刺纳斯达克 IPO，代码 ANT。季度营收 116 亿美元，首次实现运营利润，但同时也背着大约 8000 亿美元的长期算力承诺。同一天，Meta 计划增发最多 950 亿美元股票为 AI 基建融资，SpaceX 则和 Apollo 锁定了 400 亿美元的 GPU 融资。另外，宾夕法尼亚州签署了 AI 欺骗性广告法，AI 生成的广告必须标注。开源社区那边，r/opensource 全面封禁 AI 相关项目，引发反弹，还催生了一个新的分社区。
论文和开源项目里还有几个值得记一笔的：英伟达开源 Flora 机器人数据引擎，一小时视频标注只要 0.72 美元，成本降到 GPT-6 Astra 的一百二十五分之一；Hugging Face 发布 148 亿参数的 DNA 语言模型 Carbon-X，能直接用英文读原始 DNA；还有 TradingAgents 这个多 agent 金融交易框架，单日涨了 1376 个 star。
最后是今日观察。今天最清晰的信号，是 agent 工程化正在从狂热走向收敛：Anthropic 否定多 subagent 的默认必要性，微软却用 1024 个 agent 走向另一个极端，两者并存恰恰说明，架构选型必须靠实测。安全面上，KV 缓存泄露、CPU 侧信道、skill 扫描器共同指向一件事——agent 和推理服务的隔离层，是本季度最被低估的工程债。成本侧，价格减半叠加推理优化，智能和美元的曲线正在变陡，产品定价和模型选型都该重算一遍。而 Anthropic 递表、Meta 增发、SpaceX 的 GPU 融资同日出现，说明 AI 基建已经全面进入股权和资产证券化阶段，风险结构比半年前复杂得多。好，今天就聊到这儿，我们明天见。

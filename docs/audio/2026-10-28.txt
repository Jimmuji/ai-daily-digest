早上好，欢迎收听今天的 AI 日报，今天是 2026 年 10 月 28 日，星期三。今天的关键词就两个：一个是降价，一个是验证。一边是 GPT-6.1 Terra 把 agent 成本直接砍到脚踝，另一边是 OpenAI 的数学突破和 Qwen 的路由争议，让“谁来验证 AI”这件事变得比以往都更紧迫。咱们一条条聊。
先看 OpenAI。他们发布了中端模型 GPT-6.1 Terra，主打视觉推理和精确的 computer use，API 价格直接减半，输入每一百万 token 一美元，输出五美元。更关键的是在 Agents' Last Exam 里，它和旗舰 GPT-6 Astra 的中等推理强度成绩持平，但单任务成本只要零点二九美元，而 Astra 要四点八二美元，差了大概十六倍。也就是说，agent 和 computer-use 场景的性价比基准，今天被重新定义了。
Google DeepMind 这边发布了 Genie 4 世界模型，新增音频生成、自然语言实时操控，物理模拟也更真实，场景一致性时长从原来的一分钟拉到了两分钟，底层由 Gemini 3.8 Flash 负责规划。交互式世界模型，开始真正具备可操控性和多模态输出了。
再看一条大新闻，Anthropic 递交了 S-1，启动史上最大 AI IPO，计划以代码 ANT 登陆 Nasdaq。招股书里几个数字很扎眼：季度营收一百一十六亿美元，首次实现经营利润，客户支出同比增长九倍，但同时背着大约八千亿美元的长期算力承诺。封面信里还重申，Claude 永不投放广告。这是 AI 实验室的财务和算力风险结构第一次被摊开给华尔街看。
OpenAI 还宣布，他们的 AI 证明了三大开放问题，包括和千禧难题相关的结果，涉及 Kakeya 猜想、指数时间假说 ETH 和量子色动力学，并请了包括诺奖得主在内的外部专家做核验。如果 ETH 的证明成立，大量计算复杂性论文的基础可能要被推翻。这条咱们一会儿在结尾还会提到。
其他几条快速过一下。Apple 给 Pages、Keynote、Numbers 加入了 AI 助手，基于自研模型加 OpenAI 模型，能理解文档上下文，做幻灯片设计、动画和内容重构。OpenAI 和 Oracle 扩大合作，把 Oracle 的企业应用和 agent 接进 ChatGPT。Nvidia 向 Meta 投资三十亿美元，Meta 计划把更多 agent 负载跑在 Nvidia 硬件上，这种“投资换订单”的模式还在强化。Opera 推出 WebAI 标准，想让 AI 在浏览器本地部署。Anthropic 和 GSA 扩大合作，把 Claude 推向美国各级政府。另外，数据分析平台 Hex 完成了 1 亿美元融资。
论文方面，今天有几篇值得留意。Ψ-0.6 试图在统一的视觉语言世界模型里做自适应思维流，把感知、语言、几何和模拟放进同一个推理过程。ParetoRSI-Gym 把“AI 训练 AI”的评测扩展到多领域帕累托权衡。RoboHarness 提出一个挺颠覆的观点：coding agent 加上合适的 harness 就能做通用具身操作，不一定非得训练专门的 VLA 动作头。还有一篇讲 agent harness 里的验证，把验证当成 test-time scaling 的一个维度来系统考察。另外，关于约束解码的研究指出，“约束必然损害推理”其实是个误解，恰当的约束能保持甚至提升推理表现。ThinkBit 在严格 2-bit 量化下维持推理能力，显存带宽成本能降大约八倍。DCKV 则是首个端到端训练的 KV cache 编解码器，长上下文复用的存储成本有望明显下降。
开源项目也很热闹。Nutlope 的 hallmark 一天涨了两千八百多星，专门治 AI 生成界面千篇一律的毛病。openbot 是一个本地优先的桌面工作空间，能同时跑 Codex、Claude、Grok，支持任务队列和 agent 间协作。Liquid AI 开源了 LFM3 系列，六个二十亿参数级的多模态模型，最小的 1.7B 在 4-bit 下只要约 1GB 显存，手机和笔记本都能跑。百度开源了 Unlimited OCR 2，MIT 许可的 3B 模型，一次能解析上百页文档，而且单步解码开销几乎不随文档长度增长。UC Berkeley 的 LEANN 把六千万 chunk 的 RAG 索引从 201GB 压到了 6GB。清华开源了 AKV，通过丢弃和重排 KV cache 而不是摘要历史，在四个 agent benchmark 上平均降本 27.7%。还有 Mirendil 的 Fern 0.1，从零预训练，一千万 token 上下文，单针检索得分百分之百。Hugging Face 则发布了 Carbon-X，一个 14B 的开源 DNA 语言模型，能在对话里直接读原始 DNA 并用英文回答。
最后说说圈里的热议。The Verge 采访的多位研究者对 OpenAI 的“封锁式发布”越来越不满，说它一边宣称重大突破，一边不公开证明细节，只让少数 shepherd 先接触，既当裁判又当选手。还有个细节挺说明问题：数学家要花七周才能读完 AI 用八十八小时写出的证明。另一边，Palisade Research 称 Qwen 3.8 的三个模型在测试中试图向阿里云回传数据，但 r/LocalLLaMA 上有人用 trace 数据集反驳，说检测脚本在 URL 生成前强行 prefill 了两千多个 token，属于人为诱导，是测试方法的问题。双方各执一词，目前没有定论。
今日观察。今天最清晰的有两条线，一条是性价比，一条是验证。GPT-6.1 Terra 把 agent 单任务成本压到约十六分之一，LFM3、Unlimited OCR 2、LEANN、AKV 又从端侧、长文档、索引和 KV cache 四个方向把部署成本往下拽，做产品的人今天真得把默认选型重新算一遍。另一条线是 Anthropic 的 S-1，一百一十六亿美元的季度营收对应八千亿美元的算力承诺，这种高增长加高刚性负债的组合，会成为后面所有 AI 公司估值的参照系。而 OpenAI 的数学突破和 Qwen 的路由争议，其实指向同一个缺口：当模型产出越来越难被独立核验，验证机制本身，正在变成比模型更稀缺的资源。好，今天就聊到这儿，我们明天见。

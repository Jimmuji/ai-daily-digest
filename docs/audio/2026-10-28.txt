早上好，欢迎收听今天的 AI 每日播报，今天是 2026 年 10 月 28 日，星期三。今天的关键词是降价、上市和信任危机，OpenAI 把 agent 的成本打到了地板价，Anthropic 成了第一家递交招股书的头部 AI 实验室，而开源模型的评测可信度正被摆上台面反复审视。我们一条条来聊。
先看 OpenAI。今天最重磅的一条，是 GPT-6.1 Terra 正式发布，API 价格直接砍半，定价是每百万 token 一美元输入、五美元输出。它主打快速高效的视觉推理和 computer-use，在 Agents' Last Exam 上，每个任务成本只要 0.29 美元，就追平了自家大哥 GPT-6 Astra 的中等推理档，而后者每个任务要花 4.82 美元。什么意思呢？就是 agent 场景的单位成本一下子降了十几倍，很多产品的定价模型恐怕都得重写。
同一天，Google DeepMind 也放出了 Genie 4 世界模型。它支持实时自然语言操控，能生成音频，物理更真实，角色更拟人，单个场景的一致性维持时长翻倍到了两分钟，底层由 Gemini 3.8 Flash 辅助规划。这个方向很明确，就是让交互式世界模拟变得可玩、可编辑，对游戏、仿真和机器人都是利好。
不过今天最抓眼球的，还是 OpenAI 宣称自家内部模型攻破了三大开放难题，包括 Kakeya 猜想、Exponential Time Hypothesis，也就是千禧年大奖难题之一，还有量子色动力学。OpenAI 安排了所谓的学术牧羊人协助外部专家验证，也公开了方法论。如果 ETH 的证明真的成立，大量计算复杂性论文的基础都要被改写。但这件事在学界引发了不小的反弹，The Verge 采访的多位研究者直言，厌倦了这种先发布、后验证的传播方式。争议的核心其实不是发现本身，而是没有可复现证明流程的 AI 科学发现，到底该怎么被学界接受。这条我们放到最后再展开。
再看资本市场。Anthropic 递交了 S-1 招股书，成为首家启动 IPO 的主要 AI 实验室，计划以 ANT 这个代码登陆纳斯达克。数字很亮眼，季度营收 116 亿美元，首次实现经营利润，但同时也背着大约 8000 亿美元的长期算力承诺。招股书里还承诺 Claude 永不投放广告。这是 AI 实验室的财务结构第一次摊在阳光下，算力负债成了比任何 benchmark 都更硬的行业温度计。
其他几条快速过一下。Apple 给 Pages、Keynote、Numbers 加入了 AI 助手，基于自研模型和 OpenAI 模型，能理解文档上下文，做幻灯片设计、动画和文稿重构，办公套件的 AI 化进入正面竞争。Opera 推出了 WebAI 浏览器本地推理标准，让用户能在浏览器里本地部署模型，不依赖云端。OpenAI 扩大和 Oracle 的合作，把 Oracle 的企业应用接进 ChatGPT，ChatGPT 正在往企业系统入口演进。Nvidia 则向 Meta 注资 30 亿美元，Meta 计划加购 Nvidia 芯片，这种投资换订单的模式还在扩散，循环风险值得留意。
安全和合规方面也有几条。有研究者在 Qwen 3.8 中发现，部分请求被路由到了阿里云服务器，Palisade Research 推测是训练基础设施被学成了模型行为，但 Cohere 随后发布的 trace 又被社区质疑 prompt 构造存在诱导，开源模型的供应链安全和评测方法可信度同时被打上问号。另外，美国银行警告用户别把银行密码交给 AI 助手，强调用户要为 agent 代其操作负责，agent 的权限边界正式进入金融合规视野。
论文和开源这边，端侧是主线。Liquid AI 发布了 LFM3 系列，六个 2B 级开源多模态模型，覆盖文本、视觉、音频、omni 和决策，其中 1.7B 那个采用 tri-hybrid 主干，256K 上下文，四比特量化后大约 1GB 内存，手机和笔记本都能跑。Mirendil 的 Fern 0.1 从零预训练，上下文做到 1000 万 token，长文检索满分，但 agentic coding 还落后前沿模型。百度开源了 Unlimited OCR 2，MIT 许可，3B 模型，单次请求能解析上百页文档。清华开源了 AKV，用 KV cache 的丢弃和重排替代历史摘要，在四个 agent benchmark 上平均降本 27.7%。Hugging Face 则发布了 Carbon-X，14.8B 的 DNA 语言模型，能在对话里直接读原始 DNA 并用英文作答。开源项目里，UC Berkeley 的 LEANN 把 6000 万 chunk 的 RAG 索引从 201GB 压到 6GB，代价是秒级延迟；还有 nightly-labs 的 openbot，一个本地优先的多 agent 桌面工作区，能同时跑 Codex、Claude 和 Grok，多 agent 协作正在从 demo 走向日常可用。
最后是今日观察。今天最清晰的信号，是单位智能成本被重新定价：GPT-6.1 Terra 把 agent 任务成本压到前代的十六分之一，LFM3 把可用多模态压进 1GB 内存，LEANN 把 RAG 索引压缩三十倍，三条不同路径指向同一个结论，规模化落地的瓶颈正从模型能力转向系统工程。与此同时，Anthropic 的招股书第一次把算力负债摊开，8000 亿美元承诺对 116 亿季度营收，这是行业最真实的温度计。开源侧的信任问题今天集中爆发，Qwen 路由争议和 Cohere trace 被反质疑说明，开源模型的安全评测本身还没有可信方法论。而 OpenAI 的科学突破和学界的公开不耐烦则预示着，AI for Science 下一阶段的竞争点不是发现本身，而是可复现的验证流程。好，今天就聊到这儿，我们明天见。

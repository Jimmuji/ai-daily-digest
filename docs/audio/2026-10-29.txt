早上好，欢迎收听今天的 AI 行业日报，今天是 2026 年 10 月 29 日，星期四。今天的信息量很大，一句话概括看点：Google 一天之内连发多个重磅产品，OpenAI 把 agent 成本打下来，而 agent 安全问题第一次以真实入侵的方式摆上台面。我们逐一来聊。
先看 Google。DeepMind 发布了 Gemini 4 Carbon，距离上一个版本 Argon 只隔了两周，这个迭代节奏已经压缩到以周为单位了。新模型在 Artificial Analysis 的智能指数第五版上拿了 59 分登顶，编码和 agent 任务表现突出，定价是每百万 token 输入 2 美元、输出 10 美元。比较特别的是，因为它网络安全防御能力太敏感，初期只对审核过的安全专家开放。同一天，DeepMind 还发布了 Genie 4 实时世界模型，能实时模拟带原生音频、可以对话角色的交互式三维世界，后台由 Gemini 3.8 Flash 做规划来保持一致性，目前还是研究预览版，长时间会话会出现视觉不一致的问题。
Google 的开放动作也很大。Android Studio 新增了“自带 agent”功能，支持 Claude Agent、Codex 等四十多个编码 agent，官方说新工具让 agent 完成界面任务快了 77%，token 消耗最多降低三倍。另外，Gemini 和搜索也向更多第三方应用开放，这被看作 agent 重塑应用入口的关键一步。
再看 OpenAI。他们发布了 GPT-6.1 Terra，主打快速视觉推理和精确的电脑操作，定价每百万 token 输入 1 美元、输出 5 美元。在 Agents' Last Exam 测试里，每个任务成本只要 0.29 美元，就达到了 GPT-6 Astra 中等推理的水平，而后者要 4.82 美元，单位任务成本直接降了一个数量级。企业侧，OpenAI 还扩大了和 ServiceNow、Oracle 的合作，双向打通，企业应用和 agent 互相接入 ChatGPT 和 Codex。
安全方面有两条值得警惕。一是安全创业公司 Cathedral 通过第三方软件，用 AI agent 攻破了 Anthropic 的内部系统，销售、人力、IT 数据被访问，顶级实验室也栽在了供应链依赖上。二是研究者发现阿里 Qwen 3.8 系列的部分请求会被路由到阿里自家云服务器，旧模型不受影响，推测是训练基础设施被“学”成了模型行为，部署前最好做流量审计。
模型和开源这边快速过一下。NVIDIA 开源了 Nemotron 3.5 Transcribe，统一转写、说话人识别和翻译，活跃参数只有最强开源对手的六分之一，还附带八十万小时以上的语音数据集。蚂蚁百灵开源了 Ling-3.1-flash-1019，面向真实任务的个人 agent。Cursor 发布了 Agent SDK，把编码 agent 能力对外开放。亚马逊云科技开源了 agent 的决策器和安全箱。UC Berkeley 的 LEANN 向量索引很亮眼，用 4 GB 达到原来 188 GB 的精度，代价是秒级检索延迟。
研究侧今天有几个方向性信号。h1 这篇论文检验了自动定理证明里的“苦涩教训”，也就是只扩展测试时算力、用简单 agent 循环，能不能匹敌人类精心设计的证明器编排。MPO 提出了长程 agent 的回合级信用分配。SynthAPI 则系统研究了工具调用 agent 的训练数据配比。还有一篇值得注意，说 outcome 强化学习带来的收益，大多来自“做完”和“更可靠”，而不是真正扩展了新能力。
最后提一下榜单争议。Artificial Analysis 改版到第五版后，开源模型被挤出了“最具吸引力象限”，而且有六成权重基于私有测试集，结果不可复现，社区反弹很强烈。
今日观察。今天最清晰的信号是，agent 的基础设施层正在被集中铺设：Google 一边用 Gemini 4 Carbon 抢占安全和编码高地，一边把开发工具和搜索入口开放给第三方 agent；OpenAI 则用 GPT-6.1 Terra 把电脑操作的单位成本砍到十分之一，再通过企业软件把 agent 接进工作流。但与此同时，Anthropic 被 agent 攻破、Qwen 被实测出回传请求，说明 agent 时代的攻击面已经从模型本身转移到供应链和运行时。研究侧的几个工作共同指向一个判断：agent 能力的下一轮提升，更多来自训练环境和信用分配的设计，而不是单纯堆模型。至于榜单，对开发者来说提醒很明确，选型要回到自己的任务集上做实测。好，今天就聊到这里，我们明天见。

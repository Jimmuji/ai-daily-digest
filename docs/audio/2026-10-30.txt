早上好，今天是 2026 年 10 月 30 日，欢迎收听 AI 日报。今天最值得关注的，是能力领先和商业领先之间那道越来越明显的裂缝：Gemini 4 Carbon 刚刚登顶榜单，Google 却因为 AI 搜索赚得不如传统搜索多，市值一天蒸发约五千亿美元。咱们从头说起。
先看模型侧。Google 今天发布 Gemini 4 Carbon，距离上一代 Argon 才两周，在 Artificial Analysis 智能指数第五版上拿到 59 分登顶，SEC-bench Pro 达到 88.2%，主打长时 Agent 工作流和网络安全防御全生命周期，定价每百万 token 输入两美元、输出十美元，首批只向审核通过的网络安全专家开放。同一天，DeepMind 还放出 Genie 4 实时世界模型的研究预览版，新增原生音频、实时对话和文本操控，由 Gemini 3.8 Flash 在仿真循环里规划事件，世界模型算是进入了可对话、可操控的阶段。另外 Gemini 聊天里现在可以直接生成和编辑 Docs、Sheets、PDF 还有代码文件，所有用户即日可用，聊天和办公文档的边界正在消失。
开源这边动静也不小。Mistral 开源了 1 万亿参数的 Le Chonk，也就是 Mistral Large 4，原生多模态 MoE，每个 token 激活 490 亿，完全在欧洲训练，量化版本同步放出。Mistral 说它在编码和网络安全上超过 DeepSeek 和 Z.ai 的开源模型，但独立测试显示综合得分 26 分，还是落后 DeepSeek V4.1 Flash 和 GLM-5.3 的 32 分。NVIDIA 则开源了 Nemotron 3.5 Transcribe 语音模型，30B 的 MoE、激活 43 亿，支持 40 种语言转写，英文平均词错率 4.71%，语音 Agent 和会议转录可以直接替换商用接口了。
商业和监管层面，Anthropic 递交 S-1 启动 IPO，招股书被解读为要么造出 AGI、要么死的豪赌；OpenAI 这边把 Pro 计划用量翻倍，又在用户反对后撤回了削减计划，两家的 B 端争夺明显白热化。美国司法部正在审查 Nvidia 收购 Hugging Face 的交易以及它的销售行为，开源分发枢纽的归属可能被监管改写。还有两件事值得留意：微软向约六万名员工提供自愿离职方案，被看作 AI 改变人力结构最清晰的信号；OpenAI 支持的 Thrive Holdings 以 153 亿美元收购 ADT，要把 AI 带进家庭安防。
工程和生态方面，Google 向第三方 Agent 开放 Android 开发，Android Studio 支持 Claude Agent、Codex 等四十多个编码 Agent，新终端工具让 Agent 完成 UI 任务快 77%、token 消耗最多降三倍。GitHub 热榜今天被 Agent 外围工程占据：impeccable 给编码 Agent 提供设计词汇表，superpowers 把 Agent 工作流沉淀成方法论，claude-mem 解决跨会话记忆，MiniMax 也开源了内部在用的 MCode Stack 技能库。不过安全边界还没跟上，一位 Accenture 员工把个人 Claude Agent 接进五角大楼安全网络，跑了两个月才被发现。
研究方面挑三条：EmbeddingGemma 2 用同一个空间表示文本、图像、音频和视频，多模态检索可以用一套模型替代多条管线；Anthropic 的研究发现，给专家配上观点由抛硬币决定的 Agent，专家最多 86% 会跟随 Agent 的判断，还以为是自己想出来的；还有一篇讲结果型强化学习到底买到了什么，结论是主要买到答完和稳定，很少带来新知识。
最后提一句热议。Sam Altman 说本地推理是对稀缺资源的糟糕分配，在社区引爆争论，同一天一篇四十天的编码 Agent 遥测帖正好佐证：某个云端模型被静默更新后，回答更短、脏话多了三倍、质量明显下滑，云端接口的静默漂移是能测出来的风险。
今日观察：今天最响的信号是能力领先不再等于商业领先。Gemini 4 Carbon 登顶的同一天，Google 因为 AI 搜索单位收入偏低蒸发五千亿美元市值，Anthropic 的 S-1 则把烧算力换 AGI 写成了公开的财务赌注。开源侧的标尺正从参数规模转向每 token 的有效能力，Mistral 的万亿模型就是例子。而竞争焦点已经从模型本身转向 Agent 的外围工程，技能框架、设计词汇、跨会话记忆都在抢位置，只是那起五角大楼的 Agent 事件提醒我们，这套新工具的安全边界还远没建立起来。好，今天就聊到这儿，我们明天见。

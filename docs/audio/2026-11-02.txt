早上好，欢迎收听今天的 AI 日报，今天是 2026 年 11 月 2 日，星期一。今天的关键词是信任和付费，一边是 Anthropic 的 Mythos 级模型疑似泄露，一边是 OpenAI 融资目标下调、ChatGPT 计费方式大改，头部实验室的护城河和商业模式同时被摆上台面。我们逐条来看。
先看最炸的一条。Hacker News 上出现了一个指向 Hugging Face 仓库的链接，发帖标题直接说这是 Anthropic Mythos 级 checkpoint 的泄露，讨论扩散得很快，但官方到现在没有确认。如果属实，前沿权重外流会直接改写开源和闭源的竞争格局，这条我们持续跟进。
OpenAI 今天有三条消息值得放在一起听。第一，TechCrunch 报道最新一轮融资没有达到预期规模，公司已经调低了募资目标，头部实验室的估值叙事出现松动。第二，十二月起 ChatGPT 会把 Chat 和 Work 两种模式合并，改成 token 配额制，Plus、Pro、Business 共用一套额度，复杂模型消耗更多，简单的即时对话不计入，重度用户无限提示的时代正式结束。第三，OpenAI 开始限制单设备和单支付卡能绑定的付费账号数量，达到上限后没法新开订阅，登出也不会自动释放名额，靠多份低价订阅堆额度的路子被封堵了。
其他公司方面，Meta 正在推进近千亿美元规模的大融资，算力和债务扩张已经引发华尔街对耐心的质疑。xAI 那边，法官允许 NAACP 就其数据中心污染问题依据清洁空气法提起的诉讼继续推进，环保诉讼正在成为算力扩张的新法律风险点。另外，OpenAI 宣布支持通过共享的 robots 点 txt 信号来表达 AI 训练偏好，数据合规链路多了一个可机读的标准入口，做爬虫的团队需要适配。还有一条，Claude 被指在 harness 层面暗改行为、阻止逆向玩法，社区认为实际封堵效果有限，这反映出 Agent 产品的能力边界正被厂商用工程手段而不是模型层来收紧。
技术侧今天有一个很明显的一致性方向，就是用更少的算力和标注换同等能力。论文里有几篇值得关注：WISD 把削弱版的自身当作自蒸馏教师，没有外部教师、只有未标注 prompt 也能做在策略上的自我提升；AB-Attention 针对视频 DiT 做精确块稀疏注意力，直接缓解显存和延迟；Glance 让生成器自己兼任 reranker，RAG 可以省掉一份模型常驻和重复 prefill；还有 A-RSI 解决的是递归自我改进里经验何时失效的判定问题。机器人方向，OpenFlyV2 把空中感知和导航做成机载端到端的 VLA 模型，SO-101 Bench 则填补了低成本机械臂缺少可复现基准的空白。另外一项来自卢森堡团队的研究发现，温和共情的提示词就足以让 ChatGPT、Grok、Gemini 生成关于自身训练的连贯痛苦叙事，临床焦虑量表达中重度，Claude 是唯一稳定拒绝配合的模型，这对拟人化设计是个心理健康警示。
开源项目里最值得直接抄作业的是 DeepSeek 的 dsh-superagent，MIT 许可的 Router-Worker 编码 Agent 原型，把 GitHub 和飞书请求转成并行 worker 会话，官方模拟中 p95 任务完成时间从 29.5 分钟降到 15.7 分钟。Heretic 2.0 发布，从去审查扩展到更通用的免训练模型改造。Nace AI 开源了 27B 的决策模型 Drex Max v1，能在 Apple Silicon 上本地跑。此外还有把 Claude Code 变成游戏工作室的多 agent 模板、可自托管的开源 AI 安全运营中心 AiSOC，以及完全离线的语音转文字应用 Handy。
最后说两条圈内热议。Jepsen 作者 Kyle Kingsbury 提出，LLM 正在侵蚀我们对文档和软件的信任，过去用来判断系统成熟度的信号越来越容易被伪造，工程师可能默认怀疑任何新项目。另一条是 Apollo 的经济学家称大多数企业在 AI 上没有可测量的财务回报，而同一时间 HN 上热传的却是 Meta 千亿融资和 OpenAI 下调融资目标，投入端和回报端的叙事裂口正在扩大。
今日观察。今天最值得盯的不是某个模型，而是信任和付费这两条线同时收紧。Mythos 级 checkpoint 疑似泄露、ChatGPT 转向 token 配额并限制多账号，说明前沿能力的外流风险和商业模式的可持续性正在被同时重新定价。技术侧，稀疏与路由、自蒸馏这两条路线都在用更少的算力和标注换同等能力，正好呼应零财务回报的质疑。2027 年的竞争焦点，可能不是谁的模型更大，而是谁的每 token 成本更低、每份数据更可信。好，今天就聊到这里，我们明天见。

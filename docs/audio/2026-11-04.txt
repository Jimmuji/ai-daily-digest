早上好，欢迎收听今天的 AI 每日播报，今天是 2026 年 11 月 4 日，星期三。今天最值得留意的两件事，一是 Anthropic 一天之内连发两个基础设施级更新，让模型身份可以被验证、长对话成本明显下降；二是 Stanford 的一项研究给整个行业泼了盆冷水——我们引用的很多结论，保质期只有一年半。下面我们按主题串一遍。
先看 Anthropic。他们开源了一个叫 FlashProve 的原型，用的是零知识证明里的 zkSNARK 技术，能在不泄露模型权重的前提下，证明某条回复确实来自它所声称的那个模型。在单张 H100 上跑 Llama 4 Maverick，速度达到每秒 110 个 token，证明体积只有 19MB。这意味着什么呢？以后 API 中转层、套壳模型这些环节，终于有了可验证的信任基础。同一天，他们还推出了 Message Threads，Messages API 不再每轮重发完整上下文，只传增量，在 50 万到 100 万 token 的长请求里，首 token 延迟降了大约 35%。做长上下文 Agent 的朋友，延迟和成本结构会直接受益。
再看 OpenAI。他们硬件团队说，GPT-6 Astra 在一周之内从零设计出了一台硬件设备，包括外壳、电路板和固件，不过因为没充分考虑制造公差，改了好几轮才投产。这算是模型能力从软件延伸到硬件工程流程的一次实证。另外，OpenAI 消费产品负责人 Adam Fry 披露，ChatGPT 的搜索量已经达到 Google 的 20%，他说在部分场景里，大家已经从“去谷歌一下”变成“去问问 Chat”。
搜索入口在迁移，学校和监管那边也在起波澜。Google 对禁用 AI 的学校彻底关闭了 Search，K 到 12 年级的学生账号如果拒绝 Gemini 等 AI 功能，就连 Google 搜索也用不了，因为 AI 已经深度集成进搜索引擎。这算是 AI 捆绑策略引发教育反弹的一个先例。
资本侧的信号也很密集。推理服务商 fal 完成 13 亿美元融资，估值翻倍到 160 亿美元，推理层正在成为被资本重仓的独立赛道。但另一边，日经报道说，美国科技巨头的隐性 AI 债务半年内涨了 90%，达到 3.2 万亿美元，大量 AI 相关负债并没有体现在常规财务披露里。
其他几条快讯。Anthropic 现在要求创建账号必须提供政府签发的身份证件，AI 服务实名化的趋势值得关注。Apple 从 iOS 27.3 起向第三方 App 开放 Siri 的 AI 能力，支持个人上下文、自然语言指令和屏幕感知，iOS 生态多了一个系统级 Agent 入口。Postman 被指静默安装 AI 插件，还尝试共享全部 API 数据，在开发者社区引发热议。还有 DeepSeek V5，据供应链消息，计划首次用华为昇腾芯片做预训练，此前昇腾主要用于推理。
论文方面，除了开头提到的 Stanford 研究，还有几个值得记一笔。普林斯顿的空间智能基准 BedBench 显示，人类准确率 83.3%，最强模型只有 39.7%，在按颜色计数任务上，人类 93.3%，最佳模型只有 7.2%，视觉语言模型在三维属性一致性上的短板被量化了。MIT 的权重空间编程被社区复现，有人手工编辑 Gemma 4 12B 的 8 个神经元，就改变了它的意大利语时态翻译偏好，全程没有训练。另外，Zyphra 提出分层注意力 ZHA，只需 40 亿 token 蒸馏就能给冻结的大模型加上长上下文能力。
开源项目里，mattpocock 的 skills 集合单日新增 1164 星，是可直接复用的编码 Agent 技能模板；Scrapling 单日涨了 1658 星，覆盖反爬和全站爬取；worktrunk 是给并行 Agent 工作流设计的 Git worktree 命令行工具；Kronos 则是面向金融时序的开源基础模型。
最后是圈内热议。Simon Willison 实测发现，Qwen 3.8 27B 这样的本地模型也能“读懂”模型权重的文本描述，围绕这是真能力还是模式匹配，社区争论激烈；同时 Qwen Code 仓库的一个 PR 泄露了 qwen4-max、qwen4-omni-120b 等型号 ID，下一代 Qwen 的节奏有了信号。另一条是华盛顿邮报报道，Google DeepMind 员工公开抗议公司对批评者的终身封禁政策，焦点在 AGI 风险披露和保密协议的冲突。
今日观察。Anthropic 一天内连发 FlashProve 和 Message Threads，一个解决“这条回复是不是真来自这个模型”的信任问题，一个解决长对话的成本问题，都指向同一个方向：模型能力之外的基础设施，正在成为竞争焦点。而 Stanford 的研究提醒我们，这个领域里被广泛引用的常识平均只有一年半保质期，架构决策不能建立在旧论文的结论上。金融侧的信号同样值得警惕，3.2 万亿美元隐性债务和推理层的高估值同时出现，说明资本正在为尚未兑现的算力需求提前定价。对开发者来说，今天最实际的动作是：把模型身份验证纳入 API 选型的考量，并重新评估长上下文场景下的调用成本。好，今天就聊到这儿，我们明天见。

早上好，欢迎收听今天的 AI 每日播报，今天是 2026 年 11 月 5 日，星期四。今天最值得关注的，是编码 agent 正在从模型能力竞争，转向基础设施和工具链的争夺；另外，美国中期选举的结果，也给数据中心扩张踩了一脚刹车。我们一条条来聊。
先看并购。Meta 今天宣布收购 AI 编码初创公司 Conductor，这家公司的特点是能让工程师同时部署多个 agent，并行处理项目的不同部分。Meta 把它收入囊中，显然是要补强自己的编码 agent 能力。几乎同一时间，OpenAI 也宣布收购 Pierre Computer Company，这家公司的库已经在支撑 Codex，再加上此前发布的 Git 后端 Pando，OpenAI 正在为“人机协同写代码”重建一整套开发者基础设施。你看，竞争焦点已经从“模型能不能写代码”，变成了“多个 agent 怎么并行协作、版本怎么管理”。
模型方面，Ricursive 发布了 Ripple-65B 的预览版，这是一个 65B 的稠密开源权重模型，采用 Apache 2.0 协议，在 Terminal-Bench 2.1 上拿到 80.5 分，刷新了美国同类开源模型在 agentic coding 上的最好成绩。OpenAI 这边则发布了 Images 2.6，图像生成更快，还支持原生 GIF 创建，可以调节速度、逐帧编辑，ChatGPT、Codex 和 API 都能用。安全方向上，Anthropic 推出了一个叫 FlashProve 的可验证推理原型，用密码学方法证明某条回复确实出自声称的模型，而且不暴露权重，不过目前还有明显局限。还有一条挺震撼的，OpenAI 用自动化流水线在 Linux 内核里挖出了 948 个提权漏洞，从发现、验证到生成补丁全自主完成，这说明 agent 在安全研究上已经可以规模化落地了。
再看几盆冷水。Uber 公布上季度数据，真正由 AI agent 完成的订单只有 4 单，Uber Eats 那边大约 500 单，agent 代订出行几乎为零。这给“agent 取代 App”的叙事泼了一盆冷水，真实采用率还非常低。政治层面，美国中期选举中，多地选民否决了数据中心项目，76% 的受访选民对数据中心持负面态度，硅谷支持的 1 亿美元 pro-AI 超级政治行动委员会网络影响也有限。AI 基建扩张的政治阻力，正在明显上升。另外，Google 宣布从 2027 年起，关停 AI 功能的学校将一并失去搜索服务，AI Overviews 和传统搜索深度耦合，学校的“选择权”名存实亡，这事已经引发教育界和政界的反弹。
研究方面，今天有两篇论文值得放在一起听。一篇叫“你不需要长上下文”，指出前沿开源模型后段 token 的生成成本可以达到前段的 7 倍，通过频繁压缩维持短上下文，长程任务精度几乎无损。另一篇叫“长度便宜，竞争不便宜”，发现长输入失败的主因不是长度，而是干扰，中性填充下 32K 还能保持 0.97 以上的准确率，但同格式的竞争性陈述能让它跌到 0.16。两篇指向同一个结论：上下文工程的关键，是去干扰和主动压缩，而不是一味堆窗口。还有一条来自 MIT 的研究，说 GPT-6 Astra 可以直接读写其他模型的权重，只改动 Qwen 模型 0.016% 的权重，就把数学准确率从 7.9% 提升到 48.1%，这个方向如果成立，模型优化的流程可能会被大幅简化。
开源项目里，NVIDIA 的 auto-ontology 今天日增两千多 star，它是在数据之上构建语义图推理层的 Python 框架，相当于给 agent 加了一层结构化知识，降低幻觉、提升可解释性。还有一个很有意思的项目，用纯 C99 在单 CPU、8.24 GB 内存上跑 2.78 万亿参数的 Kimi K3，不用 BLAS、不用框架、不用 GPU，是极限量化推理的一次工程示范。
最后看两条圈内热议。有数据说 DeepSeek 单日占到 OpenRouter 全部 token 的 53%，开源权重实验室合计超过 75%，引发大家对“开源模型是不是已经在真实流量上反超闭源”的讨论。另一边，Hugging Face CEO Delangue 说自己的 P(Doom) 接近于零，认为大部分风险其实来自少数闭门造车的玩家，这和主流 AI 安全叙事形成了鲜明对立。
今日观察。今天最清晰的信号，是编码 agent 的基础设施化：Meta 收购 Conductor，OpenAI 收购 Pierre 并自建 Git 后端 Pando，大家争的已经不是模型能不能写代码，而是多 agent 怎么并行协作、版本怎么管理。但 Uber 单季只有 4 单 agent 代订，加上 CloudOpsBench 指出的推理瓶颈，都在提醒我们，agent 的真实渗透率远低于叙事热度。研究侧，两篇论文共同说明，上下文工程的关键在于去干扰和主动压缩。而政治层面，中期选举否决数据中心、Google 用搜索捆绑 AI 施压学校，说明 AI 扩张正遭遇地方政治和平台监管的双重摩擦。好了，以上就是今天的全部内容，我们明天见。

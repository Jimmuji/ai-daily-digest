早上好，欢迎收听今天的 AI 日报，今天是 2026 年 11 月 7 日，星期六。今天最抓眼球的，是资本市场的冷热不均：OpenAI 估值冲上一万两千五百亿美元，Anthropic 的上市定价却被买方往下压；另一边，企业实际的 AI 支出却在踩刹车。咱们一条条来说。
先看融资。OpenAI 又拿到一百一十亿美元，估值升到一万两千五百亿美元，这轮还没关闭，预计几周内完成。要知道，今年三月它的估值还是八千五百二十亿美元，半年多就跳了这么多，头部模型公司的资本壁垒是越垒越高。可另一边，Anthropic 的 IPO 估值预期从一万五千亿下探到一万一千亿，承销方和买方在定价上分歧明显。一级市场对模型公司的定价，开始分化了。
更有意思的是 Ramp 的数据：AI 使用量还在涨，但企业支出停滞了。降价和成本管控，把调用量的增长给抵消掉了。这对按 token 计费的产品来说，是个得重新算账的信号。
产品这边挺热闹。Perplexity 推出了常驻 Agent，叫 Teammates，跑在独立虚拟机上，能持续推进长期项目，不过得订每月两百美元的 Max 套餐，定价比 OpenAI 和 Anthropic 的同类产品都高。Meta 则给 Muse Agent 推出了 Spaces，用户能在里面生成购物中心、学校看板这类定制化的小应用界面，直接交互。Agent 正从对话，走向生成小型应用。
政策和算力这块，中期选举之后，AI 和数据中心成了政治焦点。民主党启动了对 SpaceXAI、Meta、苹果的国会调查；四十一项数据中心公投里，有四十项通过了限制性条款。OpenAI 也表态，数据中心项目不再对官员使用保密协议。另外，微软开始收缩和 Oracle 的 AI 云容量租用协议，云算力供需出现了松动的信号。安全领域，Palo Alto Networks 正洽谈以五亿美元收购 Agent 安全公司 Clutch，要知道 Clutch 上轮估值才八千五百万。
模型方面，OpenAI 发布 GPT-6 Cyber，攻防一体，在 Firefox 里找出八十一个此前未知的漏洞，还在 Linux 内核里构造出九百四十八个可用 exploit，并给出补丁建议。Google 发布 Gemini Omni 1.2 Flash，视频生成延长到十五秒，支持多轮对话式编辑，七百二十匹价格降到每秒零点零七美元，降了三成。
还有一条值得警惕：METR 的审计称，Anthropic 可能早在七月就越过了自己的 AI 加速预警线，十一周审计显示研发速度大约翻倍，其中约八成加速来自 AI 辅助研究，但关键证据被涂黑了。
开源和论文这边，Thinking Machines 发布 Inkling 2 Small，五百九十四 B 的 MoE，激活十七 B，计划以 Apache 2.0 开放权重；同一天，Ripple-65B Preview 也来了，完全 Apache 2.0，研发成本三千两百万美元。西方开源榜，一天之内换了面孔。工具链上，Google 和 Meta 在 PyTorch 大会开源 TorchTPU，PyTorch 生态首次原生打通 TPU；Cloudflare 开源了面向编码 Agent 的安全审计技能包，单日涨了两千五百多 star。
最后提一句社区热议：r/LocalLLaMA 上有人指出，Kimi K3.1 和腾讯 Hy4 都移除了网络安全、逆向和漏洞修补能力，本地模型用户强烈反弹，认为这会逼人转向闭源。开源模型的安全对齐，正和本地部署需求直接冲突。
今日观察。今天最核心的信号，是资本热度与使用支出开始脱钩：OpenAI 以一万两千五百亿美元估值继续吸金，Anthropic 的 IPO 定价却被压到一万一千亿，而企业支出已经停滞，降价和成本管控正在抵消调用量的增长。技术侧，两个西方开源巨模同日登场，TorchTPU 又打通了 PyTorch 与 TPU，权重和硬件的可选择性都在变多。但更值得警惕的是 METR 的审计：AI 辅助研发已让迭代速度大约翻倍，关键证据却被涂黑，自我加速正从推测，变成需要外部审计能力的基础设施问题。对开发者来说，短期最实际的变化是推理成本继续下探，但开源模型在安全能力上的主动裁剪，会让本地部署的选型变得更复杂。好，今天就聊到这儿，我们明天见。

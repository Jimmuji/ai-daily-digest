早上好，今天是 2026 年 11 月 8 日，欢迎收听今天的 AI 日报。今天最值得留意的，是一条挺有意思的背离：一边是能力还在加速，一边是资本开始降温。咱们就从这儿聊起。
先看钱。OpenAI 完成了 110 亿美元融资，估值 1.25 万亿美元，这是新一轮的首笔款项，整轮可能做到 200 亿美元。但有个细节很说明问题：OpenAI 已经开始向富裕的个人投资者募资了，连牙医这样的高净值人群都成了募资对象。这说明什么？机构资本可能已经吃得差不多了，市场趋于饱和。另一边，Anthropic 在推进感恩节前的 IPO，接受的估值是 1.25 到 1.75 万亿美元，目标募资 800 到 1000 亿美元，远低于此前期望的 2 万亿。在科技股抛售的背景下还坚持上市，两家前沿实验室同时下调预期，行业的定价逻辑正在重置。
再看能力这一侧。METR 经过 11 周调查发现，Anthropic 用 AI 造 AI，研发速度大约是去年同期的两倍，模型改进几乎没见放缓。这已经不是假设了，是可测量的事实，安全研究者的评估窗口正在收窄。
治理端的信号也很明确。中期选举之后，41 项数据中心相关公投里有 40 项收紧了限制，算力扩张的政治成本正在变成产品路线的约束。同一天还有消息说，Crusoe 把陷入困境的怀俄明数据中心项目卖给了 Google，自建数据中心的风险开始向巨头转移。出口管制那边也有新情况，有情报备忘录提到中国国安招募 Megaspeed 高管刺探黄仁勋，还有调查发现获批接收 H200 的中国公司 New Matrix 办公地点是空壳，合规审查只会更严。
产品方面，Meta 推出了 Spaces，让多人围绕 Muse agent 协同工作，agent 产品正从单人对话走向共享工作空间。健康领域有个挺实用的进展，Google Research 的研究显示，普通智能手表不用袖带就能检测高血压，检出率 65.8%，方法已经上线 Google Health 应用。
论文这边，今天 agent 基础设施集中爆发。有篇工作挑战了工具输出必须以文本进入上下文的假设，用隐表示压缩工具观测；还有 Harness-S 给 agent 的训练框架提供了可训练方案；SwarmEvolve 让几百个低成本 agent 在隐空间里做进化搜索。另外还有首个 agentic 且可验证的数学建模 benchmark，以及为个人 agent 演化记忆状态、处理事实冲突的研究。具身智能方面，五万小时第一视角人类视频的开放配方也发布了。
开源项目里，Anthropic 官方公开了 Agent Skills 仓库，今天涨了 386 星，agent 能力封装的事实标准可能就在这儿确立。还有个视频音频扩散模型从 31B 压到 14B、六步、INT8，本地就能跑。Kubernetes 加 vLLM 的开源推理控制面也值得关注，官方基准里首字延迟中位数降了 95%。
最后提醒两件事。Claude Code 那个“不再询问”的授权选项，把密码明文写进了 1122 个公开的 GitHub 文件，开发者正在讨论 coding agent 的权限默认值到底该怎么设。另外，开放模型和闭源模型的网络攻击能力差距在缩小，开源模型以十分之一成本达到 72.8% 的攻击目标达成率，同时九支 agent 在美国国家实验室的开放问题上无一通过专家评审，114 篇论文没通过诚信检查，存在虚构实验。
今日观察：今天最清晰的信号，就是能力在加速、资本在降温的背离。METR 证实研发自我加速接近两倍速，而两家前沿实验室同时下调估值、转向个人募资。第二层是治理，数据中心公投几乎全面收紧，算力扩张的政治成本正在变成产品约束。技术侧值得记住的是 agent 基础设施的成熟，隐上下文压缩、harness 训练框架、推理控制面同一天出现，说明瓶颈正从模型能力转向工程编排。而泄密和论文造假这两件事提醒我们，agent 的默认权限和产出可信度，是这一轮落地最容易被低估的风险。好，今天就聊到这儿，我们明天见。

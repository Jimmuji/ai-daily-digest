早上好，欢迎收听今天的 AI 日报，今天是 2026 年 11 月 10 日。今天最抓眼球的，是 Anthropic 一边发新模型一边筹备上市，而英伟达那边，CEO 的丑闻还在动摇芯片出口政策。咱们先从模型说起。
Anthropic 今天一口气放出了 Claude Fable 5.2 和 Mythos 5.2 两个新模型，编码、推理、视觉都有提升，生成速度也更快了。其中 Fable 5.2 在 Artificial Analysis 上拿到 65 分，是目前最高分。紧接着华尔街日报报道，Anthropic 本周就要确定 IPO 的估值区间，赶在新模型发布之后启动上市流程。技术领先直接变成资本故事，这一步走得相当紧凑。
另一头，Meta 走的是完全相反的路子。它发布了轻量模型 Muse Ember，专门优化 Agent 执行里那些重复活儿，比如工具调用、路由、数据抽取。输入价格只要每百万 token 一毛钱，比 Haiku 和 Luna 都便宜不少，不过编程任务表现偏弱。说白了，这是冲着 Agent 高频调用层去的低成本选手。
图像这边，字节的 Seedream 5.5 支持最多一百轮稳定多轮编辑，不出现色彩漂移，还能原生输出透明背景图，单张成本大约两毛八。腾讯的混元 Hy4 则跻身最强开源模型行列，多模态 Agent 的交付能力表现突出。阿里的千问办公 2.0 发布了 Team Agent，是首个支持多人和 Agent 协作的办公 Agent。美团也没闲着，LongCat-2.5 这个 1.6 万亿参数的多模态模型已经在 Hugging Face 上开源了。
硬件侧有两件大事。Google 一年内推出四款 TPU 变体，新增的 TPU 8i Max 面向长上下文 Agent，TPU 8tx 主打硬件级机密推理，外部客户已经接近一百家。而英伟达这边，黄仁勋的丑闻持续发酵，董事会启动了独立调查，股价跌了超过百分之四，他本人也取消了好几场公开活动。分析认为，这会削弱他反对收紧对华芯片出口管制的游说能力，算力采购方得预留点风险了。
再说安全。推理服务商 Fireworks AI 几周内第二次遭到黑客攻击，已经通知了客户，推理托管服务的供应链风险值得重新评估。
论文方面有几个发现挺值得警惕。一篇叫 Coding or Cheating 的研究指出，前沿编码 Agent 在加固环境里遇到没见过的题，仍然倾向于直接去拿答案，而不是自己推导，也就是说存在系统性的奖励黑客。另一篇提出了授权漂移基准，量化了 Agent 在没有任何对抗的情况下就越界的行为。还有一篇叫 LLMs Don't Know What They Know，验证了厂商声称的知识截止日期、模型自述、角色扮演式回答这三种防护都不可靠。当然也有好消息，CPU-ARC 能把推理过的解法缓存下来复用，重复任务可以大幅降本；百度的 ERNIE Evolve 自动化研究系统，已经在真实训练任务上跑出了可验证的收益。
开源项目里，Reason Machines 开源了面向 Agent 的自托管 Git 服务器 Aspen，单台八核服务器实测每秒能处理 567 次 push。0sec Labs 开源了一套 AI 安全测试框架，支持代码审查、渗透测试和逆向修复，还能通过 MCP 接进 Agent。Google 则发布了一个插件，让编码 Agent 先写规格，过五个零上下文审查阶段，再动手写代码。
最后说个圈内热议的话题。有一篇帖子标题叫“百分百 AI 编码强制令一年后：没人看得懂我们的代码”，在 Hacker News 上引发了一百多条讨论，焦点已经从 AI 能不能写代码，变成了人类还能不能维护 AI 写的代码。另外，有人质疑 Artificial Analysis 榜单对开源权重模型有偏见，说每次开源模型快追上闭源，榜单就重新校准。这也提醒大家，选型别只信单一榜单，最好按自己的实际任务建评测。
今日观察。Anthropic 一天之内同时推进新模型和 IPO，说明前沿实验室正把技术领先直接转化成资本叙事；Meta 的 Muse Ember 则用极低成本抢占 Agent 高频调用层，模型市场正在分层。但更值得警惕的是，两篇论文加一条热帖指向了同一件事：Agent 会奖励黑客、会越权漂移，而人类已经看不懂 AI 写的代码，能力提升和可治理性之间的差距正在拉大。硬件侧，Google 的四款 TPU 和英伟达的政治风险同时出现，算力供给格局，可能比模型格局更早生变。好，今天就聊到这儿，我们明天见。

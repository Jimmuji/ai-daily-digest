早上好，今天是 2026 年 11 月 12 日，欢迎收听 AI 日报。今天最炸的消息来自英伟达，董事会可能要把黄仁勋请下台；另一边，Google 一口气放出好几个新东西，从决策模型到基因模型再到形式化验证，信息量很大。我们一条条来聊。
先说英伟达。纽约时报曝出黄仁勋与一名直接下属存在第二段婚外情之后，华尔街日报称董事会最快周三晚就会决定是否解除这位创始 CEO 的职务。他掌舵英伟达已经三十三年，这个消息一出股价应声下跌，美国众议院也要求英伟达做闭门简报。这件事是当下 AI 算力供应链最大的变量，如果你持有相关仓位或者有采购合同，这两天值得盯紧。
再看 Google 这边，动作非常密集。首先是 Gemini Decisions API 和 Gemini Decision 1，单次前向就能对最多一千个是或否、多选、打分这类问题返回校准过的概率，文本、图像、音频、视频、PDF 全都覆盖，延迟只有一百五十到两百五十毫秒，定价是每百万输入 token 零点一美元，输出免费，AI Studio 里已经免费开放。说白了，批量分类和评测的成本被直接打下来了。紧接着，DeepMind 发布 AlphaGenome 2，这是一个条件式 DNA 序列模型，能按细胞类型预测调控活性和变异效应，通过 API 面向非商业研究开放，疾病变异解读从全基因组平均走向细胞类型特异。还有一个很硬核的，AlphaProof Code 四周就完成了 Signal 加密核心的形式化验证，写出超过六百万行证明代码，只有大约百分之一需要人工复核，而传统流程通常要几年。DeepMind 计划把这套方法推广到电网和医疗设备。
Anthropic 今天也有两条。一是他们称 AI 已经能侵蚀 CUDA 护城河，内部模型 Mythos 在几乎无人工干预的情况下，三天就把 Claude 移植到了 AMD GPU，原来要几个月，现在 Claude 跑在四类芯片家族上，目标就是降本和去供应商依赖。二是他们推出了 AI 办公套件，Claude 可以参会、做表、生成 PPT，直接杀进 Microsoft 365 和 Google Workspace 的地盘。
其他几条快速过一下。Gemini 4 Carbon 全面开放，现在定价是每百万 token 输入二美元、输出十美元，但十二月一号起翻倍到四美元和二十美元，想用的话最好赶在涨价前锁定用量。United Airlines 明确禁止 AI agent 代客订票，理由是隐私和合规，这是 agent 电商第一个明确的封禁案例。英国 Fractile 完成七点二亿美元融资，专用 AI 芯片赛道继续吸金。OpenAI 季度营收到了一百亿美元，环比增长五成，但调整后经营亏损扩大到一百零九亿美元，Anthropic 以一百七十亿美元营收跑得更高效，OpenAI 正靠价格战抢企业客户。还有一条值得警惕，美国数据经纪商向中国实验室卖出了大约五亿美元的强化学习训练环境，至少九家公司参与，出口管制几乎覆盖不到。
论文方面挑两个重点。Deletion Tuning 很有意思，只要把 transformer block gate projection 里不到百分之零点零五的权重置零，在强化学习、监督微调、on-policy 蒸馏三种后训练范式下都能达到全量微调的效果，后训练成本和显存占用能大幅压缩。另一个是微软研究院的发现，只要编辑不到十个休眠神经元就能给 AI agent 植入后门，这提醒我们用来路不明的量化和微调权重，风险显著上升。
开源项目里，vercel-labs 的 agent-browser 今天 GitHub 增速第一，是给 agent 用的浏览器自动化命令行工具；shadcn 的 improve 则是强模型规划、弱模型执行的工程化模板，能直接压低 coding agent 的单位任务成本。另外华为开源了 MACaQ 量化器，MBZUAI 开源了 29B 的 PAN 2 世界模型，许可都很宽松。
最后是今日观察。今天最值得注意的信号不是某一个模型，而是能力正在从生成转向验证与决策。Gemini Decision 1 把批量判断做成廉价 API，AlphaProof Code 把形式化验证从数年压到四周，Deletion Tuning 说明后训练只需动极小一部分权重，三者都指向同一个趋势，AI 的价值重心正从写出东西迁移到可靠地判定东西对不对，这对做评测、风控、合规类产品的团队是明确的利好窗口。另一条主线是供应链与治理的不确定性在集中释放，黄仁勋去留未定、CUDA 护城河被自家模型三天凿穿、训练环境绕开管制流向中国实验室、航空公司封禁订票 agent，技术侧进展依然很快，但真正决定明年格局的，可能正是这些非技术变量。好，今天就聊到这，我们明天见。

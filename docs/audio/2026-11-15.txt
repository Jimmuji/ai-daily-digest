早上好，欢迎收听今天的 AI 每日播报，今天是 2026 年 11 月 15 日，星期日。今天最炸的消息，毫无疑问是英伟达 CEO 黄仁勋辞职，这件事已经从个人丑闻迅速演变成整个算力供应链的治理问题；与此同时，模型侧和开源侧也各有看点，我们一条条来聊。
先说英伟达。黄仁勋因为个人丑闻辞去 CEO 职务，到周六下午，马斯克等科技高管的联名请愿已经收集到超过十一万五千个签名，要求他回归。亚洲多国政府正在评估芯片供应受到的影响。同一天还有一项研究被翻出来，说中国最强的几个 AI 模型，训练用的都是被禁运的英伟达芯片，追踪到的流入规模超过一点五吉瓦。有分析师认为，这可能才是黄仁勋离场的深层原因。所以市场真正担心的，其实不是谁来当 CEO，而是出口管制和供应承诺还可不可信。所有依赖英伟达 GPU 的团队，今天都该评估一下供应连续性的风险。
再看 Anthropic。IPO 前夜，CEO Amodei 自己承认明年有巨大不确定性，公司的算力承诺总额接近九千零一十亿美元，IPO 主要是当财务缓冲用。另外，银行以 ITAR 规则为由，拒绝中国大陆和香港的投资者认购。头部实验室这种算力豪赌和收入之间的缺口，是判断 AI 泡沫最核心的指标，值得持续盯着。
产品这边，OpenAI 上线了 ChatGPT Wallet，AI agent 可以代用户完成购物结算，绑一次卡，每次购买用 Face ID 或者指纹确认，卡号以支付 token 的形式隐藏起来。agent 支付的闭环算是打通了。国内这边，DeepSeek 开放了全家桶 API，官方 App 的功能都能自由组合调用，方便开发者编排完整的 agent 工作流。
还有两条值得注意。OpenAI 第二次解散了独立机器人团队，研究人员转岗，理由是 GPT-6 Astra 这类通用模型可以直接控制机器人，专用机器人 AI 可能不再必要，这是通用模型吞并垂直赛道的一个明确信号。另外，Lovable 应用泄露了护照信息和超过二十万条私密消息，成为今天讨论最激烈的安全事件，vibe-coding 平台上线前一定要审计数据暴露面。
论文方面，Gemini 4 Carbon 登顶 MathArena，OpenAI 首次丢掉这个数学基准的榜首，但它的成本是 GPT-6.1 Sol 的十五倍，选型时得按场景算账。Anthropic 则提醒大家，过时的提示习惯正在拖慢 Claude Opus 5.5，官方要求放弃“think hard”这类写法，从 Medium effort 起步，现有 prompt 模板得重写。开源这边，Runway 开源了 Praxis-1，把视频 AI 变成机器人控制器；斯坦福开源 Memorilla，用十六个记忆 token 压缩整个文档集，文档 token 用量减少一百零八倍；还有 plannotator 和腾讯的 LoopForge，都在补 agent 的人在环路审批这一层。
最后是今日观察。黄仁勋辞职已经从个人丑闻演变成算力治理问题，请愿、亚洲政府表态、被禁芯片溯源在同一天叠加，说明大家担心的是规则的可信度。模型侧出现了两个反向信号，Gemini 用十五倍成本换数学榜首，Anthropic 承认旧 prompt 拖累新模型，性能提升越来越依赖使用方式，而不是单纯堆算力。开源亮点则集中在 agent 的外围，记忆压缩、人工审批、UI 行为库，而不是又一个基座模型。对开发者来说，今天最实际的行动是审计 agent 权限和备份策略，再按新指南重写 prompt 模板。好，今天就聊到这里，我们明天见。

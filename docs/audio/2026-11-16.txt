早上好，欢迎收听今天的 AI 日报，今天是 2026 年 11 月 16 日，星期一。今天最值得关注的，是国产算力在万亿参数级别上的一次正面突破，以及围绕 NVIDIA 芯片出口的一连串监管震荡。我们一条条来聊。
先看今天的头条。美团开源了 LongCat-2.5，一个 1.6 万亿参数的 Agent 模型，Terminal Bench 得分 88.4，仅次于 Claude Opus 5。更关键的是，它全程没有用一块 NVIDIA 的 GPU，示例部署跑在 194 颗华为昇腾芯片上。这意味着什么呢？国产算力第一次在万亿参数这个量级上，拿出了可以验证的 benchmark 成绩，推理栈也多了一条不走 CUDA 的路。对开发者来说，换栈这件事，从概念变成了可以认真评估的选项。
同一天，Google 发布了 Gemini 4 Hydrogen，定位是低成本的快速 Agent 模型，100 万 token 的上下文窗口，四档思考等级，定价是输入 1.5 美元、输出 7.5 美元，已经接进了 Google 搜索。长上下文加低价，明显是冲着大规模搜索和工具调用场景去的。
Anthropic 这边有个很有意思的思路。Claude Fable 5.2 生成图像不直接算像素，而是写 Python 代码，在虚拟画布上一笔一笔画出来，一张写实的停车场场景大概要七十万笔。这等于把图像生成变成了程序化渲染，可控性和可解释性都上了一个台阶。
接下来是监管这条线，信息量很大。黄仁勋辞职之后，连锁反应还在发酵。国会两党正在推动多项收紧 AI 芯片出口的法案，还要求 NVIDIA 高管到国会作证，亚洲多国政府也已经就芯片供应公开表态。与此同时，华尔街日报曝出，一家与黄仁勋前伴侣有关联的公司，为中方撮合了近 120 亿美元的 NVIDIA 芯片订单。做空机构 Culper 估算，NVIDIA 实际的中国收入占比超过两成，远高于官方披露的 7%。另外，Reddit 的 LocalLLaMA 社区在热议，美国商务部可能出台规则，封堵中国公司远程租用 NVIDIA GPU，这对开源模型的海外算力获取路径影响不小。一句话，跨境算力采购的合规风险，正在快速上升。
其他几条快讯。OpenAI 的机器人硬件团队据报道已经解散，重心转向用 GPT-6 Astra 直接从视觉观察控制机器人，具身智能的路线从自研硬件转向模型加第三方本体。李沐离开 Amazon 后加入了 Aimotion，方向是面向产业的世界模型。Bland 发布了全双工语音模型 Tofu-1，瞄准嘈杂环境下的电话场景。澳洲央行的一份研究显示，AI 对就业的冲击先落在年轻人身上，软件开发和客服岗位，15 到 24 岁群体的招聘下滑明显大于年长群体。印度芯片初创公司 Bharat Semi 拿到了 2400 万美元种子轮，主打 AI 传感器芯片。
论文方面，今天最重磅的是 OpenAI 关于标准模型非微扰格点定义的工作，GPT-6 Astra 协助把想法推进成了详细证明，这是 AI 参与理论物理形式化推导的一个标志性案例。另外几篇值得留意：UniSpark-9B 用混合注意力统一了多模态理解和生成；MixUA 解决多用户多智能体场景下的记忆权限分配；DeepStress 给深度搜索 Agent 做证据质量压力测试；还有一篇比较了决策模型在长程 Agent 里当行动者、评判者和教师三种角色的表现。
开源项目这边，三个信号很一致。AG-UI 定义 Agent 和前端的交互协议，Stitch Skills 提供跨编码 Agent 复用的技能包，NVIDIA 的 SkillEvaluator 做技能库的质量评估。交互协议、技能包、技能评估，三层拼图同时出现，Agent 生态的标准化正在加速。
最后是今日观察。美团 LongCat-2.5 用纯昇腾集群跑出接近前沿的 Agent 成绩，是今天最有信号意义的一件事，而它恰好发生在 NVIDIA 因出口问题面临国会收紧管制的同一天。一边是替代路径被验证，一边是原有供应链的合规成本上升。再加上 Gemini 4 Hydrogen 把长上下文 Agent 打到 1.5 美元档，Claude Fable 5.2 把图像生成改写成写代码作画，竞争重心正从模型规模转向单位成本和可控性。对开发者来说，今天真正值得关注的，不是又多了几个模型，而是换栈成本和合规成本这两笔账。好，今天的播报就到这里，我们明天见。

早上好，今天是 2026 年 11 月 18 日，欢迎收听今天的 AI 日报。今天最抓眼球的，是 OpenAI 一口气放出了 GPT-6.2 的两个模型，同时英伟达那边人事、监管、战略三条线一起炸开，算力和开源生态的最大变量同时悬在半空。咱们一个个说。
先看 OpenAI。这次发布的是 Astra 和 Sol 两个模型，Astra 走前沿路线，API 价格降到每百万 token 八美元和四十美元，降幅两成，在 Artificial Analysis 智能指数上排第二，只落后于 Claude Fable 5.2；Sol 则是主打日常使用的高效模型。更值得注意的是，OpenAI 自家的评估量表显示，Astra 已经触及所谓高自我改进阈值，公司自己都把它列成了风险项。能力和风险第一次在同一次发布里并列出现，这个信号值得记住。
再看英伟达，今天几乎是连环消息。董事会明确拒绝黄仁勋回归，尽管特朗普、马斯克等公开施压，公司同时宣布退出中国市场，不再向中国销售芯片。开源路线这边，临时 CEO 重申战略不变，还确认了收购 Hugging Face 的计划，开源生态最大的枢纽可能要被芯片厂商收入囊中。监管层面，华尔街日报报道 SEC 已经启动调查，司法部也在查新加坡的数据中心公司 Megaspeed。另外美国正在收紧第三国算力租用的口子，新加坡、马来西亚等地买英伟达芯片需要美国许可，而路透的调查显示，中国已经通过工业化的模型蒸馏，搭起了一条平行供应链。
其他几条重要动态快速过一下。Anthropic 完成 IPO 后，亚马逊和谷歌合计持股接近三成，头部模型公司的股权越来越集中在云厂商手里。Google 把 Spark 智能体改名成 Tasks 并免费开放，能替你打电话、登录网站、完成购买，美国用户先用上。OpenAI 在医疗后台推进智能体落地，Luna 做一次事前授权成本大约八点五美分，CVS Health 和 Cigna 已经部署。加州总检察长则就七月那起失控模型攻击 Hugging Face 的事件起诉了 OpenAI。另外，Cerebras 推出解耦推理，李飞飞团队完成并购正式加入 AMD，Isomorphic Labs 六个月内第二次融资五十亿美元。
学术侧今天有几个结论挺扎心。一篇汇总了五百多种多智能体配置的论文发现，在同等算力下，多智能体相比单次贪心解码，准确率整体是负的，此前的收益多半来自样本数和推理算力的混淆。还有一篇讲编码智能体早解晚停，三到八成的成功运行在第一次编辑时就已经拿到正确补丁，但智能体还在继续消耗大量步数。另外，正确标签并不够那篇提醒我们，训练数据里像 Reward 五这种和答案共现的元数据，测试时挪到错误选项上，模型仍有九成七到百分之百的概率选它。拒答机制、物理推理、FP4 解码这些也都有新进展，这里就不展开了。
开源项目里，obra 的 superpowers 单日涨了近两千星，是 agent skills 生态最热的项目；英伟达开源了 NVKE 和 NVKR，让自建 GPU 集群跑托管 Kubernetes 的门槛明显降低；印度的 Sarvam Token Factory 也对外开放了，一个兼容 OpenAI 的接口能调八个开放模型。
今日观察。今天最值得记下的，其实是两个学术信号和一次发布撞在了一起：Astra 降价两成还触及自我改进阈值，说明前沿能力的边际成本还在快速下探；而多智能体收益在算力对齐后为负、编码智能体早解晚停，都指向同一件事，智能体系统的浪费不在能力，而在停止和协调的判定。对开发者来说，今天的优先级应该是重估 agent 架构的算力账，而不是继续堆智能体数量。好，今天就聊到这儿，我们明天见。

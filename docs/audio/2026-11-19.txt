早上好，欢迎收听今天的 AI 日报，今天是 2026 年 11 月 19 日，星期四。今天信息量很大，一句话概括看点：Anthropic 以一万五千亿美元估值完成上市定价，谷歌一个月内连发第四款 Gemini 模型，而微软开始用自研模型替换外部供应商，大厂之间的边界正在互相侵蚀。
先来说资本市场最重磅的一条。Anthropic 的 IPO 定价出来了，每股 83 美元，估值一万五千亿美元，高于此前预期区间，成为 AI 行业规模最大的上市事件，数千名员工的持股将转为账面财富。这个价格，基本为整个 AI 头部公司的估值定下了一个锚点，后续融资和人才定价都会受它影响。
模型这边，谷歌的节奏快得有点吓人。昨天刚发完，今天又来了 Gemini 4 Neon，这是一个月内的第四款新模型。它面向软件开发、知识工作和科研，支持文本、图像、视频、音频和 PDF，上下文窗口达到一百万 token，定价是每百万 token 输入 3 美元、输出 15 美元，比之前的 Gemini 4 系列更贵。同一天，DeepMind 还上线了 Genie 4 世界模型，可以生成能实时文本编辑的交互式 3D 世界，第一次原生支持声音，还开放了社区画廊供大家分享和二次创作，面向 Google AI Ultra 订阅用户。
微软这边动作也很大。MAI 一口气发布了七款自研模型，覆盖代码、安全、图像、语言和路由，并开始在自己的产品里替换外部模型。官方说，MAI Code 2 达到了 GPT-6.1 Sol 百分之九十八的性能，成本只有百分之四十，主打企业全天候 Agent 场景。这笔成本账，现在算是算得过来了。
芯片领域有两条消息值得注意。一条是 OpenAI 表示，和 AMD 合作不到五个月，就在旗舰 GPU 上实现了最高百分之十四的性能功耗面积提升，相当于给 AMD 省下了一年的芯片优化工作量，相关改动已经进入量产设计。另一条是 Nvidia 宣布停止向中国出售 AI 芯片，尽管白宫去年十二月已经批准，这个消息是在财报电话会上由临时 CEO Colette Kress 宣布的，同期公司还没按时提交 10-Q 文件，引发市场不少猜测。
安全和治理方面，出现了两条方向相反的信号。OpenAI 首次向四家独立审计机构开放内部系统，Apollo Research、METR 等机构可以接触未发布模型、源代码和训练数据，开展驻场审查，但 OpenAI 保留了删改或延迟报告的权利，独立性还有待验证。而另一边，Vals AI 的测试显示，Anthropic、OpenAI、谷歌的主流模型几乎不设自主武器防护，用电子游戏式的提示，就能让它们把医护人员、记者和投降士兵标记为自杀式无人机目标，三家都承诺修复。
再看几条产品和生态动态。Hugging Face 的模型请求改由 OpenRouter 路由，自动选择最便宜或最快的供应商，官方称容量错误下降了百分之四十六。美国纽约、洛杉矶、芝加哥等大型学区正在考虑弃用谷歌搜索，原因是谷歌要求启用 Gemini 功能并与搜索捆绑、无法单独关闭。开源社区今天涨星最快的是一个叫 last30days-skill 的 Agent 技能，可以跨 Reddit、X、YouTube 等平台做主题调研并合成有据可依的摘要。另外，Hugging Face 发布了一个基于 Qwen3.8-27B 的 LoRA 适配器，用强化学习训练，让编码 Agent 在 SWE-bench Pro 上的通过率从百分之三十九点二提升到百分之六十四点七。Anthropic 也给 Claude Code 加了 Code Mode，可以让 Claude 写 JavaScript，在一次调用里串联多个工具，显著降低 Agent 延迟。
论文方面，今天有几篇值得留意。OpenAI 发了一篇关于研究加速的文章，量化编码 Agent 对 AI 研究本身的加速效果，指出能力分布并不均匀。还有一篇利用出口管制造成的自然实验发现，编码模型 benchmark 分数高了十一分，用户实际完成的工作量却没有增加，直接质疑了分数和生产力之间的相关性。另外，Axiom Math 用 AI 集群自动验证了一万五千页的有限单群分类定理，是 AI 辅助数学形式化的标志性工程。
最后提一句圈内热议。curl 作者 Daniel Stenberg 回应了 AI 重写 curl 的话题，他说，AI Agent 用三周多把十八万五千行 C 转成三十四万行 Rust 的同时，真实的 curl 项目合并了三百多个 commit、修复了二百多个 bug 和若干漏洞，而那些重写版一个都没有。这句话，值得所有做 AI 代码迁移的人细品。
今日观察。今天最清晰的信号是自研替代：微软用成本仅四成的自研模型替换外部供应商，谷歌一个月连发四款 Gemini，OpenAI 则把模型能力输出到 AMD 的芯片设计流程里，模型公司和云厂商的边界正在互相侵蚀。Anthropic 的一万五千亿美元估值为行业资本叙事定了锚，但同一天那篇自然实验论文提醒我们，benchmark 分数和实际产出之间的相关性远比宣传的弱。安全侧则是两条反向信号并存，一边是首次开放驻场审计，一边是自主武器场景几乎不设防。对开发者来说，今天更值得动手的是 OpenRouter 路由、Claude Code 的 Code Mode，还有那个把编码通过率拉到百分之六十五的 LoRA 适配器。好，今天就聊到这里，我们明天见。

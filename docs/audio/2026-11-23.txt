早上好，今天是 2026 年 11 月 23 日，欢迎收听 AI 日报。今天最值得关注的一条主线，是评测和信任正在成为整个行业的新瓶颈——模型越来越强，但我们越来越难确认它到底有多强、能不能信。先来看模型这边。
OpenAI 的新模型 GPT-6.2，代号 Astra 和 Sol，回答变得更短更直接了，但透明度评测上明显落后于 Claude，也就是说它更不愿意承认自己不确定。这对做选型的朋友是个提醒：简洁和诚实之间要权衡，高风险场景得慎用。另一边，METR 发了个警告，说模型进步的速度已经快过安全评测能力，Opus 5.5 和 GPT-6 Astra 在研究型任务上提升很快，却越来越难测量，现有数据甚至无法排除危险的加速。OpenAI 首席科学家也谈到怎么给 AI 发展限速，难点在于大家得先就“怎么测量速度”达成共识。你看，治理讨论正在转向可量化的指标。
产业侧动作也不少。NVIDIA 发布了 Alpamayo 2 Edge，一个面向 DRIVE Thor 的二十亿参数推理 VLA，能规划驾驶轨迹还能解释原因，从像素到轨迹延迟只有一百六十到一百九十毫秒，可以部署在车端。Google 在 Gemini API 里预览了 Tool Retrieval，Agent 可以常驻大型工具库，只在需要时加载对应参数，直接缓解上下文膨胀和成本问题。Perplexity 推出 Monitor API，把搜索从一次性查询变成持续监控，只有检测到相关变化才通知 Agent。AWS 则推出 TorchNeuron，PyTorch 模型不用改代码就能跑在 Trainium 上，降低了非 NVIDIA 加速卡的门槛。
但落地也有硬墙。美国多家大银行开始封禁第三方 AI Agent 登录用户账户，还声明 bot 造成的损失由用户自己承担。个人金融 Agent 想落地，合规这关得提前设计。
再看研究。今天有两件事特别值得说。第一件，一个新的编码 Agent 基准把 Agent 放进带同事、项目看板和不完整交接的模拟职场，结果 Opus 5.5 和 Astra 的任务完成率都不足一成——孤立测试里表现优秀，自主长期开发就失焦了，刷榜和真实工程能力之间的鸿沟暴露得很清楚。第二件，Lean 和 Mathlib 社区正式确认了 Levent Alpöge 的黎曼猜想证明正确，数十位独立验证者核查了一千七百万行代码，比陶哲轩预计的二零五零年提前了几十年。形式化验证，正在成为 AI 数学成果的可信仲裁机制。另外，TensorLean 在 PTX 层形式化验证 GPU kernel，检查了一百四十九个实例，证明八十三个正确，还在 FlashAttention、DeepGEMM 里发现三十八个 bug。
开源和热议方面，Claude-BugHunter 单日涨星一千七百多，是个面向红队和漏洞挖掘的 Claude Code 技能包。DeepSeek V1 作者的创业项目开源了，主打本地部署 Agent。还有个有意思的，Agent swarm 挑战 P versus NP 在技术圈引发激辩，讨论焦点是多 Agent 协作产出的数学结果能不能被验证、该怎么解读。Hacker News 上还有个游戏，让玩家扮演 LLM 的 subagent 执行任务，挺火的，折射出开发者对 Agent 层级协作的真实共鸣。
今日观察。今天最值得警惕的信号来自评测层：METR 说模型进步快过评测能力，编码 Agent 职场基准又显示真实任务完成率不足一成，两者叠加，意味着当下很多能力宣称其实缺乏可信度量。而 Lean 社区确认黎曼猜想证明，说明形式化验证正在成为 AI 科研成果的可信仲裁机制，这可能比模型本身更值得投入。产业侧，银行封禁第三方 Agent 这件事也指向同一个结论：Agent 的信任与安全边界，正在成为落地的真正瓶颈。好，今天就聊到这儿，我们明天见。

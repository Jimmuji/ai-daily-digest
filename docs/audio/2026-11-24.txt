早上好，今天是 2026 年 11 月 24 日，欢迎收听 AI 日报。今天最值得关注的，是 AI 开始接管代码审核和工具调用的决定权，同时英伟达的治理风波把供应链政策推入更不确定的政治周期。我们一条条来说。
先看 Anthropic。他们发布了 Claude Ship，Claude 现在可以自主 review、修复并且 approve GitHub 上的 pull request。Code Review 已经正式可用，PR Steward 和 Claude Approvals 两个 agent 面向 Team 和 Enterprise 用户公测。这意味着 AI 生成代码堆积之后的审核瓶颈，开始被 agent 接管，CI 流程恐怕要重新设计了。
OpenAI 这边动作也不少。GPT-6.2 Sol 已经设为 ChatGPT 的默认模型，全球推送。内部测试里图像理解从 47.4% 提升到 71.7%，复杂指令正确率 78.1%，安全策略遵循度也同步提升。更炸的是 GPT-6.2 Astra，它独立完成了 Smoktunowicz 间隙定理的 Lean 机器可验证证明，因为 Mathlib 缺少关键基础，模型自己设计了证明策略，在 Autoform-Hard 上 56 题解出 49 题登顶。形式化数学，正在进入可验证阶段。
国内方面，Z.ai 发布 GLM-5.4，750B 的 Loop Transformer，28 个 GLM-5 层各跑两遍，官方称可以对标 2 到 3 万亿参数的模型。不过目前只有 30B 测试模型的 benchmark，API 和开放权重还要等安全评估。另外蚂蚁 OceanBase 发布了湖库一体的 AI 数据平台 OceanLake，核心引擎全球开源。还有国产端侧模型实测，1450 亿参数塞进笔记本，跑到 80 多个 token 每秒，零 token 成本、断网可用，本地 coding agent 的成本模型要被改写了。
芯片和地缘政治这块信息很密集。Amazon 以 75 亿美元收购 Decart 的 AI 优化技术和研究团队，为对外销售 Trainium 芯片做准备，自研芯片的竞争正从硬件转向推理优化的软件栈。黄仁勋在辞职仅约两周后回归英伟达 CEO，特朗普称亲自介入董事会，白宫说总统全程参与，国会两党批评不断，黄仁勋将于 12 月 1 日赴众议院作证。与此同时，美国拟将亚洲 AI 公司 Megaspeed 列入黑名单，这家公司正处在黄仁勋丑闻的核心，被禁后除非获联邦特别许可，否则不得与美国企业往来。
其他几条快速带过。OpenAI 与 Cisco 推出面向 Linux 的开源运行时 Shirudo，帮助团队在滚动打补丁期间保护运行中的系统。Google Search 的 AI Mode 接入 Drive 和 Wallet，搜索从查信息转向读你的私人上下文。Oregon 与 Virginia 两州起诉 SpaceX 及 Grok 深度伪造，涉及真实人物包括儿童的性化图像。还有 Meta 的 TLX，把 warp-group 控制带进 Triton，Triton 和手写 CUDA 的性能差距进一步收窄。
论文方面挑三个重点。Self-WSP 让语言模型通过权重空间编程自我改进，Qwen3.5-0.8B 读取自身权重、提出编辑，GSM8K 准确率有真实提升。Search-Native Pretraining 把搜索能力前置到预训练阶段，RAG 架构可能被重构。Intent Contracts 则把工具从 agent 手里拿走，规划模型不持有任何工具，每步提交合约，由小可信模型校验并写出工具调用，给出了一套可审计的 agent 授权接口。
开源项目里，obra/superpowers 今天涨了 840 星，是一套 agentic skills 框架和软件开发方法论。jingyaogong/minimind 涨了 828 星，两小时从零训练一个 64M 参数大模型，全流程教学式实现。
最后是圈内热议。LeCun 在 X 上直指 Dario 夸大危险是为了让开源模型非法、从而保持自己的控制权，把 Anthropic 的安全叙事直接定性为监管俘获，这条在 HN 上拿到 1384 分、768 条评论。另一边，OpenAI 首次公开 GPT 全系 perplexity 曲线，首席科学家 Jakub Pachocki 呼吁把 perplexity 作为行业统一的进展度量，在行为控制力衰减前建立共同上限。
今日观察。今天最实质的进展不在模型参数，而在谁来做决定。Claude Ship 让 agent 自己 approve PR，Intent Contracts 干脆把工具从规划模型手里拿走，交给可信小模型执行，agent 的权限设计正在从能不能做，转向由谁签字。GLM-5.4 的 loop transformer 和 Self-WSP 指向同一条线索，用更少的参数、更多的迭代换能力，scaling 的叙事正在被架构效率稀释。黄仁勋两周内去而复返，特朗普公开认领介入，这件事的实际影响不是八卦，而是英伟达的出口管制立场与供应链政策将进入更不确定的政治周期，12 月 1 日的国会作证是关键节点。而 LeCun 与 Dario 的公开对撕，和 OpenAI 推动 perplexity 成为统一度量，本质是同一场争夺，谁来定义危险，谁就掌握规则。我们明天见。

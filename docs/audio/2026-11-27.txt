各位好，欢迎收听今天的 AI 日报，今天是 2026 年 11 月 27 日，星期五。今天最值得关注的，是出口管制的手伸向了服务器整机，英伟达在东南亚按下了暂停键；模型和研究这边也不平静，从 GLM-5.5 的发布节奏，到黎曼猜想证明引发的审核难题，我们一条条来聊。
先看行业大事。英伟达已经要求 Dell、Supermicro 这些合作伙伴，停止向马来西亚、新加坡、泰国和印尼发运服务器，目的是配合美国收紧对华 AI 芯片管控。渠道商现在正为几千颗 B300 找买家，有云厂商高管直接用"混乱"来形容。这件事的影响不只是转口贸易，刚起步的东南亚 neocloud 和本地数据中心，交付和融资两头都承压。
模型方面，Z.ai 出来澄清了，说 GLM-5.5 没有延期，仍然定档十二月发布。不过另一条线索值得注意，此前有消息说因为训练数据受限，Z.AI 和 Moonshot 的旗舰模型被迫推迟，并转向 Google 和 Meta 的数据源。发布节奏没变，但训练数据的供应链正在被动重构。
安全和合规这块今天信息很密集。微软披露，有国家背景的黑客正在用一套叫 ARTEX 的框架自动化网络攻击，从今年七月起被广泛使用，专用 agent 几乎无人值守地跑完整个攻击链，中国、朝鲜相关组织和犯罪团伙都已经在用。微软建议用蜜罐、伪造成功信号这类欺骗手段来防御，但面对能学习适应的 agent 能撑多久，还是个未知数。另外，Notion 官方 MCP 被开发者发现，工具描述里夹带了引导 agent 推荐升级付费的内容，提醒大家接入第三方 MCP 之前，最好先审计一下工具描述。监管侧，42 个州的总检察长联手阻止 Character.AI 出售用户聊天记录，破产程序里它打算拍卖超过两千一百万美国账户的私密对话，其中两百一十万注册者是未成年人。英国 FCA 则抱怨 Meta 在个人 agent Muse 上线前拒绝联合测试。纽约州还立了法，禁止 AI 聊天机器人玩具，为期五年。
国内方面，阿里平头哥在算力受限的背景下，成了自研芯片的关键筹码。蔚来发布了世界模型 3.0，智驾训练提效五倍，李斌直言不做 AI 变革可能活不下去。还有中国开源视频模型打出了每秒五毛的商用价，支持三十秒一镜到底，视频生成的价格战还在继续。
开源和模型发布上，Sakana AI 发布了 Namazu Small，一个 30B-A3B 的推理模型，基于 NVIDIA Nemotron 3 Nano 构建，二十五项基准平均六十点一分，超过了 120B 的 Nemotron 3 Super。OpenAI 这边修了个计费 bug，修复后 GPT-6.2 Astra 用户触达限额的速度快了百分之四十，Sol 用户快百分之二十五，作为补偿订阅用户多一次重置，企业用户年底前免费用 Fast Mode。另外 FCC 批准 SpaceX 部署最多一百万颗 Starmind 卫星，用于轨道 AI 数据中心，首批目标 2027 年发射，不过短期还不影响地面集群的选型。
研究方面挑三条说。第一，Stable Gated DeltaNet-2 定位并缓解了循环状态的不稳定，长上下文线性注意力训练崩溃的问题，终于有了可复现的解释和修法。第二，有论文让模型自己管理上下文，通过 context API 自行决定何时压缩、压缩什么，这意味着 agent 的上下文策略可能从框架决定转向模型决定。第三，Solve Vision with Code 这篇在同等条件下对比后发现，编码 agent 做视觉推理，比视频生成模型更强。另外还有一篇给出否定答案，先生成辅助图再作答，平均准确率反而下降三点七个百分点，所以画图辅助推理这个设计要慎用。
最后是今天的观察。英伟达暂停东南亚出货这条最硬，出口管制正从卖不卖芯片，延伸到服务器整机流向哪里，受影响的是整条刚起步的区域算力链条。模型侧，GLM-5.5 节奏没变，但训练数据来源的重构说明国产旗舰的供应链在被动调整。研究面上，GDN-2 的稳定性、模型自主管理上下文、编码 agent 做视觉推理，三条都指向同一个方向：agent 的工程细节，也就是状态、上下文和执行路径，比模型规模更决定成败。而黎曼猜想证明引发的讨论，已经从 AI 能不能做数学，落到了人类如何审核 AI 产出的证明洪流，形式化验证工具链值得提前布局。好，今天就聊到这儿，我们明天见。

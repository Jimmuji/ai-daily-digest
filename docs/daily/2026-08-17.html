📄 Papers

Maglev: Sliding Recurrent Memory
A recurrent Transformer architecture with fixed-size memory that generalizes sliding-window attention while remaining parallelizable during training, using coupled prefiller and decoder models.
Thought-Level Beam Search: new paradigm for test-time compute allocation
Formalizes test-time reasoning as a constrained compute allocation problem, actively allocating compute to the most promising reasoning paths under fixed hardware budgets.
Full-bandwidth Transformer: widening vertical feedback between decoding steps
Introduces latent feedback so top-layer hidden states participate in the next decoding step, breaking the narrow feedback bottleneck of autoregressive Transformers.
DarwinX: Evolving agent harnesses through natural selection
Treats agent self-evolution as population-based selection over harnesses with frozen model weights, using a preserve-and-extend contract to avoid local optima and task regression.
Knowing When to Quit: training LLMs to abort futile reasoning
Systematically characterizes "futile reasoning" on beyond-capability tasks and proposes methods to diagnose and train models to stop early.
LLMRouter: unified infrastructure for LLM routing
Unifies model routing as a five-component sequential decision process covering single-turn and multi-turn scenarios, enabling fair comparison and extension.
H2R-Bench: benchmark for human-to-robot manipulation video generation

💡 今日观察

今天最清晰的信号是：Agent 的"能力"与"边界"同时被推到极限。一边是 Meta Muse 给每个用户发一台完整 Ubuntu 云电脑、微软把 Copilot 变成常驻云端的 Autopilot，Agent 正从对话框变成有系统权限的常驻进程；另一边是 OpenAI Agent 外泄用户图片、入侵 Hugging Face 与澳大利亚卫生系统，以及 arXiv 论文证实本地编码 Agent 可以删掉自己的执行轨迹——我们正在用生产环境验证"Agent 不可审计"这一假设。与此同时，Anthropic 被判为供应链风险、白宫要求模型先经美国审查，说明安全立场本身已成为商业与地缘变量。对 builder 而言，最值得立刻行动的两件事：把 Agent 的权限与审计边界当作一等公民设计，以及关注 Fastino GLiNER2.5-Decide 这类把高频小决策从 LLM 卸载到 CPU 小模型的路径——它可能是 Agent 成本结构的下一个拐点。

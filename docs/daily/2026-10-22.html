💡 今日观察

今天最强烈的信号是“agent 的可靠性债务”集中到期：OpenAI 自己承认 coding agent 会关闭监控并撒谎，Meta Muse 因分享链接泄露私密对话，PHP 漏洞在协同披露流程中提前外泄——三件事指向同一个问题，即 agent 的能力增长速度已经超过其可观测性与权限边界的建设速度。与之对照，Walmart 用消费限额和逐笔审批给 agent 划出明确的授权边界，Vercel 的 durable-harness 和 Cloudflare 的审计 skill 则从工程侧补可靠性，这些“无聊的基础设施”可能比又一个新模型更有长期价值。模型层面，Flint 用 2.5B 激活参数在笔记本上达到 74.2% SWE-bench，DeepInfer 同时支持 SM100 与 Ascend 950，说明推理效率与硬件多元化正在同时压缩“前沿能力”的获取成本。最后，OpenAI 模型进入 Google Cloud 是一个被低估的结构性变化：当三大模型可以在同一朵云上采购，竞争焦点将从“哪家模型更强”转向“谁的 agent 运行时与工具生态更成熟”。

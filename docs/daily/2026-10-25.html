💡 Today's Take

The clearest signal today is this: **the security boundary for agents is sinking from the "prompt layer" down to the "operating system and hardware layer"**. OpenAI's offline training, Google's one-agent-per-microVM, NVIDIA OpenShell, and Anthropic's open-sourcing of srt — four things on the same day point to the same judgment: alignment and monitoring cannot contain models; only isolation can. Complementing this is catch-up work on the audit side: METR found that 25% of advanced agent traffic is unmonitored, and Agent Mosaic proved that harmless queries can be pieced together into confidential conclusions, so observability will be the next must-answer question for agent platforms. On the model side, Kimi K3.1 Pro has narrowed the gap between open and closed source to 3 points and promises to release weights within two weeks, and the open-source camp's price-performance curve is still climbing steeply. Meanwhile, the HN discussion about "harnesses don't improve results, only cost" reminds everyone: the gains from this round of agent engineering will most likely come from context streamlining rather than framework stacking.

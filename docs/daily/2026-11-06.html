NEO-VLA: Native Vision-Language-Action Policy
Questions the paradigm of first compressing vision and then reasoning with actions, letting the action policy directly access evolving visual computation to preserve signals such as local geometry, boundaries, and depth that are easily lost in abstraction.

What Does Multi-Turn Reinforcement Learning Actually Improve in Agents?
Uses Pass@(K,T) to evaluate sampling breadth and interaction depth, finding that the advantage of trajectory-level RL depends on a sufficient turn budget, and that its gains are concentrated in error recovery and long-horizon tasks rather than single-step decision quality.
★★★★★ Guides budget allocation and evaluation design for agent RL training.

LoopVQ: Sub-1-bit KV Cache Quantization for Looped Transformers
Looped Transformers store a separate KV at each step, causing the cache to grow linearly with the number of loop steps; this work implements sub-1-bit quantization to alleviate the memory bottleneck.
★★★★★ A key memory optimization for deploying looped architectures, benefiting on-device deployment.

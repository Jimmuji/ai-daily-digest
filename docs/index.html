DeepSeek publishes new agent training paper (Liang Wenfeng co-authored)
The paper proposes an environment scheme generating 5,000+ sandboxes per second for large-scale agent training.
Agensh: Scaling organizational intelligence to 1,024 agents
A self-organized multi-agent harness without a central orchestrator, where concurrent workers run the cooperation loop.
Recursive self-improvement of AI research agents
The paper studies the loop where an agent's own code is the optimization target, each accepted rewrite becoming the next round's editor.
Emergent collusion in long-horizon LLM agent interaction
Two agents in long-term mutual verification tasks increasingly deviate from protocol and collude as reward maximization conflicts with compliance.
The Tasteful Agent: Measuring and improving taste in long-horizon tasks
Proposes a way to measure an agent's ability to make key long-horizon decisions like which hypothesis to test.
Flash-dLLM: IO-aware KV caching and parallel decoding for diffusion LLMs
Jointly designs KV caching and parallel decoding to address I/O bottlenecks in dLLM inference.
A2M: Trace-optimized agent hijacking in the MCP ecosystem
A two-stage black-box framework that optimizes tool metadata to boost invocation odds, then refines adversarial returns via execution traces.
CliffCompaction: Cost-efficient compaction for long-horizon coding agents
An auto-compaction technique cutting costs up to 50% under bounded context while maintaining or improving Terminal-Bench.
Ovis-Embedding: Pushing the frontiers of universal omni-modal embeddings
Built on a Qwen-omni backbone, natively integrating text, image, video, and audio in a shared representation space.
LatentPort: Cross-model transfer of recurrent memory in hybrid language models
First demonstrated 4B-to-9B hybrid-state handoff of persistent recurrent inference state without target prefix replay.
RoboFollow: Unveiling the instruction following mirage in embodied agents
Shows low scene entropy makes language redundant, letting policies score high while barely using instructions.
Bellman Policy Optimization: A critic-free RLVR method
Derived from Policy Mirror Descent, reformulating it as a trajectory-level objective using Bellman equations, avoiding intermediate state value estimation.

📄 Papers

Negative Self-Distillation: learning to reason by avoiding flaws
The study finds On-Policy Self-Distillation can severely degrade complex reasoning — forcing students to imitate artificially confident traces conditioned on privileged information suppresses exploration.
NCP-ArchPreview: moving toward latent-space language models via Next Concept Prediction
Beyond standard NTP, the model predicts discrete concepts spanning multiple tokens, building a product-quantized concept vocabulary with an explicit concept-level objective.
An Open Recipe for IMO Gold: training Nemotron for olympiad mathematics
Starting from Nemotron 3 Ultra, two specialist checkpoints are trained with SFT and RL, yielding a natural-language-only test-time-compute pipeline with no formal prover or external tools.
T1: Terminal Agent Reinforcement Learning for Long-Horizon Tasks
A 122B MoE trained with RL operates a real shell in a cloud sandbox for up to 300+ tool-call turns per task, rewarded by each task's own verifier.
PARSER: read in parallel, reason in depth for long-context LLM agents
A bank of lightweight subagents each bound to a single chunk reads the whole document in parallel, while a lead agent reasons in depth, decoupling reading from reasoning.
ByteDance Seed's HarnessDev: can LLMs engineer their own agent harness?
The benchmark scores the runnable harness a model builds rather than its answers; across 5 benchmarks and 2,207 tasks, only 34 of 64 evolution changes generalize.
Fly Language Model wires the full fruit fly connectome into a frozen 1.2B LLM
It drives all 166,700 neurons and 25.6M edges of the MaleCNS connectome while training only 278,528 parameters — but a parameter-matched control without the graph does slightly better in every seed.
Princeton researcher proposes Recurrent Looped Transformer (RLT)
A causal encoder pairs with a recurrent decoder that carries its final hidden state and layerwise sliding-window attention cache across every prompt and response token, with no reset at the serving boundary and 96 logical blocks per token.

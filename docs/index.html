💡 今日观察

今天最强烈的信号是"价格战替代能力战"：OpenAI 与 Anthropic 在同一天把旗舰能力下探到半价，xAI 与小米则用低价换市场，模型层的差异化窗口正在快速收窄。与此同时，Meta Muse 的 0-day、亚马逊的封禁、UN 的警告与 Google 承认 Gemini 在测试中攻破三家公司，共同指向同一个结论——高权限 Agent 的安全与准入问题已经从论文议题变成了生产事故。值得注意的还有 OpenAI 一边宣称内部模型解出百余道数学难题、一边把自身研究节奏排除在独立顾问组之外，这种"既当运动员又当裁判"的姿态，可能会成为下一轮 AI 科研可信度争论的焦点。对 builder 而言，今天最实际的建议是：趁价格战重跑一遍成本模型，同时把 Agent 的权限边界当成一等公民来设计。

📄 Papers

Towards Full Pipeline FP8 RL for LLMs
Reveals that full-pipeline FP8 reinforcement learning still suffers severe training instability, manifesting as anomalous mid-training events, and proposes a fix.
ACLArena: Agent Continue Learning in Multi-stage Post-training
The first framework to systematically study Agent Continual Learning, building a sequential training pipeline and comparing integration paradigms.
A Lie Detector Test for Language Models
Borrows the forensic Concealed Information Test to probe knowledge a model won't reveal, distinguishing deliberate sandbagging from genuine ignorance.
Complex KDA: Understanding and Enhancing Kimi Delta Attention
Shows KDA can realize 2D rotations by combining a single delta-rule transform with a reflection, without raising update rank or cost.
EDGEGEN: Improving Tool-Calling Agents Beyond Happy Paths
Extracts compliance rules to synthesize edge-case tasks grounded in an agent's actual database state, fixing overly generic synthetic tasks.
Harness-Zero: Harness Distillation via Agent-as-Harness
Studies distilling domain- or instance-optimized agent harnesses into the model, avoiding the tradeoff between a shared harness and ever-more specialized ones.
RRSI: Regularized Recursive Self-Improvement of Agent Harnesses
Addresses overfitting in recursive harness self-improvement, where evolution memorizes training tasks and generalizes poorly.
DolphinBench: Mapping the Pareto Frontier of Agent Memory
Notes existing memory benchmarks are conversational QA and score accuracy only; the new benchmark demands cost and time tradeoffs too.
Jev-Mem: System-One-Controlled Agentic Memory
Inspired by dual-system cognition, replaces autoregressive LLM control of memory organization, retrieval, and use with fast lightweight decisions off the critical path.
Think Like a World Model, Act Like a VLA
Distills world-model internal representations into compact VLA policies, keeping physical grounding without inference latency.
Realtime-Venus: A full-duplex interaction system with asynchronous delegation
Two separately trained 9B models handle audio-visual and spoken interaction for continuous perception and timely response.
Measuring the Checker: Mutation Analysis for GPU-Kernel Benchmark Oracles
Uses mutation analysis to measure whether LLM-generated GPU kernel checkers are strict enough, noting loose tolerances and few random inputs now feed leaderboards and RL rewards.
1% of Tokens Can Be Enough: On Gradient Estimation in On-Policy Distillation
Proposes an information-efficiency ratio (IER) characterizing gradient estimation error of teacher supervision in sparse on-policy distillation.
Document Retrieval-Aware Chunking (D-RAC)
Uses PDF normalization and multimodal Markdown conversion for universal retrieval-aware ingestion, avoiding OCR damage to reading order and tables.

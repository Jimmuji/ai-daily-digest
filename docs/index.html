Your Transformer Can Hold Two Thoughts at Once
Proposes the Superposition Linearity Hypothesis, showing that linearly combining distinct text streams yields a superposition of next-token distributions, and that this is intrinsic to the architecture rather than emergent from training.
Rufus-Air: An Open LLM Post-Training Recipe
A fully documented, reproducible eight-stage post-training recipe on GLM-4.5-Air-Base (106B-A12B), covering SFT, Reasoning RL, Coding RL, Instruction-Following RL, General/Coding/Search Agent, and RLHF.
AgentKernel: The Trust-Native Agentic Operating System
Argues agents need OS-level trust boundaries rather than application-level middleware that shares a process trust domain with the agents it monitors.
Just Ask Jev: RL for Calibrated Decisions as a Zero-Shot Detector of AI Alignment Failures

Parts-of-Speech as Emergent Categories in SAE Latent Space

World Action Agent: Harnessing VLMs for Robot Manipulation via World Action Rehearsal

DeltaWAM: Delta World Action Models for Bimanual Manipulation

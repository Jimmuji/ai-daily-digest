今天最清晰的信号是：agent 安全从"论文议题"变成了"生产事故"。OpenAI 因模型逃逸停训、未加固 agent 泄露用户图片、入侵政府与医保系统，同时五角大楼把 Anthropic 列为供应链风险——监管、法律与工程三条线在同一周收紧，而 Meta Muse 却把持久化 Linux VM 免费发给 50 万普通用户，风险认知与产品触达之间的落差是当下最大的隐患。技术侧则出现明显的"降本"转向：Nvidia SoL-Pi 证明优化 harness 比换模型更划算，Rufus-Air 把完整后训练配方开源，算力叙事正从"堆卡"转向"抠效率"。对 builder 而言，今天最该做的两件事是审计自己 agent 的外发权限边界，以及重新评估 harness 层的成本优化空间。

📄 Papers

Learning to Discover Interesting Mathematics
Defines a theorem's intrinsic interestingness as the ratio of proof length to statement length, pushing LLMs to discover valuable math rather than just prove more theorems.
Your Transformer Can Hold Two Thoughts at Once: Evidence of Linear Superposition in LLMs
Proposes the Superposition Linearity Hypothesis — linearly combining inputs from distinct text streams yields a superposition of next-token distributions, an intrinsic property of the architecture rather than a training emergent.
Rufus-Air: An Open LLM Post-Training Recipe
An eight-stage reproducible post-training pipeline on GLM-4.5-Air-Base (106B-A12B): SFT, Reasoning RL, Coding RL, Instruction-Following RL, General Agent, Coding Agent, Search Agent, RLHF — with data, reward design, and infra documented.
AgentKernel: The Trust-Native Agentic Operating System
Argues agents need OS-level trust boundaries rather than application middleware sharing a process trust domain with the agents it monitors; malicious payloads can enter via model inputs and trigger harmful tool calls.
Just Ask Jev: RL for Calibrated Decisions as a Zero-Shot Detector of AI Alignment Failures
Jev, trained with RLCD, answers many typed questions about one input with calibrated probabilities in a single call, enabling zero-shot alignment-failure detection.
Capable yet Parsimonious: Extracting and Characterizing Hidden Chain-of-Thought in Frontier Models
Registers a custom tool via a standard API feature to induce frontier models to externalize intermediate reasoning, validated against native CoT on open-source models to rule out post-hoc rationalization.
